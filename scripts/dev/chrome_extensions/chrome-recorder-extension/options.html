# Browser Bridge - Remote Control API Specification

## Overview
This Chrome extension connects to your server via HTTP polling and WebSocket for real-time browser control.

## Server Requirements
- HTTP API endpoint for polling commands
- WebSocket endpoint for real-time communication and audio streaming
- CORS enabled for chrome-extension:// origins

---

## HTTP API Endpoints

### 1. POST /poll - Extension polls for commands
Request:
```json
{
  "deviceId": "device_xxxxx",
  "timestamp": 1701234567890,
  "status": {
    "isExecutingTask": false,
    "audioStreamActive": false,
    "realtimeConnected": true
  }
}
```

Response (with command):
```json
{
  "command": "open_url",
  "params": {
    "url": "https://example.com",
    "newTab": true,
    "active": true
  }
}
```

Response (no command):
```json
{
  "command": null
}
```

### 2. POST /result - Extension sends command results
Request:
```json
{
  "deviceId": "device_xxxxx",
  "command": "screenshot",
  "result": {
    "success": true,
    "data": { "screenshot": "data:image/png;base64,..." }
  },
  "timestamp": 1701234567890
}
```

---

## WebSocket Protocol

### Connection
- URL: ws://your-server/ws
- Binary type: arraybuffer (for audio chunks)

### Messages from Extension

1. Register device:
```json
{ "type": "register", "deviceId": "device_xxxxx" }
```

2. Command result:
```json
{
  "type": "command_result",
  "command": "screenshot",
  "result": { "success": true, "data": {...} },
  "timestamp": 1701234567890
}
```

3. Screenshot data:
```json
{
  "type": "screenshot",
  "data": "data:image/png;base64,...",
  "timestamp": 1701234567890
}
```

4. Audio chunks: Binary WebM audio data (not JSON)

### Messages to Extension (Commands)
```json
{
  "command": "open_url",
  "params": { "url": "https://example.com" }
}
```

## Available Commands

| Command | Parameters | Description |
|---------|------------|-------------|
| open_url | url, newTab?, active? | Open URL in new/current tab |
| close_url | url OR pattern | Close tabs matching URL |
| close_tab | tabId? | Close specific or current tab |
| switch_tab | tabId OR url | Switch to tab |
| screenshot | format?, quality? | Capture visible tab |
| get_html | tabId?, selector? | Get rendered HTML |
| get_console | tabId?, clear? | Get console logs |
| get_tabs | - | List all tabs |
| execute_script | code | Run JavaScript |
| click | selector OR x,y | Click element |
| input | selector, value, clear? | Input text |
| navigate | url, tabId? | Navigate tab |
| reload | tabId?, bypassCache? | Reload page |
| start_audio | - | Start audio streaming |
| stop_audio | - | Stop audio streaming |

## Audio Streaming

When audio streaming is enabled:
1. Extension captures tab audio + optional microphone
2. Audio chunks (WebM format) sent via WebSocket as binary
3. Chunk interval configurable (default 1000ms)

To receive audio:
- Listen for binary WebSocket messages
- Each chunk is a valid WebM audio segment
- Concatenate chunks for complete audio

## Python Server Example

```python
from flask import Flask, request, jsonify
from flask_cors import CORS
import asyncio
import websockets

app = Flask(__name__)
CORS(app)

commands = {}  # device_id -> [command_queue]

@app.route('/poll', methods=['POST'])
def poll():
    data = request.json
    device_id = data['deviceId']
    if device_id in commands and commands[device_id]:
        return jsonify(commands[device_id].pop(0))
    return jsonify({'command': None})

@app.route('/result', methods=['POST'])
def result():
    data = request.json
    print(f"Result: {data['command']} -> {data['result']}")
    return jsonify({'status': 'ok'})

# WebSocket handler
async def ws_handler(websocket, path):
    async for message in websocket:
        if isinstance(message, bytes):
            # Audio chunk
            print(f"Audio: {len(message)} bytes")
        else:
            # JSON message
            data = json.loads(message)
            print(f"Message: {data}")

if __name__ == '__main__':
    app.run(port=8080)
```

## Node.js Server Example

```javascript
const express = require('express');
const cors = require('cors');
const WebSocket = require('ws');

const app = express();
app.use(cors());
app.use(express.json());

const commands = {};

app.post('/poll', (req, res) => {
  const { deviceId } = req.body;
  if (commands[deviceId]?.length) {
    res.json(commands[deviceId].shift());
  } else {
    res.json({ command: null });
  }
});

app.post('/result', (req, res) => {
  console.log('Result:', req.body);
  res.json({ status: 'ok' });
});

app.listen(8080);

// WebSocket
const wss = new WebSocket.Server({ port: 8081 });
wss.on('connection', (ws) => {
  ws.on('message', (data) => {
    if (Buffer.isBuffer(data)) {
      console.log('Audio:', data.length, 'bytes');
    } else {
      console.log('Message:', JSON.parse(data));
    }
  });
});
```
