# 文档词典统计工具 - 功能需求文档

## 核心功能需求

### 1. 单词提取功能

#### 1.1 从网页提取英文单词
- **提取模式**（用户可选择）:
  - **模式1 - 只提取文本**: 仅提取页面可见文本内容中的单词
  - **模式2 - 提取所有**: 提取所有内容，包括：
    - 页面可见文本
    - HTML 源码中的单词
    - CSS 样式表中的单词
    - JavaScript 代码中的单词
- **处理逻辑**:
  - 提取所有英文单词（只包含字母 a-z, A-Z）
  - 处理驼峰命名（如 "getElementById" 拆分为 "get", "Element", "By", "Id"）
  - 去除重复单词
- **过滤规则**:
  - 长度小于 3 的单词（如 "a", "an", "is"）→ 过滤掉
  - 不符合单词格式的字符串（如 "aB" 这种小写+大写组合）→ 过滤掉
- **输出**: 有效单词数组 `new_words`

#### 1.2 单词统计
- **总单词数**: 统计提取到的所有有效单词数量
- **未读单词数**: 根据已读单词列表，计算未读单词数量
- **完成百分比**: `(未读单词数 / 总单词数) * 100`

---

### 2. 用户交互功能

#### 2.1 提取模式切换
- **功能**: 用户可以选择提取模式
- **选项1**: 只提取文本内容
- **选项2**: 提取所有内容（包含HTML/CSS/JS源码）
- **行为**: 
  - 切换时重新提取单词
  - 更新单词统计
  - 更新显示内容

#### 2.2 单词显示
- **功能**: 显示所有提取到的单词
- **格式**: 每行一个单词，用换行符分隔
- **触发**: 用户操作触发显示

#### 2.3 单词排序功能
- **功能**: 将单词按字母顺序排序后显示
- **规则**:
  - 按字母顺序排序（A-Z）
  - 每列最多 20 个单词
  - 如果单词超过 20 个，自动创建多列
  - 所有列的行数相同

#### 2.4 单词分类功能
- **功能**: 按单词首字母分类显示
- **规则**:
  - 按首字母（大写）分组（A, B, C...）
  - 每个字母类别最多 30 个单词
  - 如果某个字母的单词超过 30 个，自动创建多列
  - 表格第一行为字母标题
  - 每个单元格内多个单词用换行分隔

---

### 3. 数据流程

#### 3.1 单词提取流程
```
用户选择提取模式
    ↓
模式1（只提取文本）:
  网页文档 → 提取可见文本 → 分割单词 → 处理驼峰命名 → 去重 → 过滤 → 存储到 new_words

模式2（提取所有）:
  网页文档 → 提取HTML源码 → 提取CSS源码 → 提取JS源码 → 提取可见文本
    ↓
  合并所有内容 → 分割单词 → 处理驼峰命名 → 去重 → 过滤 → 存储到 new_words
```

#### 3.2 单词显示流程
```
用户触发显示
    ↓
更新显示内容（每行一个单词）
    ↓
（可选）用户选择排序或分类
    ↓
更新显示格式
```

### 4. 功能清单

| 功能 | 描述 | 触发方式 |
|------|------|----------|
| 提取单词 | 从网页提取所有英文单词 | 页面加载时自动执行 |
| 切换提取模式 | 选择只提取文本或提取所有（含源码） | 用户切换选项 |
| 显示单词总数 | 显示总单词数 | 自动更新 |
| 显示未读数量 | 显示未读单词数 | 自动更新 |

| 按顺序排序 | 按字母顺序显示单词 | 用户触发排序 |
| 按字母分类 | 按首字母分类显示单词 | 用户触发分类 |

---

### 5. 数据存储

- **new_words**: 存储所有有效单词（数组）
- **filterwords**: 存储被过滤掉的单词（数组）
- **已读单词列表**: 通过 `GM_getValue`/`GM_setValue` 存储（用于计算未读数量）

---

### 6. 业务规则

#### 6.1 单词提取规则
- 只提取英文单词（a-z, A-Z）
- 最小长度: 3 个字符
- 过滤格式: 不符合 `^[a-z]+[A-Z]$` 模式的字符串（如 "aB" 会被过滤）

#### 6.2 单词显示规则
- **列表模式**: 每行一个单词，用换行符分隔
- **排序模式**: 
  - 按字母顺序排序
  - 每列 20 个单词
  - 自动分列
- **分类模式**:
  - 按首字母分组
  - 每列 30 个单词
  - 自动分列

---

### 7. 关键函数逻辑

| 函数 | 输入 | 处理逻辑 | 输出 |
|------|------|----------|------|
| `getDocumentWords(extractAll)` | `extractAll` 布尔值 | 根据extractAll决定提取范围（文本或全部），提取单词，处理驼峰命名，去重，过滤 | 单词数组 |
| `getUserWordsCount(readwords, extractAll)` | 已读单词列表，提取模式 | 调用getDocumentWords提取单词，计算未读单词，计算百分比 | `{precent, words, unread_words}` |
| `setWordsToTextarea()` | 无 | 将new_words数组用换行符连接，写入显示区域 | 无 |
| `displaySortedWords()` | 无 | 对new_words排序，每列20个单词，创建表格显示 | 无 |
| `displayCategorizedWords()` | 无 | 按首字母分组，每列30个单词，创建表格显示 | 无 |

---

## 总结

这是一个**单词提取和统计工具**，核心逻辑：
1. ✅ 从网页提取英文单词（支持两种提取模式）
2. ✅ 统计总单词数和未读单词数
3. ✅ 支持多种显示方式（列表、排序、分类）
4. ✅ 用户可切换提取模式，实时更新统计
