# Third-Party Package System - Emergency Update

## Issue Fixed

**Error**: `ModuleNotFoundError: No module named 'flask'`

**Cause**: Flask and psutil were not included in the third_party.py dependency management system.

## Changes Made

### 1. Updated DEPENDENCY_MAP

Added missing packages:
```python
DEPENDENCY_MAP = {
    # ... existing packages ...
    "flask": "flask",      # NEW - Web framework
    "psutil": "psutil",    # NEW - Process management
}
```

### 2. Added Getter Functions

**Flask Functions** (7 new functions):
- `get_third_package_flask()` - Flask module
- `get_third_package_Flask()` - Flask class
- `get_third_package_flask_render_template_string()`
- `get_third_package_flask_jsonify()`
- `get_third_package_flask_request()`
- `get_third_package_flask_send_file()`
- `get_third_package_flask_Response()`

**Psutil Function**:
- `get_third_package_psutil()` - Process management

### 3. Updated Module Wrapper

Added to `_ThirdPartyModule.__getattr__`:
```python
# Flask web framework
elif name == 'flask': return get_third_package_flask()
elif name == 'Flask': return get_third_package_Flask()
elif name == 'render_template_string': ...
elif name == 'jsonify': ...
elif name == 'request': ...
elif name == 'send_file': ...
elif name == 'Response': ...

# Process management
elif name == 'psutil': return get_third_package_psutil()
```

### 4. Updated Files to Use third_party

**utils/source_viewer_server.py**:
```python
# Before:
```
