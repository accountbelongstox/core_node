## Created Files

### 1. third_party.py (368 lines)
**Location**: `build_scripts/third_party.py`

**Features**:
- ✅ Automatic dependency checking on import
- ✅ Auto-installation of missing packages via pip
- ✅ Lazy loading mechanism (packages loaded only when accessed)
- ✅ Package caching (avoid repeated imports)
- ✅ Cross-platform compatibility (Windows/Linux/macOS)
- ✅ Platform-aware pip installation commands
- ✅ Module wrapper for direct attribute access

**Supported Packages**:
- `PIL/Pillow` - Image processing (Image, ImageOps, ImageDraw, ImageFont)
- `pyyaml` - YAML configuration
- `opencv-python` - Computer vision (optional)
- `numpy` - Numerical computing (optional)

**Architecture**:
```python
third_party.py
├── DEPENDENCY_MAP
│   └── Maps import names to PyPI packages
├── check_and_install_dependencies()
│   └── Auto-check and install on import
├── _lazy_import()
│   └── Lazy loading with auto-install
├── Getter Functions
│   ├── get_third_package_PIL()
│   ├── get_third_package_PIL_Image()
│   ├── get_third_package_PIL_ImageOps()
│   ├── get_third_package_PIL_ImageDraw()
│   ├── get_third_package_PIL_ImageFont()
│   ├── get_third_package_yaml()
│   ├── get_third_package_cv2()
│   └── get_third_package_numpy()
└── _ThirdPartyModule (wrapper class)
    └── Provides direct module-level access
```

## Usage Examples

### Method 1: Direct Import (Recommended)

```python
from third_party import Image, ImageOps, yaml

img = Image.open("image.png")
config = yaml.safe_load(open("config.yaml"))
```

### Method 2: Getter Functions

```python
from third_party import get_third_package_PIL_Image

Image = get_third_package_PIL_Image()
img = Image.open("image.png")
```

### Method 3: Module Access

```python
import third_party

img = third_party.Image.open("image.png")
```

## Platform-Specific Installation

### Windows
```bash
python -m pip install --no-user <package>
```

### Linux/macOS
```bash
python3 -m pip install --break-system-packages --ignore-installed <package>
```
