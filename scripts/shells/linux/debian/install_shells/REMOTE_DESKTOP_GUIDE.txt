================================================================================
方案1: GNOME Remote Desktop (内置，推荐用于临时访问)
================================================================================

优点：
✓ 系统内置，无需安装
✓ 与GNOME完美集成
✓ 支持标准RDP协议

缺点：
✗ 用户必须先登录桌面
✗ 性能一般
✗ 不支持VNC

安装步骤：
-----------
1. 运行配置脚本：
   sudo bash /www/programing/core_node/scripts/shells/linux/debian/install_shells/125_setup_gnome_rdp.sh

2. 按提示设置密码

3. 确保用户已登录到桌面

4. 从Windows连接：
   - Win+R → mstsc
   - 输入服务器IP
   - 用户名：ubuntu
   - 密码：刚才设置的密码

重要提示：
----------
- 用户必须先在本机登录桌面，RDP才能工作
- 这是"Desktop Sharing"模式，不是"Remote Login"
- 适合临时远程协助场景

查看状态：
----------
sudo bash /www/programing/core_node/scripts/shells/linux/debian/install_shells/125_setup_gnome_rdp.sh --status

禁用：
------
sudo bash /www/programing/core_node/scripts/shells/linux/debian/install_shells/125_setup_gnome_rdp.sh --disable

================================================================================
方案2: RustDesk (开源，推荐用于常规远程访问) ⭐推荐⭐
================================================================================

优点：
✓ 完全开源
✓ 不需要用户预先登录
✓ 性能优秀
✓ 支持文件传输
✓ 跨平台（Windows/Mac/Linux）
✓ 可自建中继服务器

缺点：
✗ 需要额外安装

安装步骤：
-----------
1. 通过桌面应用安装器安装：
   sudo bash /www/programing/core_node/scripts/shells/linux/debian/install_shells/120_install_desktop_applications.sh

   然后在菜单中选择安装 RustDesk

2. 启动 RustDesk：
   - 从应用程序菜单启动
   - 或命令行：rustdesk

3. 获取连接信息：
   - 记下显示的ID
   - 记下密码（或设置固定密码）

4. 在Windows上连接：
   - 下载RustDesk客户端：https://rustdesk.com
   - 输入Ubuntu上显示的ID
   - 输入密码

官网：https://rustdesk.com
GitHub：https://github.com/rustdesk/rustdesk

方案3: NoMachine (免费商业软件)
================================================================================

优点：
✓ 性能非常好
✓ 免费个人使用
✓ 功能丰富
✓ 不需要用户预先登录

缺点：
✗ 闭源
✗ 需要双端安装

安装步骤：
-----------
1. 下载：
   wget https://download.nomachine.com/download/8.14/Linux/nomachine_8.14.2_1_amd64.deb

2. 安装：
   sudo dpkg -i nomachine_8.14.2_1_amd64.deb

3. 在Windows上安装NoMachine客户端
   https://www.nomachine.com/

4. 连接：
   - 启动NoMachine
   - 输入服务器IP
   - 使用Linux用户名密码登录

官网：https://www.nomachine.com/

方案4: AnyDesk (商业软件，个人免费)
================================================================================

优点：
✓ 性能很好
✓ 简单易用
✓ 个人使用免费

缺点：
✗ 闭源
✗ 商业用途需付费

安装步骤：
-----------
1. 添加仓库：
   wget -qO - https://keys.anydesk.com/repos/DEB-GPG-KEY | sudo apt-key add -
   echo "deb http://deb.anydesk.com/ all main" | sudo tee /etc/apt/sources.list.d/anydesk-stable.list

2. 安装：
   sudo apt update
   sudo apt install anydesk

3. 启动并获取ID：
   anydesk

4. 在Windows上下载并安装AnyDesk
   https://anydesk.com/

官网：https://anydesk.com/

================================================================================
为什么不用xrdp？
================================================================================

❌ Ubuntu 24.04 问题：
1. 使用Wayland作为默认显示服务器
2. xrdp只支持X11协议
3. 安装xrdp会破坏GNOME Remote Desktop
4. 连接后立即断开（协议不兼容）

Reddit社区共识：
- "xrdp was for x11. You can't use that for a Wayland session"
- "installing XRDP breaks the built-in system"
- 推荐使用GNOME Remote Desktop或第三方软件

如果必须用xrdp：
- 切换到X11会话（不推荐）
- 使用Ubuntu 22.04 LTS代替

理由：配置零门槛，性能可靠

================================================================================
故障排除
================================================================================

GNOME Remote Desktop 连接失败：
--------------------------------
1. 检查用户是否已登录桌面
   who

2. 检查服务状态：
   sudo bash 125_setup_gnome_rdp.sh --status

3. 检查防火墙：
   sudo ufw status
   sudo ufw allow 3389/tcp

4. 重启服务：
   sudo -u ubuntu systemctl --user restart gnome-remote-desktop

RustDesk 无法连接：
-------------------
1. 检查服务：
   systemctl --user status rustdesk

2. 检查防火墙（默认使用中继服务器，通常不需要）

3. 重启RustDesk

通用问题：
----------
1. 确认网络连接
2. 检查防火墙规则
3. 查看系统日志：journalctl -xe

================================================================================
安全建议
================================================================================

1. 使用强密码
2. 仅在可信网络上启用
3. 配置防火墙限制访问IP
4. 定期更新软件
5. 不使用时禁用远程访问

防火墙配置示例（限制IP）：
----------------------------
sudo ufw allow from 192.168.1.0/24 to any port 3389
sudo ufw allow from 192.168.1.0/24 to any port 21118
