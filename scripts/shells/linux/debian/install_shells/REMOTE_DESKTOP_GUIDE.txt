================================================================================
GNOME Remote Desktop (推荐)
================================================================================

优点：
✓ 系统内置，无需安装额外软件
✓ 与 GNOME 桌面完美集成
✓ 支持标准 RDP 协议
✓ 配置简单，一键启用

缺点：
✗ 用户必须先登录桌面才能使用
✗ 性能中等

适用场景：
- 临时远程访问
- 需要使用标准 RDP 协议
- 不想安装第三方软件

安装步骤：
-----------

1. 启用 GNOME Remote Desktop：

   sudo bash 127_setup_gnome_rdp.sh

   脚本会自动：
   - 检测桌面环境
   - 安装必要的包（gnome-remote-desktop, freerdp2-x11）
   - 配置防火墙规则（开放 3389 端口）
   - 启用 RDP 服务
   - 设置随机密码

2. 查看连接信息：

   sudo bash 127_setup_gnome_rdp.sh --status

3. 自定义密码（可选）：

   sudo bash 127_setup_gnome_rdp.sh --password "your_password"

4. 禁用远程桌面：

   sudo bash 127_setup_gnome_rdp.sh --disable

连接方式：
-----------

Windows 客户端：
1. 打开"远程桌面连接"（mstsc）
2. 输入 Ubuntu 的 IP 地址
3. 使用 Ubuntu 用户名和设置的密码登录

macOS 客户端：
1. 安装 Microsoft Remote Desktop
2. 添加新连接，输入 IP 地址
3. 使用 Ubuntu 用户名和密码登录

Linux 客户端：
1. 使用 Remmina 或 freerdp
   remmina rdp://username@ip_address:3389

重要提示：
-----------
⚠️  用户必须先登录 Ubuntu 桌面，远程桌面才能工作
⚠️  连接时会看到实际桌面（非虚拟桌面）
⚠️  建议在局域网内使用，外网连接建议配合 VPN

================================================================================
防火墙配置
================================================================================

如果无法连接，检查防火墙：

# 检查防火墙状态
sudo ufw status

# 允许 RDP 端口
sudo ufw allow 3389/tcp

# 如果使用其他防火墙（如 iptables）
sudo iptables -A INPUT -p tcp --dport 3389 -j ACCEPT

================================================================================
故障排查
================================================================================

1. 无法连接：
   - 确认用户已登录 Ubuntu 桌面
   - 检查防火墙是否允许 3389 端口
   - 检查服务状态：systemctl --user status gnome-remote-desktop

2. 连接后立即断开：
   - 确认用户已登录
   - 检查密码是否正确
   - 查看日志：journalctl --user -u gnome-remote-desktop

3. 性能问题：
   - 降低颜色深度（16位）
   - 禁用桌面动画和特效
   - 使用有线网络而非 WiFi

其他远程桌面方案
================================================================================

如果 GNOME Remote Desktop 不满足需求，可以考虑：

NoMachine (免费):
- 无需用户预先登录
- 性能优秀
- 支持文件传输
- 官网：https://www.nomachine.com/getting-started

AnyDesk (商业):
- 适合互联网远程
- 性能优秀
- 简单易用
- 官网：https://anydesk.com/en/downloads/linux
