Date: 2025-11-12

Problem:
When selecting "Set Special Software Environment Variables (like AI)" from dd.sh main menu,
it launches the Python script which shows its own menu. However, the "Back to Main Menu"
option in the Python script did not return control to dd.sh - it just continued looping
within the Python script, trapping the user in the Python menu.

Root Cause:
In special_software_env_manager.py line 601, the "Back to Main Menu" action used
`continue` instead of `return`, which kept the script running in its while loop.

Solution Applied:
1. Changed menu item text from "Back to Main Menu" to "Back to dd.sh Main Menu"
   (line 585) for clarity
2. Changed the action handler from `continue` to `return` (line 602) to exit the
   Python script and return control to dd.sh

Result:
Users can now properly navigate:
- dd.sh main menu → "Set Special Software Environment Variables (like AI)"
- Python menu appears with options
- Select "Back to dd.sh Main Menu" → returns to dd.sh main menu
- Normal navigation flow restored
