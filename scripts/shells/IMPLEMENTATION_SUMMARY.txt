7. ADDING NEW AI SERVICES (GUIDE)
===================================================================================

To add a new AI service (e.g., "OpenAI"):

7.1 Linux (special_software_env_manager.sh)
--------------------------------------------
Add to ENVIRONMENT_CONFIGS array (around line 196):

ENVIRONMENT_CONFIGS["OpenAI"]="title=OpenAI Environment Variables;\
description=Set up OpenAI environment variables for API access;\
common=openai;\
command_prefix=openai;\
vars=OPENAI_API_KEY,OPENAI_BASE_URL;\
secrets=OPENAI_API_KEY;\
smart_recognition=true"

7.2 Windows (SpecialSoftwareEnvManager.ps1)
--------------------------------------------
Add to $script:EnvironmentConfigs hashtable (around line 507):

"OpenAI" = @{
    Title = "OpenAI Environment Variables"
    Description = "Set up OpenAI environment variables for API access"
    Common = "openai"
    CommandPrefix = "openai"
    DisplayName = "OpenAI"
    SmartRecognition = @{ Enabled = $true }
    Variables = @(
        @{
            Name = "OPENAI_API_KEY"
            DisplayName = "OPENAI_API_KEY"
            Description = "OpenAI API key"
            IsSecret = $true
            InputType = "Token"
        },
        @{
            Name = "OPENAI_BASE_URL"
            DisplayName = "OPENAI_BASE_URL"
            Description = "OpenAI API base URL (optional)"
            IsSecret = $false
            InputType = "Url"
        }
    )
}

THAT'S IT! Menu will automatically show the new service.

9. ARCHITECTURE NOTES
===================================================================================

DESIGN PRINCIPLES:
------------------
1. DRY (Don't Repeat Yourself): Single source of truth in ENVIRONMENT_CONFIGS
2. Data-Driven: Menu and logic driven by configuration data, not hardcoded
3. Extensibility: Adding new services requires only config changes
4. Consistency: Linux and Windows versions follow same patterns
5. Maintainability: Minimal code changes needed for new features

CROSS-PLATFORM COMPATIBILITY:
------------------------------
- Linux: Bash + Python 3
- Windows: PowerShell 5.1+
- WSL: Hybrid support with auto-detection
- Configuration format differs (hashtable vs string) but logic is identical
