================================================================================
Local Test Credentials - User Guide
================================================================================

This guide explains how to use the Local Test Credentials feature to securely
store and access passwords, API keys, and secrets for local testing.

================================================================================
1. OVERVIEW
================================================================================

Local Test Credentials provides a secure way to store:
  - Passwords for local testing environments
  - API Keys for test APIs
  - Secret Keys for encryption/signing
  - Encryption Keys (32 bytes hex)
  - JWT Secrets for authentication
  - Database Passwords for test databases

All credentials are stored as encrypted constants in the .secret_ignore
directory and are NOT committed to version control.

================================================================================
2. QUICK START
================================================================================

Step 1: Configure Credentials
------------------------------
Run the environment manager:
    python special_software_env_manager.py

Then navigate:
    Main Menu > Local Test Credentials > Save Encrypted Constants

Step 2: Enter Your Credentials
-------------------------------
You will be prompted to enter:
  * Local Test Password (Required)
  * Local Test API Key (Required)
  * Local Test Secret Key (Required)
  * Local Test Encryption Key (Optional)
  * Local Test JWT Secret (Optional)
  * Local Test Database Password (Optional)

You can create multiple credential sets by choosing different file numbers.

Step 3: Use Credentials in Your Code
------------------------------------
See examples below for Python and Node.js usage.

================================================================================
3. PYTHON USAGE
================================================================================

Basic Usage:
------------
```python
from scripts.pytools.special_software_env_manager.utils.local_test_helper import (
    LocalTestHelper
)

# Create helper instance (default file_number=1)
helper = LocalTestHelper(file_number=1)

# Get individual credentials
password = helper.get_password()
api_key = helper.get_api_key()
secret_key = helper.get_secret_key()
encryption_key = helper.get_encryption_key()
jwt_secret = helper.get_jwt_secret()
db_password = helper.get_db_password()

# Use the credentials
if api_key:
    print(f"Using API Key: {api_key[:8]}...")
else:
    print("API Key not configured")
```

Get All Credentials at Once:
-----------------------------
```python
from scripts.pytools.special_software_env_manager.utils.local_test_helper import (
    get_local_test_credentials
)

credentials = get_local_test_credentials(file_number=1)

# credentials is a dictionary with keys:
# 'password', 'api_key', 'secret_key', 'encryption_key',
# 'jwt_secret', 'db_password'

print(f"API Key: {credentials['api_key']}")
print(f"Password: {credentials['password']}")
```

Check Credentials Status:
--------------------------
```python
from scripts.pytools.special_software_env_manager.utils.local_test_helper import (
    print_local_test_status
)

# Print status of credentials (masked for security)
print_local_test_status(file_number=1)
```

Verify Required Credentials:
-----------------------------
```python
helper = LocalTestHelper(file_number=1)

if helper.verify_required_credentials():
    print("All required credentials available")
    # Proceed with testing
else:
    print("Missing required credentials")
    # Exit or prompt user to configure
```

================================================================================
4. NODE.JS USAGE
================================================================================

Using pyfoundations (recommended):
-----------------------------------
```javascript
const { getSecretKey } = require('pyfoundations');

// Get credentials (file_number defaults to 1)
const password = getSecretKey('LOCAL_TEST_PASSWORD_1');
const apiKey = getSecretKey('LOCAL_TEST_API_KEY_1');
const secretKey = getSecretKey('LOCAL_TEST_SECRET_KEY_1');

// Use credentials
if (apiKey) {
    console.log(`Using API Key: ${apiKey.substring(0, 8)}...`);
} else {
    console.log('API Key not configured');
}
```

Direct file access:
-------------------
```javascript
const fs = require('fs');
const path = require('path');

const secretDir = path.join(
    __dirname,
    '../.secret_ignore/raw'
);

function getLocalTestCredential(name, fileNumber = 1) {
    const filePath = path.join(secretDir, `${name}_${fileNumber}`);
    try {
        return fs.readFileSync(filePath, 'utf-8').trim();
    } catch (error) {
        return null;
    }
}

// Get credentials
const password = getLocalTestCredential('LOCAL_TEST_PASSWORD', 1);
const apiKey = getLocalTestCredential('LOCAL_TEST_API_KEY', 1);
const secretKey = getLocalTestCredential('LOCAL_TEST_SECRET_KEY', 1);
```

================================================================================
5. MULTIPLE CREDENTIAL SETS
================================================================================

You can maintain multiple sets of credentials (e.g., for different
environments):

Set #1 - Development:
```python
dev_helper = LocalTestHelper(file_number=1)
dev_api_key = dev_helper.get_api_key()
```

Set #2 - Staging:
```python
staging_helper = LocalTestHelper(file_number=2)
staging_api_key = staging_helper.get_api_key()
```

Set #3 - Production Testing:
```python
prod_helper = LocalTestHelper(file_number=3)
prod_api_key = prod_helper.get_api_key()
```

================================================================================
7. SECURITY NOTES
================================================================================

DO:
  ✓ Store credentials in .secret_ignore directory
  ✓ Ensure .secret_ignore is in .gitignore
  ✓ Use different credentials for different environments
  ✓ Rotate credentials regularly
  ✓ Use strong, random values for keys and secrets

DON'T:
  ✗ Commit credentials to version control
  ✗ Share credentials in plain text
  ✗ Use production credentials for testing
  ✗ Hard-code credentials in your source code
  ✗ Reuse credentials across multiple projects

================================================================================
9. TROUBLESHOOTING
================================================================================

Credentials not found:
----------------------
1. Check if credentials are configured:
   python special_software_env_manager.py
   > Local Test Credentials > View Encrypted Constants

2. Verify the file number matches:
   helper = LocalTestHelper(file_number=1)  # Use correct number

3. Check .secret_ignore/raw directory exists:
   ls -la .secret_ignore/raw/

Credentials appear encrypted:
-----------------------------
If you see encrypted .js files in .secret_ignore/encrypted, they need to be
decrypted. The system will prompt you for a password when accessing them.

Missing pyfoundations:
----------------------
If using Node.js and pyfoundations is not available, use direct file access
as shown in section 4.

================================================================================
10. CREDENTIAL VARIABLE NAMES
================================================================================

The following credential names are available:

Required (file_number appended):
  - LOCAL_TEST_PASSWORD_{N}
  - LOCAL_TEST_API_KEY_{N}
  - LOCAL_TEST_SECRET_KEY_{N}

Optional (file_number appended):
  - LOCAL_TEST_ENCRYPTION_KEY_{N}
  - LOCAL_TEST_JWT_SECRET_{N}
  - LOCAL_TEST_DB_PASSWORD_{N}

Where {N} is the file number (1, 2, 3, etc.)
