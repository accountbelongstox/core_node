─────────────────────────────────────────────────────────────────────────────
📋 BASIC COMMANDS
─────────────────────────────────────────────────────────────────────────────

List all servers:
  python codex_sync_mcp_servers.py list

Show config location:
  python codex_sync_mcp_servers.py show-config

Get help:
  python codex_sync_mcp_servers.py --help

─────────────────────────────────────────────────────────────────────────────
➕ ADD HTTP MCP SERVER
─────────────────────────────────────────────────────────────────────────────

Basic HTTP server:
  python codex_sync_mcp_servers.py add <name> <url> --type http

With authentication:
  python codex_sync_mcp_servers.py add <name> <url> --type http \
    --header "Authorization: Bearer TOKEN"

Multiple headers:
  python codex_sync_mcp_servers.py add <name> <url> --type http \
    --header "Authorization: Bearer TOKEN" \
    --header "X-API-Key: KEY123"

Examples:
  python codex_sync_mcp_servers.py add sentry https://mcp.sentry.dev/mcp --type http
  python codex_sync_mcp_servers.py add notion https://mcp.notion.com/mcp --type http
  python codex_sync_mcp_servers.py add stripe https://mcp.stripe.com --type http

─────────────────────────────────────────────────────────────────────────────
➕ ADD STDIO MCP SERVER
─────────────────────────────────────────────────────────────────────────────

Basic stdio server:
  python codex_sync_mcp_servers.py add <name> "<command>"

With environment variables:
  python codex_sync_mcp_servers.py add <name> "<command>" \
    --env KEY1=VALUE1 \
    --env KEY2=VALUE2

Examples:
  python codex_sync_mcp_servers.py add filesystem "npx -y @modelcontextprotocol/server-filesystem" \
    --env ALLOWED_DIRECTORIES=/path/to/dir

  python codex_sync_mcp_servers.py add airtable "npx -y airtable-mcp-server" \
    --env AIRTABLE_API_KEY=your_key

  python codex_sync_mcp_servers.py add git "npx -y @modelcontextprotocol/server-git"

─────────────────────────────────────────────────────────────────────────────
🗑️  REMOVE SERVER
─────────────────────────────────────────────────────────────────────────────

Remove a server:
  python codex_sync_mcp_servers.py remove <name>

Example:
  python codex_sync_mcp_servers.py remove sentry

─────────────────────────────────────────────────────────────────────────────
🔄 ENABLE/DISABLE SERVER
─────────────────────────────────────────────────────────────────────────────

Disable server (without removing):
  python codex_sync_mcp_servers.py disable <name>

Enable disabled server:
  python codex_sync_mcp_servers.py enable <name>

Examples:
  python codex_sync_mcp_servers.py disable notion
  python codex_sync_mcp_servers.py enable notion

─────────────────────────────────────────────────────────────────────────────
💡 QUICK TIPS
─────────────────────────────────────────────────────────────────────────────

1. List first: Always run 'list' to see current servers
2. Disable > Remove: Disable for testing, remove permanently
3. Quotes matter: Use quotes for commands with spaces
4. Headers format: "KEY: VALUE" (colon with space)
5. Env vars format: "KEY=VALUE" (equals with no space)
6. Backups: Auto-created before every change
7. Auto-reload: Codex reloads config automatically

─────────────────────────────────────────────────────────────────────────────
🚀 COMMON WORKFLOWS
─────────────────────────────────────────────────────────────────────────────

Initial Setup:
  1. python codex_sync_mcp_servers.py sync
  2. python codex_sync_mcp_servers.py list
  3. Add custom servers as needed

Add Cloud Service:
  1. Get service URL from docs
  2. python codex_sync_mcp_servers.py add <name> <url> --type http
  3. Add auth header if needed

Add Local Tool:
  1. Install npm package
  2. python codex_sync_mcp_servers.py add <name> "npx ..."
  3. Add env vars if needed

Debug Issues:
  1. python codex_sync_mcp_servers.py list
  2. python codex_sync_mcp_servers.py disable <name>
  3. Fix and re-enable

─────────────────────────────────────────────────────────────────────────────
🆘 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

Server not appearing?
  → Run 'list' to verify it was added
  → Check it's not disabled
  → Restart Codex/IDE

Authentication failing?
  → Verify header format: --header "Key: Value"
  → Check token hasn't expired
  → Review config.toml manually

Stdio server not starting?
  → Test command in terminal first
  → Check environment variables
  → Use absolute paths

Changes not taking effect?
  → Restart Codex CLI session
  → Reload IDE/editor
  → Check for error messages
