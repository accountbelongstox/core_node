可以实现 👍，这就是典型的 Linux 作为路由器/NAT 网关 的场景。

你要的效果是：

A 网卡：连接外部网络（获取外部 IP，可能是公网或者上级路由分配的内网 IP）。

B 网卡：作为 LAN 接口，给内部客户端分配私有 IP（比如 192.168.10.x），并通过 A 出口上网。

Ubuntu 相当于一台 家庭路由器。

配置步骤（内部路由 / NAT 网关）
1. 开启内核转发
echo 1 | sudo tee /proc/sys/net/ipv4/ip_forward
sudo sed -i 's/^#net.ipv4.ip_forward=1/net.ipv4.ip_forward=1/' /etc/sysctl.conf

2. 配置 B 网卡 LAN 地址

比如设置 192.168.10.1/24 作为网关：

sudo ip addr add 192.168.10.1/24 dev B-nic-name
sudo ip link set dev B-nic-name up

3. 配置 NAT 转发

让内网流量经过 A 出口 NAT 出去：

# 内网走 A 出口
sudo iptables -t nat -A POSTROUTING -o A-nic-name -j MASQUERADE

# 允许 LAN 转发到 WAN
sudo iptables -A FORWARD -i B-nic-name -o A-nic-name -j ACCEPT

# 允许已建立连接返回
sudo iptables -A FORWARD -i A-nic-name -o B-nic-name -m state --state ESTABLISHED,RELATED -j ACCEPT

4. 给内网客户端分配 IP（DHCP）

要让 B 接口自动给客户端分配 IP，你需要一个 DHCP 服务器。可以用 isc-dhcp-server 或 dnsmasq。

例如用 dnsmasq（简单方便）：

sudo apt install dnsmasq -y


编辑 /etc/dnsmasq.conf，添加：

interface=B-nic-name
dhcp-range=192.168.10.50,192.168.10.150,12h
dhcp-option=3,192.168.10.1       # 默认网关
dhcp-option=6,8.8.8.8,1.1.1.1    # DNS


重启：

sudo systemctl restart dnsmasq

5. 客户端配置

插到 B 网卡的设备会自动拿到 192.168.10.x 的 IP、网关和 DNS。

通过 A 网卡的公网/上级网络上网。

✅ 最终效果：

Ubuntu 变成一个 双网卡路由器。

A 接外网，B 管内网，内网设备可以上网。
