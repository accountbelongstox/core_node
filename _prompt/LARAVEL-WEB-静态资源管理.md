API Testing Dashboard 工作原理
1. 应用选择
顶部下拉菜单选择应用（AChatV1、AppQyV1、AwyV0、BankV1、ItToolsV1、McpV1、ServerManagerV1、Common）
选择后加载该应用的 API 列表
2. API 搜索
搜索框支持按 API 编号（如 "1"）、路径（如 "initialize"）或描述搜索
自动高亮并滚动到匹配项
3. 共享请求头管理
每个应用有独立的共享请求头配置
支持的请求头包括：
Authorization（Bearer token）
Content-Type
Accept
Client-Token
Auth-User-Token
功能：
保存所有请求头
重置为默认值
复制请求头 JSON
4. API 列表展示
每个 API 显示：
编号（#1, #2...）
HTTP 方法（POST、GET、PUT、DELETE）
端点路径
简短描述
可展开/折叠的详情区域
5. API 详情面板
展开后显示：
认证要求（Required/Optional）
控制器名称
参数列表（类型、必填/可选、示例值）
响应格式
可编辑的端点 URL
JSON 参数输入框（预填充示例）
操作按钮：
Send Request：发送请求并显示响应
Save Params：保存参数到本地存储
Load Params：从本地存储加载参数
Copy Headers：复制请求头到剪贴板
6. 工作流程
选择应用 → 加载该应用的 API 列表
配置共享请求头（如 Authorization token）
展开目标 API
编辑请求参数（JSON）
点击 "Send Request" 发送请求
在响应区域查看结果
可选：保存参数供后续使用
7. 数据持久化
使用浏览器本地存储保存：
每个 API 的参数
应用的共享请求头
支持跨会话恢复
8. 特性
实时 API 测试
参数模板（预填充示例）
请求头管理（应用级别共享）
响应查看
参数保存/加载
快速搜索与定位
该 Dashboard 用于在浏览器中直接测试 Laravel API，无需 Postman 等外部工具。
