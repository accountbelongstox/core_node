# App Management System Extension

## Overview

Continue to extend more information. Simultaneously extend client, management, and technical ends. Require generating multiple APPs daily, and display each APP's access status in backend. Each APP uses the same backend, just different APPs. Require new APP list and access status.

## Features

### Backend Display

- Each APP's current revenue
- Each APP's responsible customer service (many-to-many)
- Customer service promotion revenue for each APP

### Management End Page Design

Design management end pages with:
- APP list and access status
- Revenue tracking per APP
- Customer service assignment (many-to-many relationship)
- Customer service promotion revenue tracking
