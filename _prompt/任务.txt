● PHP-FPM vs Swoole 差异化支持方案

  已完成项目分析，以下是详细方案：

  ---
  📊 当前状态

  ✅ 已实现

  - PHP-FPM 模式: 传统 FastCGI 方式，所有 Laravel/PHP 网站都使用此模式
  - 配置位置: ServerManagerV1DomainManager.php:708
  - 模板: laravel.nginx (单一模板)

  ❌ 未实现

  - Swoole/Octane 支持: 无
  - 运行模式切换: 无
  - 进程管理: 无

  ---
  🔍 关键差异

  | 特性     | PHP-FPM                                        | Swoole/Octane
                |
  |--------|------------------------------------------------|----------------------
  ------------|
  | 协议     | FastCGI                                        | HTTP 反向代理
                    |
  | 配置     | fastcgi_pass unix:/var/run/php/php8.4-fpm.sock | proxy_pass 
  http://127.0.0.1:8000 |
  | 性能     | 基准 (100%)                                      | 3-5倍提升
  (300-500%)                |
  | 内存     | 请求级分配                                          | 常驻内存
                         |
  | 代码更新   | 立即生效                                           | 需要重启
                          |
  | 进程生命周期 | 短暂                                             | 长期
                        |

  ---
  ✅ 是否可以同时运行？

  答案：可以，但不能在同一域名上

  技术层面：
  - ✅ PHP-FPM 和 Swoole 监听不同端口/Socket，不冲突
  - ✅ 可以同时运行多个实例：
  PHP-FPM: /var/run/php/php8.4-fpm.sock
  Swoole 1: 127.0.0.1:8000 (api.example.com)
  Swoole 2: 127.0.0.1:8001 (app.example.com)
  FPM Site: unix socket (admin.example.com)

  限制：
  - ⚠️ 同一域名只能用一种模式
  - ⚠️ 不能在同一 nginx 配置中同时配置 fastcgi_pass 和 proxy_pass

  2️⃣ Nginx 配置生成逻辑

  // ServerManagerV1DomainManager.php 修改
  private static function generateNginxConfig(string $domain, array $config): bool
  {
      $phpMode = $config['php_mode'] ?? 'fpm';

      if ($phpMode === 'swoole' || $phpMode === 'octane') {
          // Swoole 模式：反向代理配置
          $port = $config['swoole_port'] ?? 8000;
          $phpConfig = "
      # Swoole/Octane Reverse Proxy
      location / {
          proxy_pass http://127.0.0.1:$port;
          proxy_http_version 1.1;
          proxy_set_header Host \$host;
          proxy_set_header X-Real-IP \$remote_addr;
          proxy_set_header X-Forwarded-For \$proxy_add_x_forwarded_for;
          proxy_set_header X-Forwarded-Proto \$scheme;
          
          # WebSocket support
          proxy_set_header Upgrade \$http_upgrade;
          proxy_set_header Connection 'upgrade';
          proxy_cache_bypass \$http_upgrade;
      }
      
      # Static files handled by Nginx
      location ~* \\.(jpg|jpeg|png|gif|ico|css|js|svg|woff|woff2|ttf|eot)\$ {
          try_files \$uri =404;
          expires 1y;
          add_header Cache-Control \"public, immutable\";
      }";
      } else {
          // FPM 模式：FastCGI 配置（现有逻辑）
          $phpVersion = $config['php_version'] ?? '8.4';
          $phpConfig = "
      location ~ \\.php\$ {
          fastcgi_pass unix:/var/run/php/php$phpVersion-fpm.sock;
          fastcgi_param SCRIPT_FILENAME \$realpath_root\$fastcgi_script_name;
          include fastcgi_params;
      }";
      }

      // ... 其余配置生成逻辑
  }
