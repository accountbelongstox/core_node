## Global Background

## Script Engine

Add many script options and script tasks. Can select one or multiple devices to execute scripts. Scripts target social APP icons. After clicking script, pop up a script flow diagram and introduction. Do not change current display effects. Can extend components on current effects.

## Frontend Extensions

### Social APP Elements

Add Douyin (TikTok), Momo elements (script engine, bottom menu).

### Device Selection

In middle device area, can drag to select multiple devices at once.

### Collision Detection

Add collision detection. If mouse is not in pressed state and moves to a device, record collision effect on that device. Click, double-click, drag (when moved out of device, record mouse auto-release). Then in bottom menu area, add a log display area, dynamically display logs. When there is collision detection: display which device was operated and trajectory status.
