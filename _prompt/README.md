## 📝 File Naming Notes

### Naming Conventions
- **All Documents**: Use uppercase with underscores, e.g., `FLUTTER_BUILD_SYSTEM_GUIDE.MD`
- **Index Files**: Keep lowercase, e.g., `README.md`
- **Configuration Files**: Keep original naming, e.g., `mcp*.json`, `mcp*.toml`

### File Formats
- **Markdown Format** (`.md`): Recommended format, structured documents
- **Text Format** (`.txt`): Simple prompts
- **Configuration Files** (`.json`, `.toml`): MCP configuration templates
