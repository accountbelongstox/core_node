  主要改进

  1. 自动项目类型检测

  - 自动识别 React、Vue、Vite、Next.js、Nuxt.js
  - 显示检测结果并提供 Y/n 确认选项

  2. 新的交互式主菜单

  1. Install Capacitor (自动备份 package.json)
  2. Development Server (调试)
  3. Build for Web (编译为 Web)
  4. Build for Android (编译为 Android)
  Q. Quit (退出)

  3. build_config.ini 解析器

  - 自动读取并解析 INI 配置文件
  - 支持所有配置段：[app_info], [package_settings], [resources] 等

  4. 智能文件替换系统

  - 递归扫描：自动扫描 android/ 目录下所有相关文件（.xml, .gradle, .kt, .java, .json, .properties）
  - App 名称替换：在所有可能的位置替换应用名称和包名
  - 不指定具体文件名：通过递归查找自动发现需要修改的文件

  5. 图片处理功能

  - 等比例缩放：根据目标图片尺寸自动等比例缩放源图片
  - 居中处理：缩放后的图片自动居中放置
  - 高质量渲染：使用 HighQualityBicubic 插值算法
  - 递归查找目标图片：自动查找所有 ic_launcher*.png 和 splash*.png 文件

  6. 图片资源 Fallback 逻辑

  优先级顺序：
  1. build_config.ini 中指定的路径
  2. assets/logo.png 和 assets/splash.png
  3. 如果都没有，显示警告但继续编译

  7. package.json 自动备份

  - 首次安装 Capacitor 时自动备份
  - 如果已有备份则跳过，避免重复备份

  核心功能说明

  安装 Capacitor（选项 1）

  1. 自动备份 package.json（如果没有备份）
  2. 安装 Capacitor 核心包和 Android/iOS 平台
  3. 初始化 Capacitor 配置
  4. 添加 Android 平台

  编译为 Android（选项 4）

  执行流程：
  1. 检查 Android 平台是否已安装
  2. 解析 build_config.ini 配置
  3. 准备替换映射（app 名称、包名）
  4. 查找图标和启动图（按优先级）
  5. 递归替换：扫描所有 Android 文件并替换文本
  6. 等比例缩放并替换图标：自动查找所有目标图标文件
  7. 等比例缩放并替换启动图：自动查找所有启动图文件
  8. 编译 Web 资源
  9. 同步 Capacitor
  10. 构建 Android APK（Debug 版本）

  使用说明

  运行脚本：
  cd D:\programing\core_node\poly_apps\cmg-corporate-portal\scripts
  .\start.ps1

  脚本会：
  1. 显示检测到的项目类型（React + Vite）
  2. 询问是否使用检测结果（默认 Y）
  3. 显示主菜单供选择操作

  配置文件说明

  确保 build_config.ini 包含必要配置：
  - app_name: 应用内部名称
  - display_name_chinese/english: 显示名称
  - default_package_id: 应用包名（如 com.ddsj.cmg.club）
  - icon_file/splash_screen_file: 图标和启动图路径（可选）

  所有变量都在脚本开头声明，符合 PowerShell 最佳实践，并且使用绝对路径而非相对路径。
