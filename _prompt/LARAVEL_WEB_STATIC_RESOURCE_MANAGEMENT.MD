# Laravel Web Static Resource Management

In Static Resources - Media Browser, when a file is selected, display in the status bar above: current directory. There is a folder button, refresh button, and upload static resource button. Upload will pop up a window that can upload a folder recursively through all directories. Then upload the entire folder to that directory. Also support browsing all types of static resources, not just videos. After clicking play, it will loop play in the same directory. Automatically play next. Also use keywords like "first", "one, two, three", "1,2,3", "lesson_1/1" for ascending sort of resources in the same directory.

Please directly bind with API center. When API is unavailable, use mock data. Please establish a mock data center. When pages request API, directly get mock data when URL is not set.
