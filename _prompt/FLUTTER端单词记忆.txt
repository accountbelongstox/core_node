  ⭐ 三大核心联动机制

  1. 单词组 ↔ 总记忆库

  - 任何单词组的学习都会更新总记忆库
  - 同一单词在记忆库中只有一份数据
  - 不同单词组学习同一单词会累加学习次数
  - 记忆库状态反向影响单词组显示（已学/待复习标记）

  2. 总记忆库 ↔ 后端词库

  - 用户学习单词时自动查询后端词库获取完整信息
  - 本地缓存词库数据减少网络请求
  - 用户学习数据可选同步到后端（用于推荐算法）
  - 后端根据用户数据推荐个性化单词组

  3. 复习系统 ↔ 记忆库

  - 复习系统根据记忆库数据计算复习时间
  - 复习结果更新记忆库中的掌握度和复习间隔
  - 艾宾浩斯曲线动态调整每个单词的复习计划
  - 优先级队列管理复习任务

  【瞬时复习详细流程】⭐⭐⭐
  ┌────────────────────────────────────────────────────────────────┐
  │                                                                │
  │  场景：用户正在阅读第 35 个单词 "vocabulary"                    │
  │                                                                │
  │  步骤 1：用户按下空格键或点击「瞬时复习」按钮                   │
  │           ↓                                                    │
  │  步骤 2：系统暂停当前播放                                       │
  │           ↓                                                    │
  │  步骤 3：从历史缓存中获取上一个单词（第 34 个 "study"）          │
  │           ↓                                                    │
  │  步骤 4：跳转到第 34 个单词                                     │
  │           ↓                                                    │
  │  步骤 5：高亮显示 "study"（黄色背景）                           │
  │           ↓                                                    │
  │  步骤 6：自动播放 "study" 的发音 + 释义                         │
  │           ↓                                                    │
  │  步骤 7：播放完毕后，自动返回第 35 个单词 "vocabulary"          │
  │           ↓                                                    │
  │  步骤 8：继续原本的播放流程                                     │
  │           ↓                                                    │
  │  步骤 9：记录瞬时复习次数 +1（用于统计）                        │
  │                                                                │
  │  💡 支持连续按多次，最多回退 10 个单词                          │
  │                                                                │
  └────────────────────────────────────────────────────────────────┘

  ┌────────────────────────────────────────────────────────────────┐
