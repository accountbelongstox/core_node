3. 功能重复实现详情
================================================================================

3.1 ColorPrint 类的重复实现 (严重)
--------------------------------------------
两个版本的 ColorPrint 类:

位置1 (推荐版本): pycore/pyfoundations/color_print.py (完整版)
  - 包含所有功能: green(), red(), yellow(), blue(), gray(), white()
  - 包含高级功能: print_progress(), print_table_row(), print_header()
  - 包含回调机制: register_callback(), unregister_callback()
  - 包含高频输出控制: print_once(), print_min_interval()

位置2 (过时版本): apps/d3-check/utils/_obsolete_color_print.py
  - 简化版本，已标记为 _obsolete
  - 包含 update_line() 方法
  - 缺少回调和高级功能

改进建议:
  - 删除过时的 _obsolete_color_print.py
  - 确保所有项目使用 pycore/pyfoundations/color_print.py
  - 如需要 update_line()，添加到完整版本

3.2 模板匹配器的重复实现 (严重)
--------------------------------------------
为D3和D4分别实现了相似的模板匹配逻辑:

位置1: d3utils/scaled_template_matcher.py (D3版本)
  - ScaledTemplateMatcher 类
  - _get_matcher() 方法
  - _get_scale_factors() 方法
  - _get_scaled_template_image() 方法

位置2: d4utils/d4_scaled_template_matcher.py (D4版本)
  - D4ScaledTemplateMatcher 类
  - 完全相同的结构和方法
  - 仅使用不同的 TEMPLATE_CONFIGS 和分辨率常量

位置3: ui/components/template_matcher_helper.py (UI辅助)
  - TemplateMatcherHelper 类
  - 重复的模板选择和匹配逻辑

代码重复度: ~85% 相同代码

改进建议:
  - 创建基类 UnifiedScaledTemplateMatcher
  - D3和D4版本继承并配置不同的参数
  - 减少代码行数 20-30%

3.3 截图处理的重复实现 (中等)
--------------------------------------------
截图相关功能在多处实现:

位置1: d3utils/screenshot_provider.py
  - ScreenshotData 类
  - 完整屏幕截图和游戏窗口截图

位置2: pycore/pyutils/window_screenshot.py
  - WindowScreenshot 类
  - 基础窗口截图功能
  - 被 screenshot_provider.py 使用

位置3: controller/d4func/screenshot_handler.py
  - D4特定的截图处理

位置4: d4utils/window_region_detector.py
  - 窗口区域截图

改进建议:
  - 统一使用 pycore/pyutils/window_screenshot.py
  - 在 screenshot_provider.py 中高层封装
  - D4特定逻辑继承 screenshot_provider.py

3.4 UI区域收集器的重复实现 (中等)
--------------------------------------------
为了不同的检测策略实现了3个相似的收集器:

位置1: d3utils/collectors/ui_region_collector_optimized.py
  - UIRegionCollectorOptimized 类
  - 基于窗口缓存的优化版本

位置2: d3utils/collectors/ui_region_collector_anchor.py
  - UIRegionCollectorAnchor 类
  - 基于锚点的检测

位置3: d3utils/collectors/ui_region_collector_ultralytics.py
  - UIRegionCollectorUltralytics 类
  - 基于YOLO的检测

重复度: ~60-70%

改进建议:
  - 创建基类 UIRegionCollectorBase
  - 使用策略模式
  - 统一返回接口 (UIRegion 数据类)
