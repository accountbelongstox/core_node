## What I built

A complete Claude Code history extractor in **`scripts/claude_tools/`** (I corrected the typo `clade_tools` → `claude_tools`):

| file | purpose |
|------|---------|
| `extract_claude_history.py` | the extractor (stdlib-only, no pip deps) |
| `extract_claude_history.sh` | convenience wrapper that forwards all args |
| `README.md` | docs (data locations, usage, options) |

**How it works.** I inspected how Claude Code stores data on this machine:
- `~/.claude/projects/<project-slug>/<session-id>.jsonl` — the full per-session **chat record** (user prompts, assistant text/thinking, tool calls, tool results)
- `~/.claude/history.jsonl` — the global **typed-prompt** log

The script parses those JSONL transcripts and writes readable **history text** back into the user data dir (`~/.claude/history-export/` by default — `$CLAUDE_CONFIG_DIR`-aware):

- `history.txt` — combined human-readable transcript of all sessions, chronological
- `prompts.txt` — user prompts only (easy to grep)
- `prompts_global.txt` — typed prompts from `history.jsonl`
- `sessions/<id>.txt` — one transcript per session
- `index.txt` — session listing (time, id, prompt count, size, title)

**Verified on this project's real data:** exported 14 sessions / 129 prompts; `--all-projects`, `--thinking`, and `--full-tools` modes all run clean. Source transcripts are never modified.

```bash
./scripts/claude_tools/extract_claude_history.sh                 # current project
./scripts/claude_tools/extract_claude_history.sh --all-projects  # everything
./scripts/claude_tools/extract_claude_history.sh --thinking --full-tools
```
