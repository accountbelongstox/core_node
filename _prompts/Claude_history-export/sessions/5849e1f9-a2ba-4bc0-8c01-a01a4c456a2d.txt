# Desktop Application Autostart Specification Summary

## File Locations

Autostart `.desktop` files must be placed in directories defined by the base directory specification:

- **User directory**: `~/.config/autostart/` (when `$XDG_CONFIG_HOME` is not set)
- **System directory**: `/etc/xdg/autostart/` (when `$XDG_CONFIG_DIRS` is not set)

The specification states: `"$XDG_CONFIG_DIRS/autostart as defined in accordance with the desktop base directory specification."`

## Precedence Rules

When identical filenames exist in multiple locations, the user directory takes priority. The spec explains: `"If $XDG_CONFIG_HOME and $XDG_CONFIG_DIRS are not set and the two files /etc/xdg/autostart/foo.desktop and ~/.config/autostart/foo.desktop exist then only the file ~/.config/autostart/foo.desktop will be used."`

## Controlling Keys

Key `.desktop` file properties that govern autostart behavior:

- **Hidden**: `"When the .desktop file has the Hidden key set to true, the .desktop file MUST be ignored."`
- **OnlyShowIn/NotShowIn**: Control which desktop environments should autostart the application
- **TryExec**: `"A .desktop file with a non-empty TryExec field MUST NOT be autostarted if the value of the TryExec key does NOT match with an installed executable program."`

## User Override Mechanism

Users can disable system-wide autostart entries by creating a same-named `.desktop` file in their personal directory with `Hidden=true`.
