## How it actually works today

## Why "chrome-mcp + pycore task center isn't enough" — the 5 real problems
1. **"completed" doesn't mean "succeeded."** Bing worker always submits `status:'completed'` even when all words errored (`bing-dictionary-worker-service.ts:914`); Laravel validates result *type* but not *shape*; chrome's "acked" is synthetic. So any detail UI built on this **lies**.
2. **Audio (TTS) is split across 3 uncoordinated paths** — and the main one (`tts_queue_poller`) **isn't even registered on the live launch path** and records *nothing*, so audio is largely **invisible** to the task UI. Two paths can claim the same word and waste work.
3. **No persisted task history/audit anywhere.** Laravel stores only current status + one error string; pycore's task list is a volatile 100-item in-memory dict (lost on restart). You can't reconstruct when/why a task was assigned, retried, or timed out — **fatal for a real detail UI**.
