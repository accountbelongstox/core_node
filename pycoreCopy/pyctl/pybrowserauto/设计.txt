
● DocumentOffline Python 版本开发计划

  ---
  📋 原版功能分析总结

  DocumentOffline (Node.js) 是一个网页离线下载工具，核心功能：

  1. 多种抓取模式: HTTP 请求 / Puppeteer / Iframe / Tampermonkey
  2. 递归链接下载: 按深度爬取同源链接
  3. 资源处理: 下载 CSS/JS/Images/Fonts/Media 并重写 URL
  4. HTML 处理: UTF-8 编码转换、可选移除 JS 标签
  5. 元数据生成: sitemap.xml / mapsite.json / failed_urls.json
  6. 增强功能: 截图、失败重试、自动打开目录

  🔍 四种抓取模式详细分析

  模式 1: HTTP 请求模式

  // 使用 PageFetcher
  this.fetcher = new PageFetcher(this.fileMapper);
  fetchResult = await this.fetcher.fetch(url);

  // 特点:
  // - 最快速，获取原始 HTML
  // - 不执行 JavaScript
  // - 使用 #@downloader 进行 HTTP 下载
  // - 支持 Content-Type 检测
  // - 自动 UTF-8 编码转换

  流程: URL → HTTP 下载 → 临时文件 → 读取内容 → 返回结果

  ---
  模式 2: Puppeteer 浏览器模式

  // 使用 PuppeteerSpiderModule.Fetcher
  this.fetcher = new PuppeteerSpiderModule.Fetcher();
  await this.fetcher.initialize('edge', { headless: !this.debug });
  fetchResult = await this.fetcher.fetch(url);

  // 特点:
  // - 执行 JavaScript，获取渲染后的 HTML
  // - 支持截图功能 (fullPage screenshots)
  // - 支持资源收集 (collectResources)
  // - 支持 XPath 资源映射
  // - 需要 ResourceProxyServer 代理

  关键方法:
  - fetcher.takeScreenshot() - 页面截图
  - fetcher.collectResources() - 收集 CSS/JS/Images 等资源
  - fetcher.getResourceCollector() - 获取资源收集器实例

  ---
  模式 3: Iframe 递归抓取模式 ⭐ 重要

  // 使用 Puppeteer 的 iframe 专用方法
  fetchResult = await this.fetcher.fetchIframeContentRecursive(url, {
    maxDepth: 10,
    delay: 1000,
    maxLinksPerPage: Infinity,
    sameOriginOnly: true,
    skipHashLinks: true,
    onPageCallback: async (pageResult, totalProcessed, depth) => {
      // 每个页面回调
      await self.savePage(pageUrl, content, false);
    },
    onFailedCallback: async (failedResult) => {
      // 失败回调
      self.failedUrls.push({...});
    }
  });

  // 特点:
  // - 专门处理 iframe 嵌套内容
  // - 递归点击 iframe 内所有链接
  // - 自动检测 iframe 域名
  // - 支持跨 iframe 域名的内部链接判断
  // - 独立的成功/失败回调

  独特之处:
  1. 不使用标准队列处理，而是递归遍历
  2. 自动识别 iframe 来源域名
  3. 每个 iframe 页面独立保存
  4. 支持深度嵌套 iframe (maxDepth: 10)

  ---
  模式 4: Tampermonkey 浏览器扩展模式 ⭐ 最复杂

  // 启动 WebSocket 服务器
  this.tampermonkeyServer = TampermonkeyServer.getInstance();
  await this.tampermonkeyServer.ensureStarted();

  // 注册事件处理器
  this.tampermonkeyServer.on('page', this.tampermonkeyPageHandler);
  this.tampermonkeyServer.on('complete', this.tampermonkeyCompleteHandler);
  this.tampermonkeyServer.on('error', this.tampermonkeyErrorHandler);

  // 发送配置和命令
  server.broadcastConfig({
    startUrl: initialUrl,
    maxDepth: this.maxDepth,
    scopeType: this.scopeType,
    sameOriginOnly: true,
    skipHashLinks: true
  });
  server.sendCommand('startPageCrawl', {...});

  // 等待完成
  await this.waitForTampermonkeyCompletion();

  // 特点:
  // - 使用已登录的浏览器会话
  // - 通过 WebSocket 双向通信 (ws://127.0.0.1:8765)
  // - 浏览器端油猴脚本推送页面内容
  // - 支持需要登录的网站
  // - 异步事件驱动模式

  关键组件:
  1. TampermonkeyServer: WebSocket 服务器 (端口 8765)
  2. 油猴脚本: DocumentOffline_Crawler.user.js
  3. 事件系统: page / complete / error 事件
  4. 配置广播: 向浏览器发送爬取配置
  5. 命令发送: focus-url / startPageCrawl 等命令

  处理流程:
  CLI → 启动 WS 服务器 → 自动打开浏览器 →
  油猴脚本连接 WS → 接收配置 →

  🛠️ 关键功能实现

  1. 域名上下文 (DomainContext)

  - canonicalize(url) - URL 规范化
  - isInternalLink(url) - 同域检查
  - isWithinScope(url) - 作用域检查 (路径模式)
  - resolveHref(base, href) - 解析相对链接
  - getOrigin() - 获取源站
  - getScopeUrl() - 获取作用域 URL

  2. 文件映射 (FileMapper)

  - mapPath(parsedUrl) - URL → 本地路径
  - 处理文件扩展名 (支持 30+ 种类型)
  - 自动添加 index.html 默认文件

  3. 资源处理 (UnifiedResourceProcessor)

  - 提取 HTML 中的所有资源引用
  - 下载资源文件到本地
  - 重写 HTML/CSS 中的 URL 为本地路径
  - 支持背景图、内联样式、HTTPS 图片

  4. 备份管理 (BackupManager)

  - 创建时间戳备份目录
  - 自动清理旧备份 (保留最新 N 个)
  - 递归复制/删除目录

  5. 进度追踪 (ProgressTracker)

  - 显示进度条 (█░)
  - 计算剩余时间
  - 限制更新频率 (100ms)

  关键发现总结

  🎯 四种抓取模式对比

  | 模式           | 速度    | JS 执行 | 登录支持 | 复杂度 | 适用场景         |
  |--------------|-------|-------|------|-----|--------------|
  | HTTP         | ⭐⭐⭐⭐⭐ | ❌     | ❌    | 低   | 静态网站         |
  | Puppeteer    | ⭐⭐⭐   | ✅     | ❌    | 中   | SPA/动态页面     |
  | Iframe       | ⭐⭐    | ✅     | ❌    | 高   | 嵌套 iframe 内容 |
  | Tampermonkey | ⭐     | ✅     | ✅    | 最高  | 需要登录的网站      |

  ⭐ Iframe 模式特点

  - 专门处理 iframe 嵌套内容
  - 自动检测 iframe 来源域名
  - 递归点击 iframe 内所有链接 (深度可达 10)
  - 独立的成功/失败回调机制

  ⭐ Tampermonkey 模式特点

  - 使用 WebSocket 双向通信 (端口 8765)
  - 利用已登录的浏览器会话
  - 浏览器油猴脚本推送页面内容
  - 事件驱动：page / complete / error 事件
  - 适合需要身份验证的网站
