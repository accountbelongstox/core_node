# Windows Auto-Start Guide
# PyCore RPC Server - 开机自启动功能说明

## 📋 功能概述

Windows Tray 菜单现已集成**开机自启动**功能，可以一键启用/禁用 PyCore RPC Server 随 Windows 启动。

**更新日期**：2025-11-28
**状态**：✅ 已测试通过

---

## 🎯 核心特性

### ✅ 实现的功能

| 功能 | 说明 |
|------|------|
| **一键切换** | 在托盘菜单中点击切换开/关 |
| **后台运行** | 使用 `pythonw.exe` 无窗口启动 |
| **调试友好** | 启动窗口延迟 5 秒关闭，便于查看错误 |
| **自动替换** | 反复切换时自动更新脚本文件 |
| **用户级启动** | 仅影响当前用户，无需管理员权限 |
| **状态显示** | 菜单项显示 ✓ 标记表示已启用 |

### 📍 启动脚本位置

```
C:\Users\{用户名}\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\PyCore_RPC_Server.bat
```

## 🖱️ 使用方法

### 方法 1：通过托盘菜单（推荐）

1. **启动服务**
   ```bash
   python pycore_module_caller.py
   ```

2. **右键点击系统托盘图标**

3. **查看菜单**
   ```
   ├─ Open Web Interface
   ├─ ────────────
   ├─ RPC v2 Server: 59000
   ├─ Singleton Port: 59100
   ├─ ────────────
   ├─ Auto-Start on Boot        ← 点击启用
   ├─ ────────────
   ├─ Restart
   └─ Exit
   ```

4. **点击 "Auto-Start on Boot"**
   - 首次点击：启用开机启动 → 菜单变为 `✓ Auto-Start on Boot`
   - 再次点击：禁用开机启动 → 菜单变为 `Auto-Start on Boot`

### 方法 2：通过 Python API

```python
from pycore.callmodule.platform.windows_startup_manager import WindowsStartupManager

manager = WindowsStartupManager()

# 查看状态
if manager.is_enabled():
    print("开机启动已启用")

# 启用
result = manager.enable()
print(result['message'])

# 禁用
result = manager.disable()
print(result['message'])

# 切换
result = manager.toggle()
print(result['message'])

# 获取详细状态
status = manager.get_status()
print(status)
```

## 🔍 生成的启动脚本

### 脚本内容

```bat
@echo off
REM ================================================================
REM PyCore RPC Server - Auto Start Script
REM Generated by Windows Startup Manager
REM ================================================================

echo [PyCore] Starting RPC Server...
echo [PyCore] Python: D:\.dev_win10\python311\pythonw.exe
echo [PyCore] Script: D:\programing\core_node\pycore_module_caller.py
echo.

REM Start server using pythonw.exe (no console window after this script closes)
start "" "D:\.dev_win10\python311\pythonw.exe" "D:\programing\core_node\pycore_module_caller.py"

echo [PyCore] Server started in background (using pythonw.exe)
echo [PyCore] Check system tray for icon
echo.
echo This window will close in 5 seconds...
echo If you see errors above, please report them for fixing.
echo.

REM Wait 5 seconds to allow viewing startup messages/errors
timeout /t 5 /nobreak >nul

REM Close this console window
exit
```

### 脚本特点

1. **使用 `pythonw.exe`**
   - 无控制台窗口
   - 真正的后台运行
   - 不影响桌面体验

2. **5 秒延迟关闭**
   - 显示启动信息
   - 捕获可能的错误
   - 便于调试问题

3. **自动生成路径**
   - 检测当前 Python 路径
   - 检测 `pycore_module_caller.py` 位置
   - 无需手动配置

## 🧪 测试方法

### 测试 1：启用开机启动

1. 运行服务：`python pycore_module_caller.py`
2. 右键托盘图标，点击 "Auto-Start on Boot"
3. 检查菜单是否显示 `✓ Auto-Start on Boot`
4. 检查启动文件夹：
   ```bash
   explorer "C:\Users\%USERNAME%\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup"
   ```
5. 确认存在 `PyCore_RPC_Server.bat`

### 测试 2：验证开机自启动

1. **重启计算机**
2. 等待 Windows 启动完成
3. 观察：
   - 启动时会短暂显示命令窗口（5秒）
   - 窗口显示启动信息
   - 5秒后窗口自动关闭
   - 系统托盘出现 PyCore 图标

### 测试 3：查看启动错误

如果启动失败：
1. 启动窗口会显示错误信息（5秒内可见）
2. 截图错误信息
3. 手动运行启动脚本查看详细错误：
   ```bash
   "C:\Users\%USERNAME%\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\PyCore_RPC_Server.bat"
   ```

### 测试 4：禁用开机启动

1. 右键托盘图标，再次点击 `✓ Auto-Start on Boot`
2. 菜单变回 `Auto-Start on Boot`（无 ✓）
3. 检查启动文件夹，确认 `PyCore_RPC_Server.bat` 已删除
4. 重启电脑，验证不会自动启动

## ⚙️ 技术细节

### 架构设计

```
┌─────────────────────────────────────┐
│  Windows Tray Menu                  │
│  - Auto-Start on Boot (clickable)   │
└──────────────┬──────────────────────┘
               │ THREAD_BUS event
               ▼
┌─────────────────────────────────────┐
│  handle_tray_toggle_startup()       │
│  - Calls startup_manager.toggle()   │
│  - Updates menu with new state      │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  WindowsStartupManager              │
│  - enable() / disable() / toggle()  │
│  - Generate .bat script             │
│  - Manage startup folder file       │
└──────────────┬──────────────────────┘
               │
               ▼
┌─────────────────────────────────────┐
│  Windows Startup Folder             │
│  PyCore_RPC_Server.bat              │
│  - Uses pythonw.exe                 │
│  - 5-second debug window            │
└─────────────────────────────────────┘
```

### THREAD_BUS 事件

| Event Name | Trigger | Handler |
|------------|---------|---------|
| `tray_action_toggle_startup` | Click menu item | `handle_tray_toggle_startup()` |

### 文件操作

| 操作 | 方法 | 文件操作 |
|------|------|---------|
| **启用** | `enable()` | 创建/替换 `.bat` 文件 |
| **禁用** | `disable()` | 删除 `.bat` 文件 |
| **切换** | `toggle()` | 根据当前状态执行启用/禁用 |
| **检查** | `is_enabled()` | 检查 `.bat` 文件是否存在 |

## 🐛 故障排查

### 问题 1：启动脚本无法运行

**症状**：启动窗口闪现后消失，托盘无图标

**排查步骤**：
1. 手动运行启动脚本：
   ```bash
   "C:\Users\%USERNAME%\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\PyCore_RPC_Server.bat"
   ```
2. 查看错误信息（5秒内）
3. 可能原因：
   - Python 路径错误
   - `pycore_module_caller.py` 路径错误
   - 缺少依赖包

**解决方案**：
```bash
# 检查 Python 路径
where python
where pythonw

# 检查启动脚本路径
python -c "from pycore.callmodule.platform.windows_startup_manager import WindowsStartupManager; m = WindowsStartupManager(); print(m.get_status())"
```

### 问题 2：菜单状态不更新

**症状**：点击菜单后状态没有变化

**解决方案**：
1. 重启服务
2. 检查控制台输出是否有错误
3. 手动检查启动文件夹

### 问题 3：启动延迟过长

**症状**：系统启动后很久才出现托盘图标

**原因**：
- Windows 启动项按顺序执行
- 其他启动项较多

**优化建议**：
- 减少其他启动项
- 使用任务计划程序（高级方法）

## 📚 API 文档

### WindowsStartupManager

#### 初始化

```python
manager = WindowsStartupManager(app_name="PyCore_RPC_Server")
```

**参数**：
- `app_name` (str): 应用名称，用于生成脚本文件名

#### 方法

##### `is_enabled() -> bool`

检查开机启动是否已启用。

**返回**：
- `True`: 已启用
- `False`: 未启用

##### `enable() -> dict`

启用开机启动。

**返回**：
```python
{
    "success": True/False,
    "enabled": True/False,
    "message": "操作消息",
    "script_path": "脚本路径"
}
```

##### `disable() -> dict`

禁用开机启动。

**返回**：同 `enable()`

##### `toggle() -> dict`

切换开机启动状态。

**返回**：同 `enable()`

##### `get_status() -> dict`

获取详细状态信息。

**返回**：
```python
{
    "enabled": True/False,
    "script_path": "脚本路径",
    "script_exists": True/False,
    "startup_folder": "启动文件夹路径",
    "python_exe": "python.exe 路径",
    "pythonw_exe": "pythonw.exe 路径",
    "launcher_script": "pycore_module_caller.py 路径",
    "launcher_exists": True/False
}
```

## 🎨 菜单更新机制

### 动态菜单

菜单项根据当前状态实时更新：

```python
# 未启用
Auto-Start on Boot

# 已启用
✓ Auto-Start on Boot
```

### 更新流程

1. 用户点击菜单项
2. `handle_tray_toggle_startup()` 执行
3. 调用 `startup_manager.toggle()`
4. 调用 `update_tray_menu()` 刷新菜单
5. 菜单显示新状态
