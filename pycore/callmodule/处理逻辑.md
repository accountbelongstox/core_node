# Pycore API 一次性重构处理逻辑

## 📋 重构策略

**策略**: 一次性重构，完全替换现有架构，不保留向后兼容性

**优势**:
- ✅ 代码结构清晰
- ✅ 没有历史包袱
- ✅ 更容易维护
- ✅ 实施速度快

**风险**:
- ⚠️ 一次性变更大
- ⚠️ 需要全面测试

---

## 🗑️ 第一步: 删除旧文件（需要删除6个文件）

### 删除命令

```powershell
# 备份现有代码（重要！）
git add .
git commit -m "[BACKUP] Before refactoring"

# 删除旧路由
Remove-Item pycore/callmodule/routers/health_router.py
Remove-Item pycore/callmodule/routers/ocr_router.py
Remove-Item pycore/callmodule/routers/translator_router.py
Remove-Item pycore/callmodule/routers/voice_subtitle_router.py
Remove-Item pycore/callmodule/routers/singleton_router.py
Remove-Item pycore/callmodule/routers/web_router.py

# 删除旧控制器
Remove-Item pycore/callmodule/controllers/health_controller.py
```
