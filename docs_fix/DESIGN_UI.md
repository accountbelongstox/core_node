# Unified UI Shell (pycore-manager, laravel-manager, wordnew)

Scope: `poly_apps/pycore_laravel_wordnew_ui` — the React/Vite shell and its apps (`apps/pycore-manager`, `apps/laravel-manager`, `apps/wordnew`, `apps/vortex`), the shared layers `core/`, `shared/`, `shell/`, and the rules every UI change must follow. Package manager: bun (`bun.lock`; `bun run lint` = `tsc --noEmit`). Flutter (`poly_apps/flutter_bloom`, pycore `flutter_dev_tools`) is frozen by user decision and is not part of this shell.

Authority: code > `config/pycore_rpc_contract.json`, `config/pycore_relay_contract.json`, `config/queue_center_contract.json`, `config/service_contract.json` > this document. Agent-history page: `DESIGN_AGENT_HISTORY.md`. Relay: `DESIGN_RELAY.md`. Wordnew client: `DESIGN_WORDNEW_CLIENT.md`.

## 1. Layering and the data-model rule

- Components never call APIs directly. Every call goes through a TypeScript data model / store, which goes through exactly one integration layer:
  - Laravel: `core/integrations/laravel/` (`LaravelAPI`, `ApiManager`, `LaravelEndpoints`, `LaravelRealtime`, `LaravelMercureConnection`, `LaravelRelay*`, transport `BaseAPI`).
  - pycore: `core/integrations/pycore/` (`PycoreApi*`, `PycoreHttp`, `PycoreEventClient`, `PycoreLiveSource`, `pycoreTarget`, `pycoreEndpoints`).
  - Compute (TTS, OCR): `core/integrations/compute/` (`ComputeScheduler`, `ComputeAvailability`; wordnew adapter `apps/wordnew/services/compute/WordNewCompute.ts`).
- Apps keep domain mappers/types only; no private fetch helpers, route literals, event listeners, polling loops or type copies.
- Shared contracts live in `core/contracts/` (`QueueCenterContract.ts`, `QueueProgress.ts`, `RelayContract.ts`, `RelayCapabilities.ts`, `ServiceContract.ts`), each read from its `config/*_contract.json`.
- Data planes: queue data, ID page tables, priority bumps, stats, dictionary, media and history go browser → Laravel through the Laravel layer; task dispatch, processor switches, engine/worker state and local capabilities go browser → pycore through the pycore layer. pycore notifications are memory-only. On each pycore connect the UI syncs configuration with pycore exactly once (no periodic config polling). Large lists use DIFF ID pages (revision-aligned page tables persisted in the browser, rows materialized lazily per visible page).
- First paint: the UI shell renders before any network, device or Laravel probe. `PcUiStateBackupGate` renders children after `GATE_GRACE_MS` (1200) even if the backend UI-state read (`STATE_READ_CEILING_MS` 10 000) is in flight, reloading once only if a late reconcile changed state; the home-page chunk is pre-warmed.
- UI state: every registered pycore-manager UI key is written to browser storage and mirrored to one revisioned JSON document under `.core_node/ui_state` (`core/persistence/RevisionedStorageReplica.ts`, `persistence/PycoreManagerUiStateSync.ts`); optimistic revision writes, conflicts apply the backend copy, pycore wins after reconnect; runtime caches are not UI keys.
- Front-end TTL cache: `apps/pycore-manager/api/PycoreCache.ts` (`saveTtlCache`, `loadTtlCache`, prefix `PYCORE_TTL_CACHE_PREFIX`); e.g. orchestration `orch.system_status` (ffmpeg probe) is cached 3 h, painted stale at once, re-probed on expiry or a relay device change.
- Shared primitives: `core/persistence/RuntimeStore.ts` (`createRuntimeStore`), `core/events/RingStore.ts`, `core/tasks/Poller.ts` + `usePolling.ts`, `core/tasks/Backoff.ts`, `core/utils/formatters.ts`, `core/network/hostDetection.ts`, `core/config/NetworkTiming.ts` (`NETWORK_TIMEOUTS`, `UI_DURATIONS`), `shared/notify/notify.tsx` (the one toast system), `StorageManager` with per-app storage-key registries.

## 2. Endpoints

- Laravel endpoint set (`LaravelEndpoints.ts`): domain APIs `https://api.<region>.<domain>` (from the shell-written domain config), every tailnet machine `https://<machine>.<tailnet>.ts.net/laravel-api` (discovered live, `refreshTailnetPeers`), and the current-origin endpoint (tailnet origin → same host + `/laravel-api`; public HTTPS origin → its api host on 443; loopback/LAN origin → `:9000`). `endpointBaseUrl` (protocol, host, port, `basePath`) feeds `buildApiUrl`, endpoint keys and displays. No hardcoded endpoint lists.
- Selection (`ApiManager`): the persisted selection (user-modified > stored current > auto-detected) always wins and is never auto-switched. Only on first run is the first answering endpoint (page's own API first, then priority) selected and persisted. A selected endpoint that does not answer turns the link `reconnecting`; requests resume on that endpoint when it returns. `preselectEndpointSync` is network-free; detection probes all endpoints for badges only.
- Mixed content: `isEndpointMixedContentBlocked` = HTTPS page + plain-HTTP non-loopback endpoint. Blocked endpoints are never fetched, report `MIXED_CONTENT_BLOCKED` and show an amber blocked state; first-run selection skips them.
- pycore target (`pycoreTarget.ts`, `PycoreEndpointProbe.switchPycoreTarget`): direct host `http(s)://<host>:<PYCORE_BACKEND_PORT>` (`ServiceContract`, `service_contract.json ports.pycore_backend`) or relay mode through Laravel. Paths come from `pycoreEndpoints.PycorePaths` / `PYCORE_HTTP_PATHS` (derived from `pycore_rpc_contract.json` `api_prefix` + `protocol_routes`); no `/api/...` literal in UI code.
- pycore routes: `PYCORE_HTTP_ROUTES`, `pycoreRouteMethod`, `isPycoreRouteServed` derive from `config/pycore_rpc_contract.json` (key = path without `ui`, camelCase); a removed route fails `tsc`. `requestPycoreHttp` picks the method from the contract.
- Four-end queue-center/worker paths: `config/queue_center_contract.json` `endpoints` block is the single source; adapters render and percent-encode tokens — Laravel `App\Support\QueueCenterContract::endpoint`, pycore `pyutils/common/queue_center_contract.queue_center_endpoint`, UI `core/contracts/QueueCenterContract.queueCenterEndpoint`, mcp-chrome `utils/queue-center-contract.ts` (`api-paths.ts` derives from it). `routes/api.php` registers them. No `/api/queue-center` or `/api/worker` literal anywhere else.

## 3. Transport

- `PycoreHttp.ts`: request controller only (one `tracedRequest` behind JSON, text, binary, binary-POST, multipart).
- `PycoreEventClient.ts`: the one pycore event subscription — WebSocket `/api/ws` only (direct and proxy; relay tunnel in relay mode), one persisted cursor, reconnect backoff, ping keepalive, presence leases (`holdPycoreLease`). One tab per browser holds the socket (Web Locks leader `pycore-events:<scope>`); other tabs replay over BroadcastChannel and announce their topics.
- Uploads: `core/network/ProgressUpload.ts` (XHR, no total deadline, aborts after `http_transfer.idle_timeout_seconds` without progress). Downloads: `core/network/StallGuardedRead.ts` (`readBytesWithStallGuard`, `consumeBodyWithStallGuard`, `signal`-aware). Both use `core/network/IdleWatchdog.ts` (`TRANSFER_IDLE_MS`). Native Android `ProtocolHttpPlugin.java` uses the same idle rule (`STALLED` → TimeoutError).
- Engine panels: `PycoreSpeechTypes.ts` `EngineRow` / `EnginePanel<Row>` is the one shape that the OCR, STT, LLM and TTS status types extend; worker state reads `processor_enabled` only.
- Console log: `PycoreConsoleLogStore` subscribes the `pycore_log` topic only while a log view is mounted (`usePcLogs()`).
- Reconnect bounds come from one constant, `RECONNECT_BACKOFF_MS` (`core/config/NetworkTiming.ts`); `RelayTransport` reuses `IdleWatchdog`.
- `core/tasks/Backoff.ts`: the one exponential backoff (`jitter` additive/half/none, `initialStep`, `delayFor(step)`), used by `ReconnectingWebSocket`, `Poller`, `LaravelRealtime`, social realtime, queue-center hub, compute scheduler.
- Client-key signing: `ClientKeySigner.ts` (HMAC-SHA256 over the contract canonical fields, WebCrypto), `ClientKeyRouteTable.ts` (Laravel's table at `service_contract.json client_key_auth.routes_endpoint` `/api/public/client-key-routes`, per endpoint, ETag-revalidated, cached in `localStorage`; while no table is known every request of a keyed build is signed), `ClientKeyFailure.ts` (401 `client_key_*` → localized message, no login window). `withClientKey` wraps every Laravel call path. The key is compiled only for the dev server or `CORE_NODE_COMPILE_CLIENT_KEY=1`; ship web builds without it.

## 4. Push-driven refresh

- Events first. `usePycoreTopicRefresh(topics, refresh, {fallbackMs, minIntervalMs=500})`: first event after quiet refreshes at once; bursts collapse into one trailing refresh; the fallback timer runs only while the event link is down; one refresh after each reconnect, server restart, replay loss, and after the relay client event `relay.events.dropped` (`watchEventGap`).
- `createPycoreLiveSource` (`PycoreLiveSource.ts`): shared live-store lifecycle (refcount, topic pushes, reconcile on restart/replay loss/event gap, fallback poll only while disconnected). No relay-only polling: the relay tunnel delivers the same topics.
- Pushed topics replace timers: `ai_usage.changed` (AI usage panel, providers/rates with `operation.changed`), `engine_load_log_appended` (engine log tail, cap 40; the engine load snapshot is polled only while the event link is down), orchestration progress deltas (`progress` template, ≤ 1/s per task) patch task rows in place.
- Remaining timers: Laravel-fed Queue Center slices (30 s reconcile) and the books sync poll.

## 5. Lists

- Keyset lists: contract `keyset_page` (request `{cursor, limit}`, response `{items, next_cursor, has_more}`, newest first). One model `core/integrations/pycore/useKeysetPages.ts` (cursor stack: pageIndex, next, previous, reload, patchItems) and one pager `apps/pycore-manager/components/PcCursorPager.tsx`. Used by the queue event page, AI usage panel, orchestration tasks (rows patched from pushes), and the speech/translate/image-search/AI-image/AI-hub histories (first page only in the merged history timeline).
- Recent tasks (`hooks/TaskCenterState.initialSync`): the first pycore keyset page (`getRecentTasks`) merged with the Laravel completed-task archive, which carries the deeper history by its own `cursor_id`.

## 6. Progress, lane state and multi-node view

- `core/contracts/QueueProgress.ts` reads `queue_center_contract.json progress_template` (`total, done, failed, pending, cursor, updated_at`, optional `languages`) and the assist/skipped shapes. One component `components/PcQueueProgress.tsx` renders counts, per-language rows, GPU/CPU assist chip and skipped reasons; it renders only fields pycore supplies.
- Lane state: `lanes.<word_audio|sentence_audio|translation>.{progress, assist, skipped, leases}`; `progress {}` before the first intake is ignored; lane header counts read `progress.done`; `leases` (`AudioLaneLeaseState`: leases, items_leased, last_batch, done_per_hour, claim_in_seconds, pooled) shows one line per lane. Lane switches are optimistic, confirmed by the `lane_state` answer or push, rolled back on failure.
- `components/PcWorkNodesPanel.tsx` (Queue Center overview): every node of Laravel `work_nodes` (`GET /api/work/nodes`), grouped and labelled by compute class (GPU first, then CPU) with lane languages, online dot, leased items/leases, done/h, batch, ETA, heartbeat age, and the lane × language pool (gap, leased, free, reason). Refetch on `work_nodes.changed` revision and after each Mercure reconnect. GPU badge comes from Laravel worker registration (`compute_class`, `gpu_name`); the UI shows lane `assist.device`. Nodes are only GPU or CPU — no platform, notebook or label checks. Codes `NO_CAPABLE_NODE`, `LEASE_LOST` are localized.

## 7. Relay gating

- Route policy: `RelayContract.relayRoutePolicyProfile` / `isRelayRouteDenied` resolve a route against `route_policies` exactly like the relay (exact > prefix > suffix, longest, default profile). In relay mode `requestHttp` rejects a denied route with `PYCORE_DIRECT_ONLY` before any round trip; `hooks/usePcDirectOnly(route)` + `components/PcDirectOnlyNotice.tsx` mark the UI.
- Code Sync is retired and frozen (repositories sync with gitsync): `pcPages.PcCodeSyncPage` shows only a localized retired notice (`common.codeSyncRetired*`); nothing polls.
- Direct-only surfaces: `ui/code_sync/*`, folder/file pickers (`pick_path`), open file/folder/output actions (`ui/audio_orch/open_output`, `ui/capability_status/open_directory`), orchestration background import, Laravel endpoint bind (`assist/bind_laravel_endpoint`).
- Host capability: `RelayCapabilities.isHeadlessRelayDevice` = device without `host_capabilities[0]` (`desktop_session`). `hooks/usePcDesktopHost` replaces the Terminal and Window automation pages with a notice for a headless relay target.

## 8. Terminal page and machine send

- `pages/PcTerminalPage.tsx`: windows grid and operation panel first (no top/bottom page padding), then notices, page header, status, desktop integration, machine send panel. One topic `terminal.changed` in direct and relay mode; `ui/terminal/viewer_demand` lease renewed at half of `terminal_viewer_demand_lease_seconds` and when online windows change; full snapshot only on first load, reconnect, oversized push or changed log count; timer only while the link is down.
- Image attach: `components/usePcTerminalImages.ts` + `PcTerminalInputBox.tsx` (paste, drop, picker, per-image progress, one upload flight per image). `terminalImageUpload` (`ui/terminal/image/upload`, multipart `file`, `window_id`) — pycore saves the file and returns `display_path`; send uploads first, reads the latest draft, appends each `display_path` as text separated by spaces, strips `[Image #N]` placeholders; any failed image blocks the send; a failed send keeps only the draft text. Image bytes never reach terminal input. Errors `terminal.images.errors.*`.
- Machine send (`core/integrations/pycore/PycoreApiMachineSend.ts`, `components/machine-send/{PcMachineSendPanel,usePcMachineSend,machineSendShortcut}`): routes `machineSendFile` (`file` repeated + `open`), `machineSendText`, `machineSendClipboard` (pycore backs up its clipboard first), `machineSendClipboardHistory`/`Delete`/`Clear`. Clipboard shortcut default Alt+Shift+V (must hold Ctrl/Alt/Meta, physical key match), storage key `PYCORE_MACHINE_SEND_SHORTCUT`. Relay: one body ≤ relay `request_body_bytes` (64 MiB); larger files blocked (`machineSend.errors.relay_too_large`), others grouped under the cap. Error codes → `machineSend.errors.*`.

## 9. Compute scheduler

- `ComputeAvailability`: per-path state with hysteresis (up after 0.5 s, down after 3 s) for `pycore`, `laravel`, `direct`, `relay`. Routing: pycore up → direct; else Laravel (202 `pycore_task` queued / `pycore_unavailable`); both down → pending in the IndexedDB journal (`core/persistence/IdbKeyValueStore.ts`). `job.id` = `client_task_id` / `Idempotency-Key` on every path; failover keeps the key; shadow resubmission after 15 s, first result wins. Concurrency pycore 2 / Laravel 4, `Backoff` 1-30 s, `maxAttempts` 6. `ComputeKind.pycoreRequired` sends Laravel-only work straight to Laravel.
- Journal: one record per job (state, attempts, path, shadow, Laravel ref, error); a reload turns `submitted-pycore` back to `pending` with the same key and resumes polling `submitted-laravel` (`GET /api/task/{id}/status`, `scheduler.wake(id)` on events); finished jobs are kept 24 h. Failures keep `error_code` / `error_params` (pycore `model_*` codes, Laravel `AI_PAID_MODEL_REFUSED`, `AI_FREE_IMAGE_MODEL_UNAVAILABLE`); `model_input_*` and `model_unknown_engine` are not retried. Large OCR bodies go through `ProgressUpload`. The relay `progress` frame's `done/total` feeds `ComputeRunContext.progress`; heartbeat-only frames update nothing.

## 10. i18n

- No hardcoded user-visible strings; every key exists in every locale file of its app (en and zh minimum; wordnew also ja/ko). `core/i18n/UiI18n.ts UI_SUPPORTED_LANGUAGES` (`en`, `zh`) drives i18next `supportedLngs` and the shell language list. pycore-manager: `pc-locales` en/zh at full parity. Error and reason codes map to localized `errorCodes` with params (`pcErrorCodeMessage`, `pcFailureMessage`).

## 11. Verification

- `bun run lint` (or `node node_modules/typescript/bin/tsc --noEmit`) in `poly_apps/pycore_laravel_wordnew_ui`: 0 errors.
- Contract drift: route/endpoint/topic changes start in `config/*_contract.json`; `tsc` fails on a removed pycore route key.
