2. DATA STORAGE LOCATIONS
--------------------------

2.1 Laravel Database (JSON-based)
- File: /www/wwwroot/laravel_db/servermanager/domains/domains.json
- Format: JSON with domain configurations
- Contains:
  - domain name
  - type (html, laravel, poly)
  - www_dir (document root)
  - php_version
  - ssl_enabled
  - nginx_enabled
  - nginx_config_file path
  - timestamps
  - status

2.2 Nginx Configuration Files
- Available sites: /www/nginxconfig/sites-available/
- Enabled sites: /www/nginxconfig/sites-enabled/
- Files: One file per domain (symlinked from available to enabled)

3. DATA FLOW
------------

3.1 Adding Websites via 130_setup_domains.sh
Step 1: Read domain list from encrypted secrets
Step 2: For each domain:
  - Call: php artisan servermanager:certificate add <domain> --prefixes=<prefixes> --provider=dnspod
  - Call: php artisan servermanager:website add <domain> --type=<type> --ssl=auto --php-version=<version>
Step 3: Laravel processes:
  - Store domain config in /www/wwwroot/laravel_db/servermanager/domains/domains.json
  - Generate nginx config in /www/nginxconfig/sites-available/<domain>
  - Create symlink in /www/nginxconfig/sites-enabled/<domain>
  - Create document root directory
  - Create index.html (for html type)

3.2 Viewing Websites via nginx_manager.sh
Step 1: User selects "Service Manager" from dd.sh
Step 2: User selects Nginx from service_manager.sh
Step 3: nginx_manager.sh launches with advanced manager
Step 4: User selects "6) Show All Websites"
Step 5: list_sites function executes:
  - Lists files in /www/nginxconfig/sites-available/
  - Lists symlinks in /www/nginxconfig/sites-enabled/

5. WEBSITE TYPES
----------------

5.1 html
- Static HTML websites
- Document root: /www/wwwroot/<domain>/
- Auto-creates index.html
- Example: local.gm15.com, si.gm15.com

5.2 laravel
- Separate Laravel project per domain
- Document root: /www/wwwroot/<domain>/public/
- Requires Laravel installation in domain directory

5.3 poly
- Shared Laravel project (poly_apps/laravel_main)
- Document root: /www/programing/core_node/poly_apps/laravel_main/public/
- Multiple domains point to same Laravel app
- Example: local.api.gm15.com, si.api.gm15.com, api.gm15.com

6. PATH CONFIGURATION
---------------------

6.1 Environment-Aware Paths (via ServerManagerV1PathResolver)
