# 验证输出图片信息面板

## 功能说明

在验证输出的图片顶部添加了一个信息面板，显示重要的验证元数据。

## 面板内容

### 1. 标题
```
VALIDATION RESULTS
```
- 颜色: 黄色（醒目）
- 字体大小: 较大

### 2. 使用的模型
```
Models: unified_model_20251017_055332
```
- 显示所有使用的模型名称
- 多个模型用逗号分隔
- 颜色: 白色

### 3. 检测用时
```
Detection Time: 0.234s
```
- 显示纯检测时间（不包括图片加载和保存）
- 精确到毫秒（3位小数）
- 颜色: 白色

### 4. 置信度阈值
```
Confidence Threshold: 0.25
```
- 显示使用的置信度阈值
- 2位小数
- 颜色: 白色

### 5. 检测总数
```
Total Detections: 2
```
- 显示检测到的目标总数
- 颜色: 黄色（醒目）

## 面板样式

- **背景颜色**: 深灰色 (40, 40, 40)
- **边框**: 灰色边框
- **面板高度**: 120 像素
- **文字颜色**:
  - 标题和重要信息: 黄色
  - 普通信息: 白色
- **字体**: HERSHEY_SIMPLEX
- **位置**: 图片顶部

## 检测框调整

由于添加了顶部面板，所有检测框的Y坐标会自动偏移120像素，确保检测框位置正确对应原始图片中的目标。

## 示例输出

```
┌────────────────────────────────────────────────────────┐
│ VALIDATION RESULTS                                      │
│ Models: unified_model_20251017_055332                   │
│ Detection Time: 0.234s                                  │
│ Confidence Threshold: 0.25                              │
│ Total Detections: 2                                     │
├────────────────────────────────────────────────────────┤
│                                                         │
│  原始图片内容                                              │
│  [检测框1]                                                │
│  [检测框2]                                                │
│                                                         │
└────────────────────────────────────────────────────────┘
```

## 优势

1. **一目了然**: 无需查看命令行输出，图片本身就包含所有关键信息
2. **便于对比**: 多次验证时可以直接对比不同模型、参数的效果
3. **记录完整**: 图片文件就是完整的验证记录
4. **分享友好**: 分享图片时，别人也能看到验证的详细信息

## 技术实现

### 1. 创建信息面板
```python
panel_height = 120
panel = np.zeros((panel_height, img_w, 3), dtype=np.uint8)
panel[:] = (40, 40, 40)  # Dark gray background
```

### 2. 添加文字信息
```python
cv2.putText(panel, "VALIDATION RESULTS", (10, 25),
            cv2.FONT_HERSHEY_SIMPLEX, 0.7, (0, 255, 255), 2)
cv2.putText(panel, f"Models: {', '.join(model_names)}", (10, 50),
            cv2.FONT_HERSHEY_SIMPLEX, 0.5, (255, 255, 255), 1)
# ... 其他信息
```

### 3. 合并面板和图片
```python
output = np.vstack([panel, output])
```

### 4. 调整检测框位置
```python
y_offset = y + panel_height
cv2.rectangle(output, (x, y_offset), (x+w, y_offset+h), color, 2)
```

## 注意事项

1. 面板高度固定为120像素，适合显示5行信息
2. 如果模型名称过长，可能会超出图片宽度（后续可以优化为自动换行）
3. 面板始终位于图片顶部，不会遮挡原始图片内容
