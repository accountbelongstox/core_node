# 🖱️ 鼠标坐标监控工具

## 功能说明

实时显示鼠标坐标的调试工具，支持：
- **屏幕坐标** - 鼠标在整个屏幕上的绝对坐标
- **游戏坐标** - 鼠标相对于游戏窗口的坐标
- **标准坐标** - 缩放到标准分辨率(1763x1126)的坐标
- **窗口信息** - 游戏窗口的偏移、大小和模式

  - 方法1: 按 `Esc` 键

### 坐标说明

#### 1. 屏幕坐标（蓝色）
- 鼠标在整个屏幕上的绝对位置
- 左上角为 (0, 0)
- 用于系统级操作，如 `pyautogui.click(x, y)`

#### 2. 游戏坐标（绿色）
- 鼠标相对于游戏窗口的位置
- 游戏窗口左上角为 (0, 0)
- **包含窗口边框和标题栏**
- 如果鼠标在窗口外，显示"(窗口外)"

#### 3. 标准坐标（橙色）
- 缩放到标准分辨率 1763x1126 的坐标
- **不包含边框和标题栏**（纯客户区坐标）
- 用于与UI设计稿对比
- 窗口模式下会自动缩放
- 全屏模式下与游戏坐标相同

#### 4. 窗口信息（灰色）
- **偏移**: 游戏窗口在屏幕上的位置
- **大小**: 游戏窗口的宽度和高度（包含边框）
- **模式**: 窗口/全屏

## 使用场景

### 场景1: 调试点击坐标
当你需要知道某个UI元素的精确坐标时：
1. 运行工具
2. 将鼠标移动到目标UI元素上
3. 记录**标准坐标**用于代码中

### 场景2: 验证坐标转换
验证 `calculate_screen_coordinate()` 函数是否正确：
1. 在代码中设置一个标准坐标，如 (100, 200)
2. 计算得到屏幕坐标
3. 将鼠标移到该屏幕坐标位置
4. 检查工具显示的标准坐标是否为 (100, 200)

### 场景3: 检查窗口边框
验证窗口边框常量是否正确：
1. 将鼠标移到窗口边框上
2. 查看游戏坐标和标准坐标的差异
3. 验证边框宽度是否符合常量定义

## 技术细节

### 坐标转换公式

#### 屏幕坐标 → 游戏坐标
```python
game_x = screen_x - window_offset_x
game_y = screen_y - window_offset_y
```

#### 游戏坐标 → 标准坐标（窗口模式）
```python
# 1. 移除边框得到客户区坐标
client_x = game_x - WINDOW_BORDER_LEFT
client_y = game_y - TITLE_BAR_HEIGHT

# 2. 计算客户区大小
client_width = game_window_w - WINDOW_BORDER_LEFT - WINDOW_BORDER_RIGHT
client_height = game_window_h - TITLE_BAR_HEIGHT - WINDOW_BORDER_BOTTOM

# 3. 缩放到标准分辨率
standard_x = client_x * 1763 / client_width
standard_y = client_y * 1126 / client_height
```

### 使用的常量
```python
WINDOW_BORDER_LEFT = 9      # 左边框宽度
WINDOW_BORDER_RIGHT = 7     # 右边框宽度
TITLE_BAR_HEIGHT = 31       # 标题栏高度
WINDOW_BORDER_BOTTOM = 8    # 底边框宽度
D4_STANDARD_RESOLUTION_WIDTH = 1763   # 标准宽度
D4_STANDARD_RESOLUTION_HEIGHT = 1126  # 标准高度
```

## 故障排查

### 问题1: 窗口信息显示"未检测到游戏窗口"
**原因**: 游戏未运行或未调用 `get_d4_interface_data().update_sizes()`

**解决**:
1. 确保游戏正在运行
2. 先运行主程序采集一次窗口数据
3. 再启动坐标监控工具

### 问题2: 标准坐标显示"N/A"
**原因**: 鼠标在游戏窗口外或边框区域

**解决**: 将鼠标移到游戏窗口的客户区内

### 问题3: 工具无法启动
**原因**: 缺少依赖库

**解决**:
```bash
pip install pyautogui tkinter
```
