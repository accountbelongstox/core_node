  I've analyzed the language inconsistency issue in the d3-check UI. Here's what I

  Root Cause

  The language dropdown shows "zh" (Chinese) while the entire UI displays in English.
  This is happening because:

  1. template_config.json:7 - "current_language": "en" is set to English
  2. i18n_base.json:3 - "default_language": "zh" is set to Chinese
  3. Language combobox displays raw language code instead of a user-friendly name

  1. Initialization mismatch:
    - i18n_manager loads from template_config.json and sets language to "en"
    - UI displays in English correctly

    - The combobox shows the raw code "zh" or "en" instead of "中文" or "English"
  2. Configuration priority:
    - i18n_manager.py:272-289 loads language from template_config.json
    - This overrides the default from i18n_base.json
    - Current value is "en", so UI is in English

  def _create_language_menu(self, parent):
      """Create language selection menu"""
      # Language label
      self.lang_label = tk.Label(
          parent,
          text=i18n_manager.get_ui_text("main_window.language") + ":",
          font=('Arial', 9),
          fg=UITheme.get_color('test_high_contrast'),
          bg=UITheme.get_color('bg_primary')
      )
      self.lang_label.pack(side=tk.LEFT, padx=(0, 5))

      # Language display mapping
      lang_display = {"zh": "中文", "en": "English"}
      current_lang = i18n_manager.get_current_language()

      # Create combobox with display names
      self.language_var = tk.StringVar(value=lang_display.get(current_lang,
  current_lang))
      self.language_combo = ttk.Combobox(
          parent,
          textvariable=self.language_var,
          values=list(lang_display.values()),
          width=8,
          state='readonly'
      )
      self.language_combo.pack(side=tk.LEFT, padx=(0, 10))

      # Custom binding for language change
      def on_language_change(event):
          display_value = self.language_var.get()
          # Reverse mapping: display name -> code
          lang_code = {v: k for k, v in lang_display.items()}.get(display_value)
          if lang_code:
              ConfigBinding.set_config_value("ui_settings.current_language", lang_code)

      self.language_combo.bind('<<ComboboxSelected>>', on_language_change)
