● 测试正在运行。现在让我总结新的解决思路：

  ✅ 新思路：configure() 设置默认，map() 仅覆盖特定状态

  问题根源重新分析

  之前的错误理解：
  # ❌ 错误思路：在 map() 中设置所有状态包括默认
  style.map('Tab',
           background=[('selected', '#color1'),
                     ('active', '#color2'),
                     ('#default_color',)])  # 试图设置默认状态

  实际上：当 map() 中包含默认状态元组时，可能会与 configure() 冲突！

  正确的 ttk 样式设置模式

  # ✅ 正确：分离默认和覆盖
  # Step 1: configure() 设置 BASE/DEFAULT 颜色（用于未选中Tab）
  style.configure('TNotebook.Tab',
                 background='#f0f0f0',    # 这是默认/未选中状态
                 foreground='#1a1a1a')

  # Step 2: map() 仅设置特定状态的覆盖（不包含默认元组）
  style.map('TNotebook.Tab',
           background=[('selected', '#16213e'),   # 覆盖：选中时
                     ('active', '#0f3460')],      # 覆盖：悬停时
           foreground=[('selected', '#e0e0e0'),
                     ('active', '#e0e0e0')])

  工作原理

  1. 未选中Tab：使用 configure() 中的 BASE 颜色
  2. 选中Tab：map() 的 ('selected', color) 覆盖 BASE
  3. 悬停Tab：map() 的 ('active', color) 覆盖 BASE

  这样清晰分离了默认外观和状态覆盖，避免冲突！

  - 选中Tab: 深蓝色背景 (#16213e) + 浅色文字 (#e0e0e0) ✅
