Matrix Application - Python vs Node.js Implementation Comparison
===============================================================

Launch Command:
--------------
Python:  python pycore/pylauncher/__init__.py app=matrix
Node.js: node main.js app=matrix


Implementation Architecture:
---------------------------

Python (pyapps/matrix/matrix_main.py):
--------------------------------------
from pycore.pyutils.native_ui import NativeUIConfig, launch_native_app

launch_native_app(
    config=NativeUIConfig(
        app_name="Matrix Cloud",
        frontend=FrontendConfig(
            enabled=True,
            framework="vite",
            app_dir=PROJECT_ROOT / "poly_apps" / "matrixui",
            mode="dev",  # Hot reload
            port=38007,
            block_until_ready=True
        ),
        rpc_v2=RpcConfig(
            port=48000,
            init_callback=rpc_init_callback
        ),
        main_entry=matrix_main_entry,
        tray_enabled=True,
        single_instance=True
    )
)


Node.js (apps/matrix/main.js):
------------------------------
const { launchElectronApp } = require('#@ncore/utils/electron');

await launchElectronApp({
    appName: 'Matrix Cloud',
    singleInstance: true,
    singleInstancePort: 58099,

    frontend: {
        enabled: true,
        framework: 'vite',
        appDir: config.FRONTEND_DIR,  // poly_apps/matrixui
        mode: 'dev',  // Hot reload
        port: 38007,
        host: '0.0.0.0',
        autoInstall: true,
        blockUntilReady: true,
        packageManager: 'pnpm'
    },

    mainWindow: {
        width: 1400,
        height: 900,
        minWidth: 1200,
        minHeight: 700,
        title: 'Matrix Cloud'
    },

    systemTray: {
        enabled: true,
        title: 'Matrix Cloud',
        tooltip: 'Matrix Cloud - Android Device Manager'
    },

    onFrontendReady: async (frontend) => {
        await rpcInitCallback();  // Initialize RPC on port 48000
    },

    onReady: async (manager) => {
        await matrixMainEntry();  // App fully initialized
    }
});

Service Starter Integration:
----------------------------

Python (pycore/pythreadpool/service_starters.py):
--------------------------------------------------
SERVICE_STARTERS['electron_ui'] = start_electron_ui

def start_electron_ui(config):
    from pycore.pyutils.native_ui import launch_native_app
    return launch_native_app(config)


Node.js (ncore/thread_pool/starters.js):
-----------------------------------------
SERVICE_STARTERS['electron_ui'] = startElectronUI

function startElectronUI(config) {
    const { launchElectronApp } = require('#@ncore/utils/electron');
    launchElectronApp(config).then((launchResult) => {
        // Register shutdown handler
    });
    return { launching: true };
}


Summary:
--------
The Node.js implementation successfully replicates all functionality from the
Python version while following Electron and ncore standards. The key difference
is using Electron instead of PySide6 for the native UI, while maintaining the
same architecture, features, and user experience.

Both versions:
- Use the SAME frontend (poly_apps/matrixui)
- Auto-start the Vite dev server
- Provide hot reload during development
- Use the same ports (38007 for frontend, 48000 for backend)
- Enforce single instance
- Provide system tray integration
- Support cross-platform operation (Linux/Windows/macOS)
