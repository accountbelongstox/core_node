4. Configuration
===========================================

File: apps/ai_translator_app/config/index.js

RPC Configuration:
{
    rpcConfig: {
        enabled: true,              // Enable/disable RPC
        port: 8090,                 // RPC HTTP port
        host: '0.0.0.0',            // Listen address
        enableWebSocket: true,      // Enable WebSocket RPC
        wsPort: 8091                // WebSocket port (if separate)
    }
}

To disable RPC, set enabled: false in rpcConfig.

5. Usage Examples
===========================================

Starting the Application:
--------------------------
const app = require('./apps/ai_translator_app/main.js');
await app.start();

The application will automatically start:
1. Translation Service
2. Web Interface (port 3000)
3. RPC Interface (port 8090)

RPC Client Usage (JavaScript/TypeScript):
------------------------------------------
const rpc = require('#@ncore/utils/rpc');

const client = rpc.createClient('http://localhost:8090/rpc', {
    clientId: 'translator-client',
    httpFallback: true
});

// Translate text
const result = await client.call('AITranslator.translate', {
    text: 'Hello World',
    sourceLanguage: 'en',
    targetLanguage: 'zh-CN'
});

// Get status
const status = await client.call('AITranslator.getStatus', {});

// Restart service
const restartResult = await client.call('AITranslator.restart', {});

RPC Client Usage (Nuxt/Frontend):
----------------------------------
import { $fetch } from 'ohmyfetch';

// Using HTTP RPC
const result = await $fetch('http://localhost:8090/rpc', {
    method: 'POST',
    body: {
        route: 'AITranslator.translate',
        params: {
            text: 'Hello World',
            targetLanguage: 'zh-CN'
        }
    }
});

12. Security Notes
===========================================

Current Configuration:
- RPC auth disabled by default (matching web interface)
- Runs on localhost (0.0.0.0)
- No HTTPS by default

Production Recommendations:
1. Enable RPC authentication:
   ```javascript
   {
       rpcConfig: {
           auth: {
               enabled: true,
               secret: 'your-secret-key'
           }
       }
   }
   ```

2. Use reverse proxy (nginx) for HTTPS
3. Configure firewall rules
4. Enable rate limiting

13. Troubleshooting
===========================================

Issue: RPC port already in use
Solution: Change rpcConfig.port in config/index.js

Issue: RPC not starting
Solution: Check rpcConfig.enabled = true

Issue: Cannot connect to RPC
Solution: Verify firewall allows port 8090

Issue: WebSocket connection fails
Solution: Enable rpcConfig.enableWebSocket
