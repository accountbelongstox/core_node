## 🚀 Migration Guide for External Code

If you have external code importing from the old path, update as follows:

### Before (Old - Will Fail)
```python

from pycore.pyutils.stream import VideoStreamHandler
```

### After (New - Correct)
```python
from pycore.pyutils.video_stream import H264Decoder

```
