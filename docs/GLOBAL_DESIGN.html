全局业务战略规范方案

一、 业务板块详细介绍

1. 码市（CodeMart）：程序员流量的唯一抓手

定位： 专属程序员的搬砖式兼职平台。

核心逻辑： 程序员群体普遍适配“任务导向型”劳动。由于思维壁垒，即便告知其极具前景的商业生意，他们也难以理解。他们最感兴趣的是“所见即所得”的搬砖式劳动。

战略必要性： 码市是吸引程序员的唯一有效方案。通过常规渠道很难打动程序员，只有建立一个专门的“搬砖网站”，才能精准聚集人才。没有这个平台，后续的技术储备将无从谈起。

2. AI 转发平台：技术钩子与情报中心

利用国内外 AI 巨大代差，通过提供顶级 API 转发，吸引高端人才。同时后端建立审计机制，获取竞争对手的开发动态，实现情报监听。

3. 多聊盘口：现金流变现业务

作为核心盈利点，直接产生收益。若没有“码市”的人才池和“AI平台”的情报支持，该业务将因技术对抗而陷入被动掣肘。

4. 群控系统：品牌力与规模化扩张

建立自动化壁垒。该业务需投入大量技术，必须依赖码市长期积累的低廉劳动力进行模块化开发，方可保证进度。

二、 业务关联原则

关联链条： AI平台(获客/情报) → 码市(人才留存) → 多聊(现金流支撑) → 群控(规模化变现)
  • 引流原则： 程序员只适配在搬砖网站上被吸引。
  • 支撑原则： 前期业务（码市/AI）为后期重型开发（群控）提供组件库和廉价人力。
  • 反馈原则： 现金流业务产生的资金，优先回馈老挝实体运营和码市报酬发放。

三、 原始设想路线图

  • 实际上： 我们的开发资金远远不足以支持全部开发。
  • 第一步（生存）： 老挝旅客/实体业务，保底每月几千生活收益。
  • 第二步（圈人）： 扩展码市，通过“搬砖任务”招揽源源不断的低廉人才。
  • 第三步（后期）： 结合 AI 情报与码市劳动力，全力推进群控及其他高壁垒业务。

四、 实现方案与当前规范

1. 分层体系： 老挝核心层（拆需求/管钱）→ 平台中间层（分任务/抽情报）→ 执行层（搬砖程序员）。

2. 情报转化： 监控 AI 平台异常流量，发现赚钱生意的雏形，立即在码市发标进行仿制。

3. 推荐规范：

  • 禁止与执行层讨论商业远景，仅讨论技术交付。
  • 所有代码必须进行标准化封装，确保不同人写的代码能拼装。
  • 资金与服务器保持离岸，老挝作为物理避风港。
