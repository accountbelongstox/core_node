| SPW-001 | Desktop icon organizer: files desktop shortcuts into category folders under `.desktopIcons\<Category>` linked on the desktop. The category comes from ApplicationsList packages (key, Name, DesktopShortcuts Name, Exec) first, then the category keyword lists. ASCII keywords match whole token runs (camelCase and digit splits); keywords of 3 chars or fewer must start the name; CJK keywords match as substrings; the highest score wins, ties go to the package, then to category order. Keep-on-desktop list (`Window Launcher`). Broken and hidden shortcuts stay. Refile moves a filed shortcut only when nothing supports its current folder, and never over an existing name. Browser launchers whose name has a `chrome` or `edge` token are copied into Browsers and stay on the desktop (keep-copy rule). Same destination: the plan keeps at most one differing item per `<Category>/<name>`, the newest wins, and ties go to scan order (user desktop, then all-users desktop, then category folders). Identical items follow the winner; the others are reported as conflicts and stay put. An existing different file is displaced only by a strictly newer item (mtime); otherwise the item is a conflict. An identical desktop duplicate moves to the state dir (move mode) or is left alone (copy mode). Preview uses the same placement decision as the real run and says "Nothing to move" when the run would change nothing. Moves only, no deletes; a second run changes nothing.
