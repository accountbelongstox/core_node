Ruling R5 (`docs_fix/TASK_20260928_TEAM_RESUME_ROSTER.md`, set by codemart-lead, 2026-09-28) makes codemart-laravel the standing writer for `poly_apps/laravel_main/lang/{en,zh_CN}/codemart.php`. Before this, the lang file's writer was assigned per-round by codemart-lead/claude lead (see G1 report cross-scope notes, which routed a zh_CN glossary pass as "next writer of the file, as the claude lead assigns").

**Why:** avoids re-litigating who owns the shared codemart lang files every round; codemart-laravel already owns the CodeMartV1 PHP that defines the lang keys, so it's the natural single writer.

**How to apply:** any future zh_CN/en glossary or key work on `lang/{en,zh_CN}/codemart.php` is mine to do directly, without waiting for a per-task file-list assignment — but still only when codemart-lead dispatches the work (a standing-writer ruling is not a standing green light to start unprompted). As of 2026-09-28 the queued zh glossary pass (审核员/您/提案/KYC per PAGE_POLISH §3) is on hold until codemart-lead dispatches it with the next round.
