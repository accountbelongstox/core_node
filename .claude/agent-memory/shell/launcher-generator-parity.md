Generated launchers: claude1-5 (v4), codex1-2, kimi1-2, ark1-7 (+ piark1-7, which copy the hand-written piyolo.sh/.ps1 templates), ssh1-3. Hand-written: claudevolc/zhipu/alibaba/deepseek, piyolo, kimiyolo, *yolo, claudeteam*. openai1.sh is an orphan (no config has an `openai` prefix).

Committed outputs can lag the generator (on 2026-09-27 claude/codex/kimi lacked the shared ai_cli_provision section). Before regenerating, diff generator output against the files. How: import managers.script_manager with sys.path at special_software_env_manager, monkeypatch its module-level get_winenvs_dir/get_linuxenvs_dir to a scratch dir and ScriptManager._ensure_linux_symlink to a no-op, call generate_v4_launcher_for_config / generate_scripts_for_config per existing file number, then write back with _write_script_file. The generator also emits ark3-7.sh, which do not exist in the repo: do not create them.

**Why:** the team lead requires "fix the generator, regenerate, never hand-edit generated files" (shell-7, B9).

**How to apply:** secret display goes through utils/secret_display.is_secret_name plus the shared ai_cli_mask_secret / Get-AiCliMaskedSecret. See [[secret-password-runner]].
