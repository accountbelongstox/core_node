===========================================
RPC 框架快速开始指南
===========================================

完整功能的RPC框架，支持子应用集成

基础使用：
=========

1. 启动服务器
   ```javascript
   const rpc = require('#@ncore/utils/rpc');

   const server = rpc.createExpressServer({ HTTP_PORT: 8080 });
   const rpcServer = rpc.createHttpServer(server.getApp());

   rpcServer.route('hello', async (params) => {
       return { message: `Hello, ${params.name}!` };
   });

   rpcServer.start();
   await server.start();
   ```

2. 客户端调用
   ```javascript
   const client = rpc.createClient('http://localhost:8080/rpc', {
       clientId: 'my-client',
       httpFallback: true
   });

   const result = await client.call('hello', { name: 'World' });
   console.log(result); // { message: 'Hello, World!' }
   ```

子应用集成：
===========

1. 注册子应用
   ```javascript
   rpc.registerSubApp('UserModule', {
       config: { USER_TIMEOUT: 5000 },
       staticPaths: { '/users': '/path/to/user/static' }
   });
   ```

2. 注册路由
   ```javascript
   rpc.registerRoute('UserModule', 'getUser', async (params, context) => {
       // context.requestId - 请求ID
       // context.appName - 应用名
       const user = await fetchUser(params.userId);
       return { user }; // 结果返回RPC框架统一管理
   });
   ```

3. 客户端调用
   ```javascript
   const result = await client.call('UserModule.getUser', { userId: 123 });
   ```

智能路径解析：
=============

自动检测环境并解析路径：
```javascript
const envInfo = rpc.getEnvironmentInfo();
// { platform: 'win32', isWSL: false, isProduction: false, ... }

const paths = rpc.getDefaultStaticPaths();
// 自动检测的静态路径配置

const staticPath = rpc.resolveStaticPath('wwwroot');
// Windows: D:\www\wwwroot
// WSL: /mnt/d/www/wwwroot
// Linux Prod: /www/wwwroot
```

关键要点：
=========

1. 所有结果由RPC框架统一按requestId管理
2. 子应用只需返回结果，框架自动处理缓存/通知
3. WebSocket失败自动重试3次，然后缓存供HTTP查询
4. 客户端自动选择WebSocket或HTTP，透明切换
5. 静态路径根据环境自动解析（Windows/Linux/WSL）
6. 子应用配置优先级最高，覆盖主配置
