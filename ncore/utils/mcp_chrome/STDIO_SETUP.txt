# MCP Chrome STDIO Server Setup Guide

## Overview
The STDIO server acts as a proxy between Claude Desktop (STDIO) and ncore HTTP MCP server.

## Architecture
```
Claude Desktop (STDIO)
        ↓
mcp-server-stdio.js (STDIO Proxy)
        ↓
ncore HTTP Server (Port 12306)
        ↓
Chrome Extension (Tools)
```

## Configuration for Claude Desktop

### Windows
Edit: `%APPDATA%\Claude\claude_desktop_config.json`

```json
{
  "mcpServers": {
    "chrome-mcp-ncore": {
      "command": "node",
      "args": [
        "D:\\programing\\core_node\\ncore\\utils\\mcp_chrome\\mcp-server-stdio.js"
      ]
    }
  }
}
```

### macOS/Linux
Edit: `~/.config/Claude/claude_desktop_config.json`

```json
{
  "mcpServers": {
    "chrome-mcp-ncore": {
      "command": "node",
      "args": [
        "/path/to/core_node/ncore/utils/mcp_chrome/mcp-server-stdio.js"
      ]
    }
  }
}
```

## Prerequisites

1. **Start ncore HTTP server:**
   ```bash
   node ncore_module_caller.js
   ```

   This will start the HTTP MCP server on port 12306.

2. **Load Chrome Extension:**
   - Open Chrome: `chrome://extensions/`
   - Enable "Developer mode"
   - Click "Load unpacked"
   - Select: `apps/mcp-chrome/app/chrome-extension/.output/chrome-mv3`
   - Click extension icon and "Connect"

3. **Restart Claude Desktop:**
   - Close Claude Desktop completely
   - Reopen Claude Desktop
   - The MCP server will auto-connect

## Configuration File

You can customize the HTTP server URL by editing:
`ncore/utils/mcp_chrome/stdio-config.json`

```json
{
  "url": "http://127.0.0.1:12306/mcp"
}
```

## Troubleshooting

### Error: Cannot connect to HTTP MCP server

**Solution:**
1. Verify ncore is running: `node ncore_module_caller.js`
2. Check port 12306 is open: `netstat -ano | findstr ":12306"` (Windows)
3. Check HTTP server logs in ncore output

### Error: No tools available

**Solution:**
1. Make sure Chrome Extension is loaded
2. Click extension icon and verify "Connected" status
3. Restart Claude Desktop

### Debugging

Check Claude Desktop logs:
- Windows: `%APPDATA%\Claude\logs\`
- macOS: `~/Library/Logs/Claude/`
- Linux: `~/.config/Claude/logs/`

## Testing

Test STDIO server manually:
```bash
node D:\programing\core_node\ncore\utils\mcp_chrome\mcp-server-stdio.js
```

Expected output:
```
[MCP Chrome STDIO] Starting STDIO MCP server...
[MCP Chrome STDIO] Server started successfully
[MCP Chrome STDIO] Proxying requests to HTTP server at: http://127.0.0.1:12306/mcp
[MCP Chrome STDIO] Waiting for requests from Claude Desktop...
```
