Azure Translator Setup Guide for stream_translator
==================================================

STEP 1: Get Azure Translator Credentials
-----------------------------------------

1. Go to Azure Portal: https://portal.azure.com

2. Create Translator Resource:
   - Search for "Translator" or "Cognitive Services"
   - Click "Create"
   - Fill in:
     * Subscription: Azure subscription 1 (or your subscription)
     * Resource Group: azureservice (or create new)
     * Region: Choose your preferred region (e.g., East US, West Europe)
     * Name: Your unique translator name
     * Pricing Tier: F0 (Free, 2M chars/month) or S1 (Standard)
   - Click "Review + Create"
   - Wait for deployment to complete

3. Get API Key and Endpoint:
   - Navigate to your Translator resource
   - Click "Keys and Endpoint" in left menu
   - You will see:
     * KEY 1: Copy this
     * KEY 2: Backup key
     * Location/Region: Copy this (e.g., "eastus", "global")
     * Endpoint: Should be api.cognitive.microsofttranslator.com

STEP 2: Configure Environment Variables
----------------------------------------

Windows PowerShell:
-------------------
$env:AZURE_TRANSLATOR_ENDPOINT="api.cognitive.microsofttranslator.com"
$env:AZURE_TRANSLATOR_KEY="<paste-your-key-here>"
$env:AZURE_TRANSLATOR_REGION="<your-region>"

Linux/Mac Bash:
---------------
export AZURE_TRANSLATOR_ENDPOINT="api.cognitive.microsofttranslator.com"
export AZURE_TRANSLATOR_KEY="<paste-your-key-here>"
export AZURE_TRANSLATOR_REGION="<your-region>"

Or add to your Node.js config file (recommended for production):
-----------------------------------------------------------------
Edit your app's config file to include:

{
  "stream_translator": {
    "azure": {
      "endpoint": "api.cognitive.microsofttranslator.com",
      "apiKey": "<your-key>",
      "region": "<your-region>",
      "defaultTargetLanguage": "zh-Hans"
    }
  }
}

STEP 3: Test Configuration
---------------------------

Run this command to check if configuration is correct:

node -e "require('#@ncore/utils/stream_translator').checkConfig()"

Or in your code:

const translator = require('#@ncore/utils/stream_translator');
translator.printConfigSummary();

STEP 4: Basic Usage
--------------------

const translator = require('#@ncore/utils/stream_translator');

// Check configuration first
if (!translator.checkConfig()) {
    translator.printSetupInstructions();
    process.exit(1);
}

// Start translation
const sessionId = 'my-session';
translator.appendData(sessionId, 'Hello world\n');
translator.appendData(sessionId, 'This is a test\n');
translator.flushSession(sessionId);

// Wait a bit for translation
setTimeout(() => {
    const result = translator.getFullText(sessionId);
    console.log(result);
}, 2000);

SUPPORTED LANGUAGES
-------------------
To see all supported languages:

translator.printSupportedLanguages();

Common language codes:
- zh-Hans: Simplified Chinese
- zh-Hant: Traditional Chinese
- en: English
- ja: Japanese
- ko: Korean
- fr: French
- de: German
- es: Spanish

PRICING INFORMATION
-------------------
Free Tier (F0):
- 2 million characters per month
- Perfect for testing and small projects

Standard Tier (S1):
- Pay as you go
- $10 per million characters
- Best for production use

TROUBLESHOOTING
---------------

Issue: "Azure Translator API credentials not configured"
Solution: Make sure you set the environment variables or config file correctly

Issue: "Translation API error: 401"
Solution: Check your API key is correct

Issue: "Translation API error: 403"
Solution: Check your region is correct, some regions may have restrictions

Issue: "Translation API error: 429"
Solution: You've exceeded the rate limit. The plugin will auto-retry.
         Consider upgrading to S1 tier or reducing request frequency.

Issue: Translations not appearing
Solution: Make sure to call flushSession() after appending data
         Allow some time for async translation to complete
