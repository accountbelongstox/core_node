Tray Icon Configuration
======================

To enable the system tray icon for Ncore Module Caller, place a PNG image
file named "tray-icon.png" in this directory.

Recommended specifications:
- Format: PNG
- Size: 16x16 or 32x32 pixels (for best display on Windows)
- Transparency: Supported
- Name: tray-icon.png

If no icon is provided, the application will run without a tray icon.

You can create or download an icon and save it as:
D:\programing\core_node\ncore\assets\tray-icon.png
