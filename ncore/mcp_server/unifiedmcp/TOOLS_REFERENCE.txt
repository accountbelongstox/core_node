1. get_file_info
   Description: Extract file info with OCR/document parsing
                Supports: images (PNG, JPG, etc.), PDFs, documents (DOCX, etc.)
   Sync: false (async - ACK mechanism due to OCR processing time)

   Parameters:
     - file_path (string, required): Path to the file to analyze
     - use_cache (boolean, optional, default: true): Use cached results if available
     - include_pixel_matrix (boolean, optional, default: false): Include pixel matrix data for images
     - ocr_model_type (string, optional, default: 'general'): OCR model type (general, dense, etc.)
     - num_colors (number, optional, default: 10): Number of dominant colors to extract from images
     - extract_images (boolean, optional, default: true): Extract images from documents
     - extract_tables (boolean, optional, default: true): Extract tables from documents
     - extract_hyperlinks (boolean, optional, default: true): Extract hyperlinks from documents

   Returns:
     - success (boolean): Operation success status
     - backend_id (string): Backend identifier
     - file_path (string): Path to analyzed file
     - file_type (string): Detected file type
     - ocr_text (string): Extracted text via OCR
     - color_analysis (object): Dominant colors and statistics
     - document_metadata (object): Document properties and metadata
     - images (array): Extracted images from document
     - tables (array): Extracted tables from document
     - hyperlinks (array): Extracted hyperlinks from document

   Backend Requirements:
     - OCR engine (cnocr or paddleocr)
     - Document parser (PyMuPDF, python-docx, etc.)
     - Image processing (Pillow)
     - Color analysis capabilities

   Usage Example:
     const result = await backend.getFileInfo({
       file_path: '/path/to/file.pdf',
       extract_images: true,
       extract_tables: true
     });

   - Support for both sync (immediate) and async (ACK mechanism) operations

   - All tools return success/error status
   - Detailed error messages with backend_id for debugging
   - Graceful degradation when backends are unavailable

3. Parameter Validation:
   - Type checking for all parameters
   - Required parameter enforcement
   - Default value application

4. Backend Requirements:
   - Each tool specifies its backend requirements
   - Backend implementation will be added later
   - Support for multiple backend instances

5. Testing:
