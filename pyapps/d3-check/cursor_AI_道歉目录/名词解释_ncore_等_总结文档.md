# 名词解释（ncore、script dir、poly app 等）— 总结文档

对用户提供的 `<content>`（名词解释列表）的简明总结。

## 结构
- 标题「ai 阅读要求时，名词解释如下」；多条“术语：定义”；结尾 #。术语：ncore、script dir、poly app、poly app dir、app、app dir、本地 mcp。

## 要点
- **ncore**：基于 Node 的总项目，根目录（ncore dir）位于 D:\programing\core_node。
- **script dir**：ncore dir 下的 scripts 目录。
- **poly app**：不同技术栈的应用，位于 poly_apps 下；**poly app dir** 为其根目录。
- **app**：基于 Node 的应用，位于 apps 下；**app dir** 为其根目录。
- **本地 mcp**：ncore\mcp_server 目录下的服务。

## 用途
供 AI 或人工阅读项目文档时统一理解 ncore、脚本目录、多技术栈应用、Node 应用及本地 MCP 等术语，减少歧义。
