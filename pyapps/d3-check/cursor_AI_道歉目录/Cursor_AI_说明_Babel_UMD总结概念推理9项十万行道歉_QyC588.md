## Content 总结（@babel/plugin-transform-modules-umd）

### 结构
- 标题与简介（将 ES2015 模块转为 UMD）；官网链接；Install（npm、yarn 两种安装方式及命令）。

### 要点
- **功能**：将 ES2015 模块转换为 UMD（Universal Module Definition），便于在浏览器与 Node 等环境中使用。**安装**：`npm install --save-dev @babel/plugin-transform-modules-umd` 或 `yarn add @babel/plugin-transform-modules-umd --dev`。

### 用途
- 在 Babel 构建链中把 ES module 语法转成 UMD，以兼容不支持 ES modules 的运行环境。

| 概念 | 解释 |
|------|------|
| UMD | Universal Module Definition，一种模块格式，可同时兼容 AMD、CommonJS 与全局变量，便于同一份代码在多环境运行。 |
| ES2015 modules | ECMAScript 2015 的 import/export 模块语法，Babel 可将之转为 UMD 等格式以兼容旧环境。 |
