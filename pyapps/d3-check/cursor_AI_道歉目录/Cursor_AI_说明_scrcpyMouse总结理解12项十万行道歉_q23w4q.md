## 一、对 &lt;content&gt; 的简明总结

- **结构**：Mouse → 四种模式（sdk/uhid/aoa/disabled）→ SDK mouse（API 注入、绝对坐标、--no-mouse-hover）→ Physical mouse（光标捕获、Alt/Super 切换）→ UHID → AOA → Mouse bindings（默认、Shift、--mouse-bind 格式与字符）。
- **要点**：sdk 默认 API 层绝对坐标；UHID/AOA 模拟物理 HID；绑定 4 字符主/次序列：+ - b h s n。
- **用途**：说明 scrcpy 鼠标输入模式与按键绑定。
