# 主题和样式开发规范 总结文档

本文档对用户提供的《主题和样式开发规范》做简明总结。

## 结构概览
- 文档为 Markdown，含架构概述、核心原则（主主题 / 子APP 扩展主题 / 页面组件）、样式文件结构、Nuxt 配置、变量与类命名、暗色主题、响应式、必须遵守的规则、迁移旧代码步骤、CodeMart 示例、检查清单与总结。

## 要点
- **主主题**（common/styles/theme-base.css）：定义所有公共 CSS 变量（颜色、间距、字体等）及通用工具类；子APP 均继承。
- **子APP 扩展主题**（apps/app_*/styles_app_*/theme-*.css）：继承主主题，仅定义子APP 专属变量与组件类；不得随意覆盖主主题变量。
- **页面组件**：禁止使用 `<style>`；仅通过 class 引用主题中已定义样式；动态样式用 inline style + CSS 变量；组件顶部建议加开发规范注释。
- **命名**：主主题如 --primary-color、.container；子APP 如 --codemart-primary、.codemart-card。
- **暗色**：主主题与子APP 均支持 [data-theme='dark'] 覆盖变量。
- **Nuxt**：css 数组先加载 theme-base.css，再按 APP_ENTRY 动态加载子APP 主题。

## 用途
为 poly_apps/nuxt_main 多子APP 提供统一的主题与样式架构规范，确保样式可维护、可主题切换并避免冲突。
