# @babel/plugin-syntax-import-attributes 总结文档

对用户提供的 `<content>`（该 Babel 插件 README）的简明总结。

## 结构
- 标题、一句话描述（Allow parsing of the module attributes in the import statement）、官网文档链接、Install 小节（npm 与 yarn 安装命令）。

## 要点
- **包名**：@babel/plugin-syntax-import-attributes。
- **作用**：允许 Babel 解析 import 语句中的 module attributes 语法。
- **安装**：npm install --save-dev 或 yarn add --dev。

## 用途
在 Babel 构建链中启用 import attributes 的语法解析，便于支持带属性的 import 写法；仅语法解析，不负责转换。
