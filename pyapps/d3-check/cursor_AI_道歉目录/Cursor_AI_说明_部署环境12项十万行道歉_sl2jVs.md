## Content 总结（Deployment and Environment Setup Guide）

- **结构**：文档为部署与环境搭建指南，分四块：1) 初始环境（Windows 用 curl 下载并执行 dd.cmd；Linux Debian 系 apt 安装 dos2unix、chmod 执行 dd.sh）；2) 应用依赖（DocumentOffline 需 iconv-lite、jsdom；Puppeteer 需 puppeteer、puppeteer-extra、stealth 等）；3) 服务管理与调试（VoiceStaticServer 的 systemctl 停服、--client/--server 运行、重启与部署命令）；4) 外部服务与工具（Brave Search API、Cursor 相关链接、Xata 数据库连接与 CLI 使用）。
- **要点**：Windows/Linux 各自一行或少量命令完成环境准备；子应用依赖用 yarn add；服务调试先 stop 再 node main.js --app=VoiceStaticServer；Xata 提供 PostgreSQL/HTTP 端点与 API Key，CLI 需 npm 全局安装与 xata init。
- **用途**：供开发与运维按步骤完成环境准备、依赖安装、服务调试与部署及第三方服务对接。
