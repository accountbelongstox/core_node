## Content 简明总结（Deployment and Environment Setup Guide）

**结构**：§1 初始环境（Windows：curl 下载 dd.cmd 并执行；Linux：apt 安装 dos2unix、dos2unix dd.sh、chmod +x dd.sh）→ §2 应用依赖（DocumentOffline：yarn add iconv-lite jsdom；Puppeteer：yarn add puppeteer 等）→ §3 服务管理与调试（systemctl stop VoiceStaticServer、node main.js --app=VoiceStaticServer --client/--server、--rebuildmaindb、部署与重启命令）→ §4 外部服务（Brave Search API、Cursor 相关仓库、Xata.io 连接信息与 CLI 使用）。  
**要点**：环境以 dd.cmd/dd.sh 初始化；VoiceStaticServer 通过 systemctl 管理，支持 --server/--client；Xata 提供 PostgreSQL/HTTP 端点与 API Key，CLI 安装与 xata init 示例。  
**用途**：core_node 及 VoiceStaticServer 的开发环境与部署操作指南。
