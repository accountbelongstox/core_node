## Content 总结（compareDesc）

### 结构
- 单文件 TypeScript 声明：`import type { DateArg } from "./types.js"`；JSDoc（@name compareDesc、@category、@summary、@description、@param、@returns、@example 两则）；`export declare function compareDesc(dateLeft, dateRight): number`。

### 要点
- **语义**：按时间倒序比较两个日期；若 dateLeft 晚于 dateRight 返回 -1，早于返回 1，相等返回 0；与 compareAsc 相反，常用于 `array.sort(compareDesc)` 得到从新到旧排序。
- **参数**：dateLeft、dateRight 均为 `DateArg<Date> & {}`。
- **示例**：比较 1987-02-11 与 1989-07-10 得 1；对日期数组 sort(compareDesc) 得到倒序。

### 用途
- 为 date-fns 等库提供 compareDesc 的类型声明与文档，供按倒序比较或排序日期时使用。
