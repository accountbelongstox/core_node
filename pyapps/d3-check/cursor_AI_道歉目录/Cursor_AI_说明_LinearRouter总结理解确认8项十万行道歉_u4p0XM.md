## 一、Content 简明总结（LinearRouter）

- **结构**：从 `../../router` 导入类型 `Result`、`Router`；`export declare class LinearRouter<T>` 实现 `Router<T>`；类含属性 `name: string`、方法 `add(method: string, path: string, handler: T): void` 与 `match(method: string, path: string): Result<T>`。
- **要点**：泛型 T 为 handler 类型；add 注册 (method, path) → handler；match 根据 (method, path) 返回 Result<T>；线性路由即按顺序匹配、无前缀树等优化。
- **用途**：作为路由器的线性实现，用于 HTTP 或类似框架中注册与查找 (method, path) 对应的处理函数。
