## Content 总结（CreateHTML / String 增强模块）

- **结构**：require _export、_fails、_defined；正则 quot = /"/g；内部 createHTML(string, tag, attribute, value)；module.exports 向 String 挂载 NAME 方法（exec(createHTML)），并通过 fails() 条件导出。
- **要点**：createHTML 拼出 `<tag [attr="value"]>...</tag>`，value 中 `"` 转 &quot;；仅在原生缺失或行为不符时挂载；符合 ES B.2.3.2.1 CreateHTML 的 polyfill 行为。
- **用途**：为 String 提供 HTML 包装方法（如 anchor、bold 等）的 polyfill。
