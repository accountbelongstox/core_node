## Content 总结（transports 导出模块）

- **结构**：`import { XHR } from "./polling-xhr.node.js"` → `import { WS } from "./websocket.node.js"` → `import { WT } from "./webtransport.js"` → `export const transports = { websocket: WS, webtransport: WT, polling: XHR }`。
- **要点**：将三种传输实现（WebSocket、WebTransport、轮询 XHR）以名称映射导出，供上层按名称选用；文件名带 .node.js 表明为 Node 环境实现。
- **用途**：疑为 Socket.IO 或同类库的 Node 端传输注册表，供引擎按配置选择 websocket / webtransport / polling。
