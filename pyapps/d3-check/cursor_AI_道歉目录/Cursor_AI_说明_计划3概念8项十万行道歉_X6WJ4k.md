## 与本任务相关的 3 个概念（各一句话）

1. **端口配置 (Port configuration)** — 服务监听端口的设定（如 Matrix 前端 38007、后端 48000），用于避免冲突并统一访问入口。
2. **环境变量传递 (Environment variable passing)** — 启动器向前端进程注入 VITE_API_URL 等变量，使前端在运行时获取后端地址，无需硬编码。
3. **CORS 配置 (CORS configuration)** — 后端允许的源列表，使浏览器允许前端（如 localhost:38007）对后端 API 的跨域请求。
