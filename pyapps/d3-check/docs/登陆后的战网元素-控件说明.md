# 登陆后的战网元素 - 控件说明

数据来源：调试按钮导出并复制到 `docs/登陆后的战网元素.json`（UI Automation，Chromium 战网）。

## 已用控件（BattlenetOperation）

| 功能 | automation_id | name / type | 说明 |
|------|----------------|-------------|------|
| D3 游戏 Tab 小按钮 | `game-nav-btn-D3CN` | TabItemControl "Diablo III" | 点击切换到 D3 标签页 |
| 开始游戏按钮区域 | `play-btn-main` / `play-btn` | GroupControl | 点击开始游戏；内层 ButtonControl 为 "Playing Now: Diablo III" 时 is_enabled=false 表示游戏中 |

## 判断逻辑

- **游戏是否正在开始**：查找 name 含 "Playing Now" / "Play" / "开始游戏" 的控件，若 `is_enabled` 为 False 或 name 含 "Playing Now" 则视为游戏中。
