# ROSBOT 启动流程（流程分支图）

禁止过多说明文档；所有信息在流程节点内。启动顺序：战网 → 暗黑 3 → ROSBOT，不可乱。

---

## 状态管理与全局定时器

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 点击「启动 ROSBOT」→ 总状态开启；点击「停止」→ 总状态关闭。总状态关 → 本流程不执行。 │
│ 总状态开 → 每节点为 wait（本 tick 跳过）或 有导向（执行并切换）。                    │
│ 全局定时器 1 秒一跳；本流程 %2 即 2 秒一个 tick。                                  │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 分支 A 详图：片段 1（start → 游戏工具 → 传送）

```
状态 = "start"（D3 窗口截图 scale match d3_start_game_button.png = 开始游戏界面）
         │
         ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 点击 d3_start_game_button；每 2 秒截图检测 d3_game_tool，最多 5×2 秒；未出现 wait。│
└─────────────────────────────────────────────────────────────────────────────┘
         │
         ├─ 超时未出现 d3_game_tool → 片段 1 失败（结束 D3，走分支 B）
         │
         └─ 出现 d3_game_tool
                          │
                          ▼
              ┌─────────────────────────────────────┐
              │ 仅 d3_game_tool 出现时按 M；按 M 后间隔 2 秒；                    │
              │ 缩小地图 (751,413)，点击传送 (610,126)。                            │
              └─────────────────────────────────────┘
                          │
                          ├─ 成功 → 设置 D3 已运行→结束 ROSBOT→启动→任务初始化→启动后自动化 → 成功
                          └─ 失败 → 结束 D3，走分支 B
```

## 分支 B 详图：从战网启动 D3（外层最多 3 轮；战网用 UI 自动化识别，不 OCR）

```
每轮（内层最多 3 次尝试）：
         │
         ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. 无战网窗口 → 启动战网 → 等待数秒                                             │
│ 2. 结束当前 D3 进程（若有）→ 等 5 秒                                            │
│ 3. 托盘/激活聚焦战网 → 等 1 秒                                                  │
│ 4. UI 自动化（控件树）识别战网界面                                               │
└─────────────────────────────────────────────────────────────────────────────┘
         │
         ├─ 找不到战网窗口（多次后）→ 返回失败
         ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 5. UI 元素查找「D3 tab」与「Play」                                              │
└─────────────────────────────────────────────────────────────────────────────┘
         │
         ├─ 找到 D3 tab 可点击 → 点击 D3 tab → wait 直到 Play 出现 → 点 Play（见下）
         └─ 未找到/不可点击 → 按 UI 判断：国服/需登录→登录流程两步；其他→重启战网等 5s continue
                    │
         内层 3 次未找到可点击 D3 tab → continue 外层下一轮
```

**点击 D3 tab、再点 Play 之后：**

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ wait 直到 Play 出现 → 点 Play                                                  │
└─────────────────────────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ sleep(5)；轮询查找 D3 窗口最多 10 秒                                           │
└─────────────────────────────────────────────────────────────────────────────┘
         │
         ├─ 10 秒未找到 D3 窗口 → 重启战网、等 5 秒，continue 外层下一轮
         └─ 找到 D3 窗口
                    │
                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ D3 状态已运行；窗口缩放到标准分辨率；每 2 秒截图 scale match d3_start_game_button │
│ 最多 10 次（约 20 秒）；匹配到则点击并再等 2 秒                                  │
└─────────────────────────────────────────────────────────────────────────────┘
         │
         ├─ 超时未点击成功 → 重启战网、等 5 秒，continue 外层下一轮
         └─ 成功点击「开始游戏」
                    │
                    ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 结束已有 ROSBOT；等 1 秒；若配置则启动 ROSBOT；任务初始化；「ROSBOT 启动后自动化」│
│ （等窗口、调试输出、点主档案 Tab、点 Start botting!）→ 返回成功                │
└─────────────────────────────────────────────────────────────────────────────┘
```

外层：某轮成功则整体成功；触发「重启战网 continue」则下一轮；最多 3 轮失败则返回失败。

## 主线程收尾

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 战网就绪并登录检查返回成功 → 主线程：面板「运行中」、刷新按钮；                  │
│ 启用 rosbot_task 周期任务；再次任务初始化；日志「ROSBOT Started monitoring」。    │
│ 返回失败或抛错 → 按钮恢复未运行、错误日志。                                      │
└─────────────────────────────────────────────────────────────────────────────┘
```

## ROSBOT 启动后自动化（流程内统一调用点）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 在「设置 D3 已运行→结束 ROSBOT→启动→任务初始化」之后、返回成功之前执行：          │
│ 1. 等 ROSBOT 窗口出现（按标题），超时可配置；激活窗口。                          │
│ 2. （可选）递归遍历可操作元素，输出类型、名称、AutomationId、矩形。               │
│ 3. 点主档案：Tab 名称包含「主档案/主檔案/Main Profile」→ 点击。                    │
│ 4. 点 Start botting!：automation_id 或名称对应「Start botting」→ 点击。        │
│ 异常记黄色日志，不改变流程成功/失败。                                            │
└─────────────────────────────────────────────────────────────────────────────┘
```
