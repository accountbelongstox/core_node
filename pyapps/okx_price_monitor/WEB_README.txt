================================================================================
OKX Price Monitor - Web Interface
================================================================================

监听端口: 58888
访问地址: http://localhost:58888/

================================================================================
快速启动
================================================================================

Windows:
    1. 双击运行: start_web.cmd
    2. 或命令行: python start_web.py

Linux/macOS:
    1. 终端运行: ./start_web.sh
    2. 或命令行: python3 start_web.py

================================================================================
自动打开浏览器
================================================================================

服务器启动后会自动打开浏览器：
- Windows: 使用默认浏览器 (cmd /c start)
- Linux: 使用 xdg-open (如果可用)
- macOS: 使用默认浏览器 (open)

如果浏览器未自动打开，请手动访问: http://localhost:58888/

================================================================================
API 端点
================================================================================

基础路径: http://localhost:58888/rpc/

可用路由:
- api/coins/stats       - 获取币种统计
- api/coins/summaries   - 获取所有币种摘要
- api/coins/summary     - 获取单个币种摘要
- api/coins/changes     - 获取价格变化
- api/status            - 获取服务器状态

查看所有路由: http://localhost:58888/rpc/routes

================================================================================
集成到主应用
================================================================================

在 okx_price_monitor_main.py 中添加:

    from pyapps.okx_price_monitor.web_server import OKXWebServer
    import threading

    # 创建 Web 服务器实例
    web_server = OKXWebServer(coin_data_manager=coin_data_manager)

    # 在后台线程启动
    web_thread = threading.Thread(
        target=web_server.start,
        daemon=True
    )
    web_thread.start()

    # 继续运行主监控程序...

================================================================================
技术架构
================================================================================

后端框架: pycore.pyutils.rpc_v2 (FastAPI)
前端技术: 原生 HTML/CSS/JavaScript
配置管理: 中心配置库 (config.js)
API 通信: RPC v2 协议 (同步/异步路由)

================================================================================
故障排除
================================================================================

1. 端口被占用:
   修改 lib/config.py 中的 WEB_PORT 参数

2. 浏览器未自动打开:
   手动访问 http://localhost:58888/

3. 无数据显示:
   独立启动时无数据是正常的，需要集成到主应用

4. API 调用失败:
   检查服务器是否正常运行，查看终端错误日志
