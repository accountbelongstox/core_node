## 🔧 系统架构

### 后端服务

1. **主监控程序** (okx_price_monitor_main.py)
   - 通过 RPC 抓取 OKX 价格数据
   - 实时处理和存储数据
   - 管理 CoinDataManager

2. **数据管理器** (CoinDataManager)
   - 管理所有币种的数据对象
   - 提供统一的查询接口
   - 自动去重和数据库持久化

3. **Web 服务器** (OKXWebServer)
   - 使用 `pycore.pyutils.rpc_v2` 框架
   - 提供 RESTful API
   - 服务静态 Web 文件

### API 端点

基础路径: `http://localhost:58888/rpc/`

- `api/coins/stats` - 获取币种统计
- `api/coins/summaries` - 获取所有币种摘要（历史统计页面使用）
- `api/coins/summary` - 获取单个币种摘要
- `api/coins/changes` - 获取价格变化
- `api/status` - 获取服务器状态

查看所有路由: http://localhost:58888/rpc/routes

### 前端技术栈

- **纯原生技术** - 无框架依赖

## 📈 数据流程

```
OKX 网站
  ↓ (RPC 浏览器抓取)
主监控程序 (okx_price_monitor_main.py)
  ↓ (更新数据)

  ↓ (持久化)
SQLite 数据库 (okx.db)
  ↓ (查询)

  ↓ (HTTP JSON)

```

## 🔍 故障排除

### 1. Web 界面无法打开

**检查：**
- RPC 服务器是否运行（端口 58000）
- 端口 58888 是否被占用
- 控制台是否有错误信息

**解决：**
```bash
# 检查端口占用
netstat -ano | findstr "58888"

# 如果端口被占用，修改 config.py 中的 WEB_PORT
```

### 2. 页面显示"Coin data manager not initialized"

**原因：** 主监控程序还未完成初始化

**解决：** 等待主程序完成以下步骤：
1. RPC 服务器连接
2. 币种列表加载
3. 数据库初始化
4. 历史数据加载

通常需要 10-30 秒。

### 3. 数据不更新

**检查：**
- RPC 服务器是否正常运行
- 控制台是否有错误
- 网络连接是否正常

**解决：**
- 点击"Refresh"按钮手动刷新
- 检查浏览器控制台的错误信息
- 检查 API 端点: http://localhost:58888/rpc/api/status
