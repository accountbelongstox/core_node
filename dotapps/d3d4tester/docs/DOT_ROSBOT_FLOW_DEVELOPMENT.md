# ROSBOT 启动流程（流程分支图）

启动顺序：战网 → 暗黑 3 → ROSBOT，不可乱。已在运行且正常的战网 / D3 / ROSBOT 一律复用，不重启。

---

## 状态管理与驱动方式

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 点击「启动监控」→ 监控开关开，RosbotFlowRunner 在独立线程上按流程顺序执行；          │
│ 点击「停止监控」→ 监控开关关，流程在当前步骤立即结束（所有等待都可取消）。            │
│ 点击「暂停监控」→ 流程在当前步骤停下，监控仍开（重启请求忽略，战网守护不动）；          │
│   ROSBOT 正在运行（running）→ 按 ROSBOT 暂停键 F6 暂停。                            │
│ 点击「继续监控」→ 由暂停按下的 ROSBOT 再按 F6 恢复；清除暂停前排队的重启请求；         │
│   日志超时重新计时；从 F1 继续。                                                    │
│ 触发器动作同样支持「暂停监控」「继续监控」。                                         │
│ 驱动方式：流程驱动（顺序执行 F1 → B → D → E → P → F3，一轮结束回到 F1），不按 tick。 │
│ TickDriver（1 秒）只给定时服务用：ROSBOT 日志读取、监控统计、智能回响、空闲刷新。     │
│ 异常：记录日志，等 5 秒后重新从 F1 开始。                                         │
│ 管理员：程序启动时自动以管理员身份重启（一次 UAC）；战网 / ROSBOT 以管理员身份启动，     │
│   脱离本程序进程树（本程序重启不影响），且本程序仍可操作其窗口。                          │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 战网就绪详图（BattlenetReadyProcess）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 每 2 秒探测一次战网客户端状态（BattlenetClientStateDetector），按状态处理，直到就绪。 │
│ 同一时刻只运行一个（监控、确保战网守护、手动启动 D3/D4 共用）。                    │
└─────────────────────────────────────────────────────────────────────────────┘
                                        │
                                        ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ 已登录主界面 / 游戏启动中 → 区服与全局设置一致 → 就绪（复用）；                      │
│                          区服不一致 → --setregion 重启（冷却 120 秒）后继续探测     │
│ 未运行            → 启动战网，等 5 秒                                           │
│ 隐藏在托盘         → 托盘恢复，否则再次启动 Battle.net.exe 显示窗口；绝不关闭；        │
│                     刚启动 30 秒内不重复启动；确保战网守护不弹出托盘里的战网          │
│ 国服登录页         → 同意 + 网易登录（冷却 15 秒），再网页登录自动化                 │
│ 网页登录 / 浏览器等待 → 网页登录自动化轮询                                        │
│ 亚服登录页（邮箱/密码）→ 已存账号密码填写提交；无凭据 → 弹出凭据对话框               │
│ 正在登录 / 安全验证 / 验证码 → 等用户（安全验证自动点一次 Continue），永不重启        │
│ 弹窗              → 关闭                                                      │
│ 断线 / 登录失败     → 重启战网                                                  │
│ 连接中 / 加载 / 离线 / 未知 超过 battlenet.abnormal_timeout_sec → 重启             │
│ 休眠 / 读取账号 超过 5 分钟 → 清缓存后启动                                       │
│ 各登录页 超过 battlenet.login_timeout_sec → 重启                                 │
│ 所有关闭都经 BattlenetManager.Close：登录中 / 验证中 / 游戏启动中拒绝关闭。          │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 从战网启动 D3 详图（GameLaunchProcess，单次执行）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 1. 结束 ROSBOT（启动 D3 前一步）                                                │
│ 2. 直接启动（RBAssist 方式）：Battle.net.exe --exec="launch D3"（国服 D3CN），       │
│    D3 进程未出现时每 10 秒重发，最多 60 秒；期间关闭 "New version" 提示（Esc）；        │
│    窗口类 "D3 Main Window Class" 且高度 > 500 才算就绪                              │
│ 3. 直接启动失败才回退：激活战网 → 点 D3 页签 → 点 Play（显示更新/安装/下载 → 失败）     │
│ 4. 回退时：等 5 秒 → 轮询 D3 窗口最多 10 秒                                       │
│ 5. 找到 → D3 已运行、标记「刚进入游戏」；未找到 → 失败                             │
│ 失败只返回给流程（20 秒后从 F1 重来），从不重启战网。                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 插件启动动作详图（RosbotBridgeStartActions）

不再截图识图、按 M、点击坐标传送；D3 画面状态检测（`D3ScreenState`）只留给状态刷新、手动登录尝试和 F3。

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ ROSBOT 上线后（[E] 成功或复用在线 ROSBOT）立即执行：                              │
│ 1. 读取设置：已保存的跟随设置（桥接面板发出的最后一条 follow，非 off）；                │
│    传送 UI 序列 rosbot.bridge_teleport_ui_sequence（监控中控 TAB 设置，| 分隔，     │
│    只在本轮新启动 ROSBOT 时传送）。都没有 → ROSBOT 照常挂机                          │
│ 2. 等 90 秒内插件数据在线且英雄在游戏内；否则跳过，ROSBOT 照常挂机                     │
│ 3. 按 F6 暂停 ROSBOT                                                             │
│ 4a. 跟随（跟随队列）：跳过传送，直接重发 follow → 暂停监控，ROSBOT 保持暂停，由插件跟随， │
│     不与 ROSBOT / 日志超时竞争；点击继续监控时结束跟随（设置保留）并按 F6 恢复 ROSBOT    │
│ 4b. 传送：插件 ui_sequence 按顺序等待（每步 3 秒）并点击 D3 UI 元素 → 按 F6 恢复 ROSBOT │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 启动 ROSBOT 详图（RosbotRunFlow.RunEBlock）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ [F2] ROSBOT 已在线 → 只开启监控任务，不重启                                       │
│ [E1] 结束已有 ROSBOT → [E2] 等 1 秒                                             │
│ [E3] 自动使用最新 ROS：找更新 zip → 解压 → 复制 RoS-BoT.ini → 更新 ros_directory；│
│      auto_start_rosbot 关闭 → 不启动                                             │
│ [E4] 以 "autostart" 参数启动 ROSBOT（战网休眠 / 读取账号时本轮跳过），记录 F3 起算时间 │
│ [E5] 任务初始化                                                                 │
│ [E5a] 45 秒内自行开始挂机（无可见 ROSBOT 窗口 = running，期间自动填 KEY）→ 完成      │
│ [E6] 否则回退：等 ROSBOT 窗口 / 服务器 → 点主档案 → 点 Start botting!（停止监控即中断）│
│ 完成后发布「ROSBOT 已启动」事件（托盘通知、按设置缩小 D3）。                        │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 监控详图（F3MonitorProcess）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 每 2 秒检查一次，每 10 秒静默刷新 D3 / ROSBOT 状态，状态行原地刷新：               │
│ 重启请求（错误弹窗 / 内存超限 / 触发器 / 日志系统错误）→ 重启                       │
│ 只重启 ROSBOT 的请求（智能回响恢复失败）→ [E]，D3 不动                            │
│ ROSBOT 日志掉线 → 重启                                                         │
│ D3 窗口消失 → [F4]                                                             │
│ ROSBOT 日志超时（F3LogTimeout，含测试模式）→ 重启                                  │
│ ROSBOT 离线超过 30 秒（D3 仍在）→ 回 F1，D3 复用，重走 E + P                       │
│ （auto_start_rosbot 关闭则只等待，不启动）       │
│ 进入监控时清除旧的日志掉线标记。                                                  │
└─────────────────────────────────────────────────────────────────────────────┘
                                        │ 重启
                                        ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ [F4] 重启计数（掉线 / 请求）、通知、错误截图、按设置关闭战网 → F7 停止挂机 → 等 2 秒 →        │
│ 结束 D3 → 第二次 F7 关闭 ROSBOT → 轮询其退出（最多 5 秒）→ 按 PID 结束残留 → 回 F1      │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 回城配装对齐（D3PlannerTownService + 插件 TownHold）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 对齐：当前配装（maxroll，魔盒除外）每件已穿在身上（任一部位）且远古/太古等级达标 = 已对齐。 │
│ 换装：背包里有未对齐件的更好副本（等级达标，或同等级词缀达标更多）→ town_hold.txt=1。   │
│   ROSBOT 回城事件（in_town）：插件阻塞事件线程（ROSBOT 暂停回城流程，插件定时器照常写状态）│
│   跟随模式在城里：点战旗前等待（状态 town_tasks）。                                  │
│   应用：激活 D3 → 打开背包 → 识别背包格 → 右键每件 → 关背包 → town_hold.txt=0 放行。   │
│   放行条件：应用写 0 / 离开城镇 / 超时 90 秒；每次进城只拦一次，每件装备本次运行只试一次。│
│ 赌博：未对齐部位 → RosBotGamblingSettings.ini 只开对应类型，GambleShardsMin = 血岩上限，│
│   由 ROSBOT 回城时到卡达拉处购买；全部对齐或关闭开关 → 恢复用户原设置（备份 json）。      │
│   赌到的配装件下次回城按上面换装，直到全部对齐。跟随模式不跑 ROSBOT 回城，不会赌博。      │
│ 跟随回城：野外跟丢 → 应用按回城键；城里先做换装，再用战旗：优先按战旗主人 ACD 找目标的    │
│   战旗，其次队伍位，再轮流 1-4。                                                     │
└─────────────────────────────────────────────────────────────────────────────┘
```

## 自动操作仲裁（GameControl）

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 所有自己动手的模块（流程 F4/暂停键、触发器动作、日志系统错误重启、SmartEcho、No items 处理、 │
│ Login try 重启战网、回城换装、跟随回城键）都经过 GameControl：                          │
│ 闸门：用户接管（暂停）时一律不动游戏/ROSBOT；绑定监控的模块只在监控开启时动。             │
│   触发器在接管时只执行写日志、截图、通知、停止监控、外部命令。                          │
│ 租约：同一时刻只有一个模块发按键/点击/切窗口/结束进程；同线程可重入；拿不到就跳过或稍后重试。│
│ 暂停：等正在执行的流程步骤结束（最长 20 秒）后再按 F6；停止监控不清除接管状态，恢复时补按 F6；│
│   恢复后若插件在跟随则关闭跟随。                                                    │
│ 回城保持中：F3 不执行重启、日志超时窗口顺延，日志空闲计时触发器暂停。                     │
│ ROSBOT 单独重启：强制走 [E]（关闭并重新启动 ROSBOT），不再因“在线”而跳过。              │
│ 全局热键只响应人按的键，程序/ROSBOT/宏注入的按键不触发；开始/停止、暂停按钮 1 秒内只认一次。│
└─────────────────────────────────────────────────────────────────────────────┘
```
