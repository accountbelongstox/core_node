# core_node — AI main spec (OpenAI / Codex / generic agents)

**Cross-OS / relative path conversion (mandatory):** Before using any path or command, detect the path style in the prompt and the executing environment (Windows / Git-Bash / WSL / Ubuntu / deployed Linux), then convert the path accordingly and resolve relatives to absolute — never reuse a foreign-environment path or command verbatim. Full rule: [development-guides/PATH_CONVERSION_SPECIFICATION.md](development-guides/PATH_CONVERSION_SPECIFICATION.md). Laravel `poly_apps/laravel_main` runtime paths must resolve via `App\Providers\PathMapper::mapWebPath()` / its helpers only — never raw `storage_path()` / `base_path()` / `database_path()` / `env('*_PATH')` / ad-hoc concatenation (see §6 of the canonical spec).

**core_node deletion safety (mandatory):** Never remove, recursively delete, overwrite, or re-clone over the `core_node` project directory (`$CORE_NODE_DIR` / `$CORE_NODE_PROJECT_ROOT` / any `*/core_node`) without the guarded triple confirmation (each `[N/y]`, default **N**). Hard-refuse — with no prompt — system paths, any git working tree (`<target>/.git`), self-deletion, and all non-interactive runs. An existing populated/`.git` project tree is authoritative: a "partial/incomplete clone" check must **adopt or abort, never delete**. Use `confirm_core_node_deletion` (`scripts/shells/linux/common/gvar_common.sh`, `install_bootstrap.sh`). Full rule: [development-guides/CORE_NODE_DELETION_SAFETY.md](development-guides/CORE_NODE_DELETION_SAFETY.md).

**Git & no-revert (mandatory):** Run **`git commit` ONLY** (plus read-only `git status`/`log`/`diff`). NEVER run any other Git operation — no `checkout`/`switch`/`reset`/`revert`/`restore`/`clean`/`rm`/`mv`/`stash`/`rebase`/`merge`/`cherry-pick`/`branch -D`/`push`/`pull`/`fetch --prune` or any `--force`. Record renames/removals via normal file tools + the next commit, never `git rm`/`git mv`/`git reset`. NEVER revert, undo, roll back, overwrite, or delete existing code or the user's local (uncommitted) changes — only move forward (add/extend/fix in place); if something looks wrong, surface it and ask rather than reverting. Commit completed work locally; never push/sync unless explicitly asked. Full rule: [development-guides/GIT_AND_NO_REVERT_SAFETY.md](development-guides/GIT_AND_NO_REVERT_SAFETY.md).
