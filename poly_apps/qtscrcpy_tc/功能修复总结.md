## 🎯 技术要点

### 1. DeviceManage 单例模式

```cpp
// 正确使用方式
DeviceManage& dm = DeviceManage::getInstance();
QList<QString> serials = dm.getDeviceSerials();
dm.disconnectAllDevice();
```

### 2. 设备断开流程

```
1. 获取设备列表 → dm.getDeviceSerials()
2. 遍历设备断开 → dm.disconnectAllDevice()
   - 关闭 VideoSocket
   - 关闭 ControlSocket
   - 移除 ADB 隧道 (reverse/forward)
   - 停止 scrcpy-server
3. 等待断开完成 → QThread::msleep(500)
4. 清理全局资源
```

### 3. 异常处理

```cpp
try {
    DeviceManage& dm = DeviceManage::getInstance();
    // ... 操作设备 ...
} catch (const std::exception &e) {
    qWarning("Exception: %s", e.what());
    return false;
}
```
