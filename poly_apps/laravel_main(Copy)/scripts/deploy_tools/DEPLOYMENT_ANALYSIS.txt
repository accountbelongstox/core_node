1.1 Laravel Artisan Command Callable (VERIFIED)

STATUS: FULLY IMPLEMENTED

  - Laravel artisan executable verification is implemented in nginx_integrator.sh
  - Functions: verify_artisan_command(), test_laravel_artisan()
  - Checks: File existence, executable permission, command invocation test

  4. Confirms Laravel command system availability

1.2 Initial Deployment Without Web Server (VERIFIED)
----------------------------------------------------
STATUS: FULLY IMPLEMENTED
DESCRIPTION:
  - Initial deployment phase does NOT require web server
  - Laravel is deployed first in standalone mode
  - Web server (Nginx) integration happens AFTER Laravel setup
  - Path structure aligns with system scripts (25_install_nginx.sh, 31_ensure_php84_intelligent.sh)
  - Real-time output: Every step provides direct console feedback

IMPLEMENTATION:
  PHASE 1: Core Laravel Setup (deploy.sh main execution)
    - Environment validation
    - System dependencies installation
    - Database configuration
    - Permission setup
    - Composer dependencies
    - All with real-time console output

  PHASE 2: Optional Nginx Integration (production mode)
    - Only executed if APP_ENV=production
    - Uses Laravel artisan command
    - Creates Nginx configuration
    - Reloads Nginx service
    - With full real-time status updates

1.3 Nginx Integration via Laravel Artisan (VERIFIED)
---------------------------------------------------
STATUS: FULLY IMPLEMENTED
DESCRIPTION:
  - Primary: Uses ServerManagerV1 artisan commands
  - Fallback: Manual Nginx configuration creation
  - Configuration path: /www/nginxconfig (consistent with system scripts)
  - Root path: /www/wwwroot (consistent with system scripts)
  - Real-time execution: All operations produce direct console output

COMMAND HIERARCHY:
  Level 1: Try ServerManagerV1 artisan command
    Command: php artisan servermanager:website:add
    Parameters: name, domain, path, type, php-version
    Fallback: If command not available

  Level 2: Manual Nginx configuration (fallback)
    Creates: /www/nginxconfig/{app_name}.conf
    Template: Complete Laravel/PHP-FPM configuration
    Optimization: Gzip, caching, security headers

  Level 3: Nginx verification and reload
    Verify: nginx -t (syntax check)
    Reload: systemctl reload nginx
    Fallback: systemctl start nginx (if not running)

5. ARTISAN COMMAND INTEGRATION DETAILS
============================================================

5.1 Primary Integration: ServerManagerV1
---------------------------------------
COMMAND: php artisan servermanager:website:add

PARAMETERS:
  --name: Application name (e.g., laravel_main)
  --domain: Domain name (e.g., localhost)
  --path: Public path (e.g., /www/wwwroot/laravel_main/public)
  --type: Type (set to: laravel)
  --php-version: PHP version (e.g., 8.4)

EXPECTED OUTPUT:
  Line 1-N: Command execution feedback
  Final: Success or failure message

REAL-TIME DISPLAY:
  All output piped to console AND /tmp/artisan_output.log
  Status immediately visible to user

5.2 Command Location
-------------------
IMPLEMENTATION:
  File: app/Apps/ServerManagerV1/ServerManagerV1CLI/Commands/
  Command Name: ServerManagerV1WebsiteCommand.php
  Available via: php artisan list (shows in output)
  Verification: check_servermanager_command() function

5.3 Fallback Configuration
--------------------------
IF ServerManagerV1 command not available:
  - Manual Nginx configuration template
  - Located in: nginx_integrator.sh (lines 185-220)
  - Template includes:
    * Upstream PHP-FPM configuration
    * Server block configuration
    * Gzip compression
    * Security headers
    * Static file caching
    * Error handling
  - All placeholders automatically replaced with actual values

6. CONFIGURATION FILE LOCATION AND FORMAT
============================================================

6.1 Generated Nginx Configuration
--------------------------------
LOCATION: /www/nginxconfig/{app_name}.conf

EXAMPLE: /www/nginxconfig/laravel_main.conf

CONTENT STRUCTURE:
  1. Upstream block (PHP-FPM connection)
  2. Server block (listening configuration)
  3. Index settings (index.php)
  4. Logging configuration
  5. Gzip compression settings
  6. Security headers
  7. Sensitive file protection
  8. URI rewriting for Laravel
  9. PHP processing rules
  10. Static file caching

6.2 Placeholder Replacement
---------------------------
ORIGINAL:
  server_name APP_DOMAIN;
  root APP_PATH;
  upstream unix:PHP_FPM_SOCKET;

REPLACED WITH:
  server_name localhost;
  root /www/wwwroot/laravel_main/public;
  upstream unix:/var/run/php/php-fpm.sock;

REPLACEMENT METHOD:
  sed -i 's|PLACEHOLDER|VALUE|g' filename

10. ERROR HANDLING AND RECOVERY
============================================================

10.1 Error Handling Strategy
----------------------------
FRAMEWORK:
  - Each function returns 0 (success) or 1 (error)
  - stderr redirection (>&2) for error messages
  - || true for non-critical failures
  - || return for critical path failures

NGINX_INTEGRATOR SPECIFIC:
  - Verify artisan command (critical)
  - Test artisan execution (critical)
  - ServerManagerV1 command attempt (fallback available)
  - Nginx config verification (fallback available)
  - Nginx reload attempt (non-critical)

10.2 Fallback Mechanisms
------------------------
LEVEL 1: Try ServerManagerV1 Artisan Command
  IF FAILS: Go to Level 2

LEVEL 2: Manual Nginx Configuration
  Creates config from template
  IF FAILS: Report error but continue

LEVEL 3: Nginx Validation
  IF SYNTAX ERROR: Report warning but continue
  IF RELOAD FAILS: Report warning but continue
  (Application can still be accessed)
