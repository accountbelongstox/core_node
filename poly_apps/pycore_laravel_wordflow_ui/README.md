# pycore_laravel_wordflow_ui

React + Vite SPA — one shell hosting three ends: **laravel-manager**, **pycore-manager**, **wordflow**.

- Run: `npm install` && `npm run dev`
- Build: `npm run build`

Documentation lives in [`docs/`](docs/README.md): architecture, API layer, UI conventions.
WordFlow's own design docs are under [`apps/wordflow/docs/`](apps/wordflow/docs/README.md).
