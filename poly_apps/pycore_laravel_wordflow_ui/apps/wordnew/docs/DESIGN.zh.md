# 书架学习体验——功能与需求设计

> **AI 维护规则：** AI 必须先阅读英文主文档 `DESIGN.en.md`，英文版是唯一的
> 规范来源。本文件仅作为英文版的中文备份，不是独立规范，也不具有权威性。
> 修改英文版时，必须在同一次变更中同步更新本文件；即使修改请求从中文版开始，
> 也必须先更新英文版，再同步更新本中文备份。两份文件必须保持章节编号、需求编号
> 和含义一致，禁止只修改中文版或只修改英文版。

## 1. 旧版 Bing 词典学习客户端调研

本章归纳旧客户端中值得 Wordnew 书架复用的交互，不要求复制旧技术实现。

### 1.1 页面布局

- 顶部状态区显示学习数量、进度和当前模式。
- 主区域为连续单词流，每个词拥有独立学习状态。
- 控制区提供播放、暂停、前后切换、显示方式和设置入口。
- 学习过程中始终能定位当前单词，同时允许用户自由滚动。

### 1.2 单词记录

每个单词至少需要：稳定 ID、原文、音标、翻译/释义、音频、学习状态、
阅读次数、复习次数、最后阅读时间、下次复习时间和排序位置。用户状态与词典
公共数据分离，不能因重新加载词典数据而丢失。

### 1.3 单词卡片呈现

- 单词、音标和翻译按当前学习模式展示。
- 可播放真实音频；真实音频不可用时使用语音合成回退。
- 可标记掌握、忘记、收藏，并打开现有单词详情。
- 简洁模式只保留学习所需的最小信息。

### 1.4 学习与朗读模式

- 列表：浏览整组单词。
- 卡片：翻转或揭示内容。
- 背诵：自动播放并推进。
- 复习：优先处理到期或忘记的单词。
- 每词可播放 N 次，并支持播放间隔、速度和回看。

### 1.5 进度与统计

展示掌握率、每日目标、当前会话进度，以及已掌握、学习中、待复习数量。
统计以后台进度为准，离线时可暂存并在恢复连接后同步。

### 1.6 设置

学习设置需持久化并在相关页面复用，包括每词播放次数、回看次数、播放间隔、
播放速度、回看距离、每页数量、语音和复习顺序。

## 2. Wordnew 书架“默认词汇组”需求

- 打开 `#/shelf` 中的词组后，应进入真实学习界面，而非静态占位内容。
- 支持列表、卡片、背诵和复习四种模式。
- 支持显示/隐藏释义、发音、掌握/忘记、收藏和单词详情。
- 自动朗读按当前顺序推进，每词播放配置次数，并自动保持当前词可见。
- 显示掌握率、每日目标、会话进度和学习状态数量。
- 复习模式优先显示到期或需要复习的词。
- 登录用户读取并同步真实后台数据；访客或离线状态保留本地会话进度。
- 拼音开关、旧式 DOM 缓冲、旧压缩传输和旧多选题实现不在迁移范围内。

## 3. 旧功能到 Wordnew 的对应关系

| 旧功能 | Wordnew 对应功能 | 复用原则 |
| --- | --- | --- |
| 单词流 | 书架词组学习面板和单词列表 | 使用现有词组数据 |
| 自动朗读 | 统一背诵控制器 | 复用音频中心和播放设置 |
| 已读/待复习 | 学习进度动作 | 后台优先，本地降级 |
| 进度条和计数 | 学习统计区 | 使用统一进度数据 |
| 到期复习 | 复习模式 | 未学习词优先 |
| 最近最少阅读排序 | 背诵/复习排序 | 从进度记录计算 |
| 设置面板 | 学习设置面板 | 使用 Wordnew 持久化设置 |
| 简洁模式 | 精简单词行 | 保留词、音标和释义 |
| 投影模式 | 大号卡片模式 | 合并到卡片体验 |
| 发音按钮 | 单词扬声器按钮 | 真实音频优先，TTS 回退 |
| 详情面板 | 现有单词详情弹窗 | 不重复实现 |
| 收藏 | 收藏按钮 | 使用现有收藏状态 |

英文主文档中列出的组件和服务位置用于定位现有实现；新增功能应优先复用现有
组件，避免产生第二套学习状态或播放控制器。

## 4. 顺序阅读模式——功能需求

### 4.1 模式目标

顺序阅读是无需答题的自动朗读模式。释义始终可见，用户可以只听，也可以随时
暂停、跳词或改变当前位置。一次只处理当前打开的词包。

### 4.2 单词列表与排序

- 单词以单列垂直列表显示。
- 普通词组按最久未读优先；从未读过的词排在最前。
- 默认词汇组采用第 5 章规定的一次随机排序和未读优先规则。
- 每行始终显示单词和翻译/释义，不使用模糊、翻面或点击揭示。
- 当前播放词具有明显状态。
- 自动播放推进时保持当前词可见；用户主动滚动时不强制抢回滚动位置。

### 4.3 播放游标

- 播放只有一个当前游标。
- 点击任意单词会把游标移到该词并从此处继续。
- 下一词、上一词和分页操作只改变游标，不结束会话。
- 每个单词按设置播放 N 次，然后等待指定间隔再推进。
- 播放速度由统一播放设置控制。

### 4.4 浮动控制面板

开始播放后显示浮动控制面板，至少提供：

- 播放/暂停；
- 停止；
- 上一个词/下一个词；
- 上一页/下一页；
- 大字模式开关。

手动控制后应从新位置继续自动播放。

#### 4.4.1 大字模式

大字模式强调当前词、音标和释义，隐藏非必要信息。切换显示模式不改变播放游标、
进度或当前会话。

### 4.5 回跳复习

- 正向播放完成当前词后，可临时回到前面某个词进行短暂复习。
- 回跳距离由“回跳间隔词数”决定。
- 回跳播放次数由“回跳次数”决定；设为 0 时关闭。
- 回跳完成后必须返回原来的正向位置，不能丢失主游标。
- 回跳词显示临时视觉标识。

### 4.6 分页

- 页面是固定数量单词的窗口，默认每页 100 词。
- 播放到页尾后自动进入下一页，并从下一页第一词继续。
- 手动上一页/下一页后从新页第一词开始。
- 第一页和最后一页必须限制越界操作。

### 4.7 语音选择与回退

- 用户可以选择朗读语音、口音和速度。
- 优先使用符合设置的真实音频。
- 不可用时依次尝试其他可用音频、匹配语言的系统语音和默认语音。
- 不得在仍有可用发音方式时静默跳过单词。
- 所有发音方式都失败时，仍显示当前词状态并继续播放。

### 4.8 播放设置

| 设置 | 含义 | 默认值 |
| --- | --- | --- |
| 每页词数 | 每个页面窗口中的单词数 | 100 |
| 每词播放次数 | 游标推进前的朗读次数 | 1 |
| 回跳次数 | 回跳词的重播次数，0 为关闭 | 1 |
| 回跳间隔词数 | 回跳到前面的距离 | 1 |
| 播放间隔 | 两个词之间的等待时间 | 2.5 秒 |
| 播放速度 | 语音播放倍率 | 1.0 倍 |
| 朗读语音 | 使用的语音及自动回退规则 | 系统/口音匹配默认值 |

设置修改应作用于后续播放并被持久保存。

## 5. 默认词汇组：一次随机与每日目标顺序阅读

### 5.1 当前基础

- 默认词汇组使用现有词组和用户进度体系。
- 用户的单词映射记录保存阅读、复习和排序状态。
- 数据初始化通过现有系统初始化流程处理。
- 进入书架学习面板时，列表顺序阅读是默认体验，多选题仍可从模式切换进入。

### 5.2 R1——默认进入列表顺序播放

点击“开始学习/开始竞技场”时，默认进入列表并启动顺序朗读，不直接进入多选题。
用户随后可切换到卡片、背诵、复习或测验模式。

### 5.3 R2——默认词汇组只进行一次随机排序

- 默认词汇组首次可用时执行一次随机排序。
- 排序结果必须持久稳定，重复打开或初始化不能再次打乱。
- 在首次读取时也应保证排序已完成。
- 已有排序位置不得被后续读取覆盖。

### 5.4 R3——新增单词只随机新增部分

- 加入默认词汇组的新单词获得随机位置。
- 已存在单词的位置保持不变。
- 每次加入新词不得重新随机整个词组。
- 首次完整随机与后续新增词随机必须收敛为稳定、无遗漏的顺序。

### 5.5 R4——按每日目标朗读未读单词并提交播放时间

- `#/shelf` 按固定随机顺序读取默认词汇组中的未读单词。
- 每日读取数量不超过用户的每日目标。
- 单词播放完成后自动提交本次实际播放时间。
- 已成功读取的单词不再属于“未读”，后续每日队列自然向后推进。
- 重读时间与首次阅读时间分别累计。
- 单词映射至少表达：单词 ID、排序位置、首次/最后阅读时间、阅读次数、
  阅读总时长、重读总时长、复习次数、最后复习时间、下次复习时间、熟练度、
  权重和加入时间。
- 播放时间优先使用真实音频时长乘以播放次数；无法取得时长时使用配置间隔，
  并限制在合理范围。

### 5.6 实现范围对应

英文主文档记录了当前后端模型、控制器、前端学习面板、播放控制器和 API 层的
详细对应关系。中文版以同一功能边界为准：一次随机、只随机新增词、未读过滤、
每日目标、播放时长累计和前后端同步必须作为同一功能交付。

### 5.7 跨端契约

- 获取词组单词时可请求仅返回未读词，并限制每日数量。
- 提交阅读进度时可包含本次播放秒数。
- 返回的进度包含阅读总时长和重读总时长。
- 默认词汇组身份必须使用系统统一定义，不能由前端名称猜测。
- 其他词组继续使用其原有排序规则。

### 5.8 当前实现状态

截至英文主文档记录的 2026-07-19 审核，一次随机、新增词随机、每日未读集合、
播放时间提交和对应前端流程均已实现。后续修改实现状态时，必须同时更新两种语言。
