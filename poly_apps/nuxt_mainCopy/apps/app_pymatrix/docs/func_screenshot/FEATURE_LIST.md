# PyMatrix 功能列表

> 基于截图 OCR 识别生成的功能清单

## 一、设备连接管理

### 1.1 USB 连接
- USB 线连接设备
- 显示设备序列号
- 更新设备状态
- 启动设备 adbd 服务
- 停止所有服务

### 1.2 无线连接
- 一键 WIFI 连接
- 获取设备 IP 地址
- 无线连接/断开 (默认端口 5555)
- 双击快速连接已保存设备
- 显示设备 IP: `192.168.0.1`

### 1.3 设备列表管理
- 刷新设备列表
- 自动刷新
- 仅显示已连接设备
- 设备总数/已连接/已投屏统计
- 设备序列号显示 (如: R38M10KS4DX)

## 二、批量设备管理

### 2.1 多设备控制
- 支持 100+ 设备同时管理 (截图显示156台)
- 全选/反选设备
- 分组管理
- 批量投屏操作
- 设备状态实时监控

### 2.2 批量操作
- 批量发送文件
- 批量安装 APK
- 批量执行 ADB Shell 命令
- 全选设备进行统一操作

## 三、投屏功能

### 3.1 基础投屏
- 实时屏幕投影
- 解码器帧显示 (Decoder::onNewFrame)
- 启动/停止服务
- 服务器控制

### 3.2 投屏设置
- 精简模式/完整模式切换
- 窗口置顶
- 无边框模式
- 比特率调节 (Mbps)
- 最大尺寸设置 (如: 1080)
- 锁定屏幕方向
- 显示 FPS
- 反向连接

## 四、录制功能

### 4.1 屏幕录制
- 录制屏幕
- 后台录制
- 录制格式选择
- 录像保存路径设置
- 选择保存路径

### 4.2 录制选项
- 比特率设置
- 最大尺寸控制
- 方向锁定

## 五、ADB 工具

### 5.1 ADB Shell
- 执行自定义 ADB 命令
- 命令终止
- 命令历史记录
- 清理输出
- 示例命令: `devices`

### 5.2 ADB 操作
- 启动 adbd 服务
- 更新设备列表
- 获取设备 IP
- 停止服务

## 六、文件与应用管理

### 6.1 文件操作
- 发送文件到设备
- 选择文件路径

### 6.2 应用管理
- 安装 APK
- 应用脚本执行
- 刷新脚本

## 七、音频功能

- 安装 sndcpy (音频投屏工具)
- 开始音频传输
- 停止音频传输

## 八、系统设置

### 8.1 显示设置
- 窗口无边框
- 窗口置顶
- 显示 FPS
- 精简模式

### 8.2 电源管理
- 保持唤醒
- 自动息屏

### 8.3 其他设置
- 反向连接
- 更新设置名称
- 刷新设备列表
- 启动配置

## 九、系统监控

### 9.1 性能监控
- CPU 使用率监控 (如: Intel Xeon CPU E5-2670 V2)
- 内存使用情况 (如: 5/15.9 GB)
- 磁盘状态 (SSD)
- 网络 (以太网)
- GPU 状态

### 9.2 任务管理
- 进程监控
- 运行时间统计
- 句柄数统计
- 资源监视器
- 应用历史记录

## 十、用户界面特性

### 10.1 设备显示
- 设备手机屏幕实时显示
- 设备信息展示
- 时间、天气、网络状态显示

### 10.2 操作便捷性
- 双击快速连接
- 一键操作按钮
- 全选快捷功能
- 自动刷新
