# pycore_laravel_wordnew_ui

React + Vite SPA — one shell hosting three ends: **laravel-manager**, **pycore-manager**, **wordnew**.

- Run: `npm install` && `npm run dev`
- Build: `npm run build`

Documentation lives in [`docs/`](docs/README.md): architecture, API layer, UI conventions.
WordNew's design is documented in [`apps/wordnew/docs/DESIGN.en.md`](apps/wordnew/docs/DESIGN.en.md).
