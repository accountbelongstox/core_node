Flutter App Runner Usage Guide

This system provides multiple ways to run Flutter apps in the project:

1. INTERACTIVE MODE (Recommended)
   - Double-click: runApp.bat
   - Or run: winStart.bat (calls runApp.bat)
   - Shows a menu of available apps to select from

2. COMMAND LINE MODE
   - runApp.bat [app_name]
   - Examples:
     * runApp.bat main      (runs main aggregation app)
     * runApp.bat achat     (runs achat app)
     * runApp.bat example   (runs example app)
     * runApp.bat wuy       (runs wuy app)

3. FEATURES
   - Automatically scans lib/apps directory for available apps
   - Runs flutter pub get before starting the app
   - Starts web server on 0.0.0.0:8080
   - Displays local and network access URLs
   - Shows your local IP address for network access

4. REQUIREMENTS
   - Flutter SDK installed and in PATH
   - PowerShell available
   - Windows operating system

5. NETWORK ACCESS
   - Local: http://localhost:8080
   - Network: http://[your_ip]:8080
   - The script will display your actual IP address

6. TROUBLESHOOTING
   - If Flutter is not found, add Flutter to your PATH
   - If PowerShell is not found, install PowerShell
   - If apps are not detected, check lib/apps directory structure

7. FILE STRUCTURE
   - winStart.bat          (main entry point, calls runApp.bat)
   - runApp.bat            (quick runner)
   - winStartNew.bat       (alternative entry point)
   - scripts/dev/appSelector.ps1  (PowerShell app selector)
   - scripts/dev/testAppScanner.ps1  (test script)

The system automatically detects apps in lib/apps/ that follow the pattern:
- Directory: app_[name]
- Main file: main_app_[name].dart

Example: app_main/main_app_main.dart becomes selectable as "main"
