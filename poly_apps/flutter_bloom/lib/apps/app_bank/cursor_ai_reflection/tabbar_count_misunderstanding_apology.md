## 技术深度分析

### TabBar组件的完整概念

**TabBar组件的结构**：
```dart
TabBar(
  controller: _tabController,  // TabController控制tab的切换
  tabs: [
    Tab(text: '财富全景'),  // 第一个tab标签
    Tab(text: '银行卡'),    // 第二个tab标签
  ],
)
// 上面的TabBar + 两个Tab标签 = 一个完整的tab组件
```

**TabBarView的结构**：
```dart
TabBarView(
  controller: _tabController,  // 使用相同的TabController
  children: [
    _buildWealthPanoramaTab(),  // 第一个tab的内容
    _buildBankCardTab(),        // 第二个tab的内容
  ],
)
// TabBarView包含两个内容页面，对应TabBar中的两个tab标签
```

**完整的tab组件**：
- TabBar（包含两个Tab标签）
- TabBarView（包含两个内容页面）
- TabController（控制tab的切换）
- 这三个部分共同组成一个完整的tab组件
