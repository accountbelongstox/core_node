App WUY 代码与页面现状审查（2025-10-08）

一、结论摘要
- 首页应改为“我的好友（Friends List）”。当前代码将初始路由指向 /wuy/home（Home），且未做登录鉴权拦截。
- 登录未集成真实鉴权与持久化，仅模拟 2 秒后跳转到 /wuy/home；GoRouter 与 Navigator 混用，存在路由体系不一致问题。
- 按截图清单（14 张）对照代码实现（仅 6 个基础页：Home/Login/Profile/Settings/Dashboard/Splash），多数业务页尚未开发（好友列表/查找好友/添加好友/好友信息/聊天/地图/历史轨迹/网络记录/关于我们/搜索等）。
- 路由与状态管理没有打通：WuUserProvider/SharedPreferences 存在，但路由未根据登录态做 redirect，Splash 也未生效。

二、依据与证据
1) 截图目录（screenshots_catalog.md）
- 共 14 个目标页面：Profile、About us、History tracking、Map、Friend info、Friends list、My profile、Find friends、Registration、Add friend、Login、Network records、Chat、Search。

2) 代码目录（app_wuy_tree_code_assets_20251008_111443.txt）
- 存在的 Wuy 特性页：authentication/login_screen.dart、home/home_screen.dart、profile/profile_screen.dart、settings/settings_screen.dart、dashboard/dashboard_screen.dart、splash/splash_screen.dart。
- 有用户提供者 WuUserProvider 和 AppPrefs（具备持久化能力），以及 GoRouter 配置 router_app_wuy.dart。

3) 路由与入口
- main_app_wuy.dart: runCommonApp 传入 routerConfig=WuyAppRouter.createRouter()；initialRoute=WuyAppRouter.getDefaultRoute()；homeRoute=WuyAppRouter.getHomeRoute()。
- router_app_wuy.dart: initialLocation 直接固定为 routeHome（/wuy/home）；getDefaultRoute() 也返回 routeHome。未配置基于登录态的 redirect，也未使用 Splash 进行分流。
- login_screen.dart: 登录按钮使用 Navigator.pushReplacementNamed(context, '/wuy/home') 跳转，未使用 GoRouter API，且未写入用户登录态（仅延时 2 秒）。

三、首页改造建议（首页=我的好友，未登录跳登录）
A. 新增“我的好友”页面
- 建议新增 features_app_wuy/friends/views/friends_list_screen.dart（或将现有 home_screen 语义改为朋友列表）。
- 路由常量：const String routeFriends = '/wuy/friends'; 将标题显示为“我的好友”。

B. 路由默认页与重定向
- 修改 createRouter 的 initialLocation 使用 getDefaultRoute()；getDefaultRoute() 返回 routeFriends。
- 在 GoRouter 顶层增加 redirect 回调：
  - 若 userProvider.isAuthenticated==false 且 目标非 /wuy/login，则 redirect -> /wuy/login；
  - 若已登录访问 /wuy/login，则 redirect -> routeFriends。
- 使用 refreshListenable 监听 userProvider，登录态变化时自动重算重定向。

C. 登录页跳转改为 GoRouter，并写入登录态
- 登录成功后：
  - 调用 WuUserProvider.updateAuthMetadata(isAuthenticated:true, jwtToken:'mock'...) 或 setAppUser(...)+setAuthMetadata(...);
  - 使用 context.go(WuyAppRouter.routeFriends) 替代 Navigator.pushReplacementNamed。

D. Splash 分流（可选）
- initialLocation 改为 routeSplash；Splash 完成初始化后根据 isAuthenticated 分流到 routeFriends 或 routeLogin。

五、结构性问题与风险
- 路由系统混用：GoRouter（推荐）与 Navigator 混用，易导致返回栈异常、深链与重定向失效。
- 未集中使用路由常量：部分字符串硬编码（'/wuy/home'），建议统一调用 WuyAppRouter 常量与 go()/push() 扩展。
- Splash 未参与首屏：存在却未使用，导致初始化逻辑（本地会话恢复、权限请求）缺失。
- 鉴权未落地：WuUserProvider 与 AppPrefs 已准备，但未在登录/登出、应用启动、路由守卫等处打通。
- 多端主题/国际化具备，但具体业务页未复用公共组件（卡片、列表、表单）—后续建议沉淀组件库减少样式分叉。
- 命名与职责：当前 home_screen 是示例卡片页，建议改为 friends_list_screen 以贴合业务；dashboard 与 map/轨迹之间的边界需明确。
