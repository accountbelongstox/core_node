
# Flutter Bloom 项目规范

## 1. 项目结构
```
lib/
├── app_[name]/              # 应用模块 (qy/achat/wuy)
│   ├── feature_[name]/      # 功能模块
│   │   ├── view/           # 页面视图
│   │   ├── actions/        # 动作事件代码
│   │   ├── widgets/        # 小部件
│   │   └── common_widgets/ # 应用特定公共组件
│   ├── router_[name]/      # 应用路由
│   ├── controller/         # 应用控制器
│   ├── localization/       # 本地化文件
│   └── resources/         # 资源文件
│       ├── icon_images/   # 图标和图片
│       └── styles/        # 样式
├── common/                # 全局公共模块
│   └── widgets/          # 全局共享组件
└── theme/                # 主题配置
    └── mobile/          # 移动端主题
```

## 2. 开发规范

### 路由管理
- 路由文件位置：`app_[name]/router_[name]/router_[name].dart`
- 所有路由必须添加应用前缀（如：qy_）
- 所有页面必须注册到路由系统
- 主入口配置：`lib/util/route_manager.dart`

### 本地化
- 文件位置：`app_[name]/localization/`
- 必须包含 `en.dart` 和 `zh.dart`
- 翻译键必须添加应用前缀
- 使用方式：`"[app_name]_key".tr(context)`

### 主题应用
- 必须使用 `Theme.of(context)` 应用主题
- 主题文件：
  - `theme/mobile/app_dark_theme.dart`
  - `theme/mobile/app_light_theme.dart`
  - `theme/mobile/app_color.dart`
- 新增颜色添加到 `app_color.dart`，不修改现有颜色

### 功能模块结构
```
feature_name/
├── view/             # 页面视图
├── actions/          # 状态管理
├── domain/          # 业务逻辑
│   ├── model/       # 数据模型
│   └── service/     # 服务层
└── widget/          # 组件
```

### 命名规范
- 文件命名：
  - 视图：`xxx_screen.dart`
  - 组件：`xxx_widget.dart`
  - 模型：`xxx_model.dart`
  - 服务：`xxx_service.dart`
- 类命名：
  - 视图：`XxxScreen`
  - 组件：`XxxWidget`
  - 模型：`XxxModel`
  - 服务：`XxxService`

### 开发流程
1. 新页面必须添加到开发测试页面：
   `lib/app_dev/feature_dev/home/view/home_screen.dart`
2. 遵循现有代码结构，不破坏其他功能
3. 使用公共组件时，如需修改复制到应用内 `common_widgets` 目录
