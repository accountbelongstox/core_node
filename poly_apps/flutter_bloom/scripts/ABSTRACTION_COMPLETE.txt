## 文件系统桥接 (变量交换)

### PowerShell 实现
```powershell
# FlutterGlobalVar.ps1
$Global:GVAR_EXCHANGE_DIR = "$env:USERPROFILE\.core_node\.flutter_build\global_vars"

function Set-FileVariable($Name, $Value) {
    $filePath = Join-Path $Global:GVAR_EXCHANGE_DIR $Name
    [System.IO.File]::WriteAllText($filePath, $Value, [UTF8])
}

function Get-FileVariable($Name, $DefaultValue = "") {
    $filePath = Join-Path $Global:GVAR_EXCHANGE_DIR $Name
    if (Test-Path $filePath) {
        return (Get-Content -Path $filePath -Raw -Encoding UTF8).Trim()
    }
    return $DefaultValue
}
```

### Python 实现
```python
# unified_variable_system.py
class UnifiedVariableSystem:
    def __init__(self):
        self.gvar_exchange_dir = Path.home() / ".core_node" / ".flutter_build" / "global_vars"

    def set_file_variable(self, name: str, value: str) -> bool:
        self._ensure_gvar_dir()
        var_file = self.gvar_exchange_dir / name
        var_file.write_text(str(value), encoding='utf-8')
        return True

    def get_file_variable(self, name: str, default: str = "") -> str:
        var_file = self.gvar_exchange_dir / name
        if var_file.exists():
            return var_file.read_text(encoding='utf-8').strip()
        return default
```

### Bash 实现
```bash
# start.sh
GVAR_EXCHANGE_DIR="$HOME/.core_node/.flutter_build/global_vars"

get_file_variable() {
    local var_name="$1"
    local default_value="${2:-}"
    local var_file="$GVAR_EXCHANGE_DIR/$var_name"

    if [ -f "$var_file" ]; then
        cat "$var_file" | tr -d '\r\n' | xargs
    else
        echo "$default_value"
    fi
}
```

**结果**: ✅ 三种实现完全兼容,无编码问题

## 核心架构原则

### 1. 职责分离
```
Python (逻辑层)               Shell (执行层)
├── 配置读取                 ├── 平台特定命令执行
├── 决策逻辑                 ├── 进程管理
├── 脚本生成                 ├── 文件系统操作
├── 变量管理                 └── 平台差异处理
└── 错误处理
```

### 2. 文件系统桥接
```
Python 写入                   Shell 读取
├── 变量保存到文件            ├── 从文件读取变量
├── 脚本路径保存              ├── 执行脚本路径
├── 配置参数保存              └── 使用配置参数
└── UTF-8 编码,无 BOM
```

### 3. 平台感知
```
Python 检测平台               生成对应脚本
├── Windows                   ├── .ps1 / .bat
├── Linux                     ├── .sh (chmod +x)
└── Mac (未来)                └── .sh
```
