# PowerShell to Python Abstraction Mapping
# Cross-platform Flutter Bloom Build System
# This file documents the abstraction from PS1 to Python

## Core Architecture

### File System Bridge (Variable Exchange)
- **Windows**: PowerShell uses $Global:GVAR_EXCHANGE_DIR (~/.core_node/.flutter_build/global_vars)
- **Linux**: Bash uses $GVAR_EXCHANGE_DIR (~/.core_node/.flutter_build/global_vars)
- **Python**: unified_variable_system.py provides get_file_variable/set_file_variable
- **Principle**: File-based variable storage, one file per variable, avoids encoding issues

### Entry Points Comparison

#### Windows (start.ps1)
```powershell
1. Set working directory to Flutter Bloom root
2. Import win_common modules (FlutterGlobalVar, CommonUtilities, etc.)
3. Execute python main.py for app selection
4. Read KEY_SELECTED_ACTION from file variables
5. Route to: Invoke-DebugMode, Invoke-BuildMode, or Invoke-DesignTool
6. Execute appropriate PowerShell script or function
```

#### Linux (start.sh - NEW)
```bash
1. Set working directory to Flutter Bloom root
2. Define get_file_variable() bash function
3. Execute python3 main.py for app selection
4. Read KEY_SELECTED_ACTION from file variables
5. Route to: debug mode, build mode, or design_tool mode
6. Execute appropriate bash script or Python bridge
```

**Status**: ✅ Linux now has identical logic flow to Windows

### 4. Start Launcher (NEW)
**File**: scripts/build_scripts/shared/start_launcher.py
**Purpose**: Unified launcher orchestration

**Abstracted from start.ps1**: Main routing logic (lines 150-188)

**Original PS1 Logic**:
```powershell
try {
    $selectedAction = Get-FileVariable -Name $Global:KEY_SELECTED_ACTION

    if ($selectedAction.ToLower() -eq "debug") {
        Invoke-DebugMode
    }
    elseif ($selectedAction.ToLower() -eq "build" -or $selectedAction.ToLower() -eq "release") {
        Invoke-BuildMode
    }
    elseif ($selectedAction.ToLower() -eq "design_tool") {
        Invoke-DesignTool
    }
    else {
        Write-ErrorMsg "Unknown action"
    }
}
```

**New Python Logic**:
```python
class StartLauncher:
    def route_to_mode(self, action: str) -> dict:
        if action.lower() == "debug":
            return self.prepare_debug_mode()
        elif action.lower() in ["build", "release"]:
            return self.prepare_build_mode()
        elif action.lower() == "design_tool":
            return self.launch_design_tool()
        else:
            return {"success": False, "error": f"Unknown action: {action}"}
```

**Functionality Preserved**: ✅
- Identical routing logic
- File variable reading from same directory
- Error handling for unknown actions
- Mode preparation and script generation

## Variable Exchange System Validation

### PowerShell Implementation (FlutterGlobalVar.ps1)
```powershell
function Set-FileVariable {
    param([string]$Name, [string]$Value)
    $filePath = Join-Path $Global:GVAR_EXCHANGE_DIR $Name
    [System.IO.File]::WriteAllText($filePath, $Value, [System.Text.UTF8Encoding]::new($false))
}

function Get-FileVariable {
    param([string]$Name, [string]$DefaultValue = "")
    $filePath = Join-Path $Global:GVAR_EXCHANGE_DIR $Name
    if (Test-Path $filePath) {
        $value = Get-Content -Path $filePath -Raw -Encoding UTF8
        return $value.Trim()
    }
    return $DefaultValue
}
```

### Python Implementation (unified_variable_system.py)
```python
def set_file_variable(self, name: str, value: str) -> bool:
    self._ensure_gvar_dir()
    ps_var_file = self.gvar_exchange_dir / name
    ps_var_file.write_text(str(value), encoding='utf-8')
    return True

def get_file_variable(self, name: str, default: str = "") -> str:
    ps_var_file = self.gvar_exchange_dir / name
    if ps_var_file.exists():
        return ps_var_file.read_text(encoding='utf-8').strip()
    return default
```

### Bash Implementation (start.sh)
```bash
get_file_variable() {
    local var_name="$1"
    local default_value="${2:-}"
    local var_file="$GVAR_EXCHANGE_DIR/$var_name"

    if [ -f "$var_file" ]; then
        cat "$var_file" | tr -d '\r\n' | xargs
    else
        echo "$default_value"
    fi
}
```

**Status**: ✅ All three implementations are compatible
- Same directory: ~/.core_node/.flutter_build/global_vars
- Same encoding: UTF-8
- Same trimming: whitespace removed
- Same fallback: default value returned if missing
