================================================================================
NUXT MAIN START SCRIPT - USAGE GUIDE
================================================================================

The start.ps1 script has been enhanced to support both interactive menu and
command-line parameter modes.

================================================================================
BASIC USAGE
================================================================================

1. Interactive Mode (Original Behavior)
   .\start.ps1

   - Opens interactive menu to select app and mode
   - Saves last selection for next time

2. Direct Launch with Parameters
   .\start.ps1 <app_name> [mode]

   - app_name: Application to launch (required)
   - mode: "debug" or "build" (optional, default: debug)

================================================================================
AVAILABLE COMMANDS
================================================================================

Help:
  .\start.ps1 help

List Available Apps:
  .\start.ps1 list

Launch Specific App:
  .\start.ps1 pymatrix          # Debug mode (default)
  .\start.ps1 pymatrix debug    # Debug mode (explicit)
  .\start.ps1 pymatrix build    # Build mode

================================================================================
EXAMPLES
================================================================================

# Start pyMatrix in development mode
.\start.ps1 pymatrix

# Build ITTools for production
.\start.ps1 ittools build

# Start Example app
.\start.ps1 example

# Show help
.\start.ps1 help

# List all available applications
.\start.ps1 list

================================================================================
PYTHON INTEGRATION (pyMatrix)
================================================================================

The Python pyMatrix launcher (poly_apps/pyMatrix/main.py) now uses this
PowerShell script to launch the frontend:

  python poly_apps\pyMatrix\main.py

This will:
  1. Start the FastAPI backend on port 8000
  2. Automatically launch the Nuxt frontend on port 3007
  3. Wait for frontend to be ready
  4. Open browser automatically

Frontend output is captured and displayed with [Frontend] prefix.

================================================================================
TECHNICAL DETAILS
================================================================================

Architecture:
  - Multi-app entry switching via switch-app-entry.js
  - Physical file replacement of pages/index.vue
  - Environment variable APP_ENTRY determines active app
  - Each app has isolated directory structure

Start Process:
  1. Validate prerequisites (Node.js, Yarn)
  2. Scan available applications
  3. Process command-line arguments or show menu
  4. Switch app entry point (copy index.{app}.vue -> index.vue)
  5. Set environment variables (NUXT_PORT, NUXT_HOST, APP_ENTRY)
  6. Execute yarn dev:{app} or yarn build:{app}

Configuration Files:
  - apps/app_{name}/app-config.json (optional overrides)
  - package.json (yarn scripts)
  - scripts/functions/*.ps1 (helper modules)

================================================================================
TROUBLESHOOTING
================================================================================

If frontend fails to start:

1. Check prerequisites:
   node --version  # Should be >= 18.0.0
   yarn --version  # Should be installed

2. Install dependencies:
   cd poly_apps\nuxt_main
   yarn install

3. Check port availability:
   netstat -ano | findstr :3007

4. Manual start:
   cd poly_apps\nuxt_main\scripts
   .\start.ps1 pymatrix

5. View detailed output:
   The script now captures and displays frontend output in real-time
