六、使用指南
===============================================================================

启动应用 (通过 start.ps1)
─────────────────────────────────────────
推荐方式:
  cd D:\programing\core_node\poly_apps\nuxt_main
  ./scripts/start.ps1

说明:
1. 显示交互式菜单
2. 选择应用和模式 (Debug/Build)
3. 自动切换入口文件
4. 自动启动 Nuxt 开发服务器

手动切换应用
─────────────────────────────────────────
命令:
  node scripts/switch-app-entry.js ittools

查看当前应用:
  node scripts/switch-app-entry.js --current

列出备份文件:
  node scripts/switch-app-entry.js --list

恢复备份:
  node scripts/switch-app-entry.js --restore index.backup.xxx.vue

导入子 APP 资源 (正确方式)
─────────────────────────────────────────
✓ 正确:
  import { useItToolsStore } from '@/apps/app_ittools/stores_app_ittools/ittools-store'
  import ToolModal from '@/apps/app_ittools/components_app_ittools/ToolModal.vue'

✗ 错误 (已移除别名):
  import { useItToolsStore } from '@/app_ittools/stores_app_ittools/ittools-store'

导入公共库 (所有 APP 可用)
─────────────────────────────────────────
✓ 正确:
  import { useAppStore } from '@/stores/index'
  import { useAuth } from '@/composables/useAuth'
  import MainHeader from '@/common/components/layout/MainHeader.vue'

公共库导入规则 (严格禁止)
─────────────────────────────────────────
✗ 严格禁止在 common/ 中导入子 APP:
  // common/utils/helper.ts
  import { useItToolsStore } from '@/apps/app_ittools/...'  // ← 禁止!

原因:
- 违反依赖方向原则
- 导致所有 APP 都被引入
- 破坏 APP 隔离性
