**执行步骤:**
1. `yarn dev:ittools` → 调用 npm 脚本
2. `npm run switch-app ittools` → 执行 switch-app-entry.js

4. `nuxt dev` → 启动 Nuxt 开发服务器

- Host: `0.0.0.0` (从 `$env:NUXT_HOST`)
- Port: `3005` (从 `$env:NUXT_PORT`)

## 环境变量传递流程

```
PowerShell 环境变量设置
  ↓
$env:NUXT_PORT = 3005
$env:NUXT_HOST = "0.0.0.0"
$env:APP_ENTRY = "ittools"
  ↓
传递给 Yarn 进程
  ↓
Yarn 启动 NPM 脚本
  ↓
NPM 执行: cross-env APP_ENTRY=ittools nuxt dev
  ↓
cross-env 设置环境变量
  ↓
Nuxt 进程读取环境变量
  ↓
process.env.NUXT_PORT → 3005
process.env.NUXT_HOST → "0.0.0.0"
process.env.APP_ENTRY → "ittools"
  ↓
Nuxt 应用配置
```

## 错误处理机制

### Invoke-CommandWithErrorHandling

所有关键命令都通过此函数执行，提供:

1. **异常捕获**: Try-Catch 包装
2. **退出码检查**: `$LASTEXITCODE` 验证
3. **错误暂停**: `-PauseOnError $true`
4. **友好提示**: 格式化的错误信息

**示例错误输出:**
```
========================================
           ERROR OCCURRED
========================================

Error: Switch app entry to ittools failed

Details:
Source file not found: pages/index.ittools.vue

Exit Code: 1

========================================

Press any key to exit...
```

1. **菜单状态缓存**: 保存上次选择，加快重复启动

4. **异步浏览器打开**: 不阻塞主流程
