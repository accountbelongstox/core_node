# WordFlow AI — 设计与交互意图 / Design & Interaction Intent

本文件描述 WordFlow 前端要达到的**目标观感(Part A)**与**交互行为(Part B)**。它讲"要做成什么样、怎么用起来",不讲"用哪个类、哪个变量、哪个文件"。任何能达成这套意图的实现都是合格的。

|---|---|
| 视觉气质、配色、布局、组件形态 | Part A — 视觉意图 |
| 导航、用户流程、交互状态、浮层、动效 | Part B — 交互意图 |

# PART A — 视觉意图 / Visual Intent

## 1. 视觉身份与气质 / Visual identity & mood

整体调性取名 **Iris(鸢尾)**——一套以薰衣草/长春花(periwinkle)到紫罗兰为核心的柔和靛蓝紫色系。

- **亮色主题:** 柔和的薰衣草/长春花底色,近乎纯白的清透卡片漂浮其上,空气感强、留白充足、心情放松。
- **暗色主题:** 近黑的深靛蓝底色,带紫色环境辉光(violet ambient glow),不是死黑而是有氛围、有深度的夜空感。
- **玻璃拟态 + 极光氛围(glassmorphism / aurora):** 表面有半透明磨砂玻璃质感,背景有缓慢流动的柔光极光/光斑,营造通透、有层次、会呼吸的空间感。
- **渐变 vs 实色的纪律(核心设计原则):** 长春花→紫罗兰的**渐变只保留给"主角表面"(hero surfaces)**——主操作按钮 CTA、被选中的胶囊、底部导航中心动作、悬浮圆形操作按钮、Bento 卡片角标等"最该被点的东西"。**正文文字、图标、激活态文字、边框、轻底色一律用实色长春花-靛蓝**,绝不把正文染成渐变,也绝不用平涂的蓝色去画本该是渐变的主角表面。渐变=吸引点击,实色=承载信息。
- 卡片与行的阴影是**中性的紫灰色**(neutral violet-grey),不是偏蓝的冷阴影,保持柔和高级感。

## 2. 参考图一致性(强制) / Reference-image parity

整个应用的视觉事实来源是两张参考图:一张**亮色参考图**、一张**暗色参考图**。在创建或修改任何有可见设计的页面/组件前,必须先比对这两张参考图,确保产出在以下方面与之吻合:配色、渐变与实色的用法、圆角、玻璃质感、间距、悬浮岛底栏、胶囊菜单、区块标题、圆形图标块、亮/暗双主题。没有对照参考图的改动视为缺陷。亮暗双主题的视觉一致(dark/light parity)本身就是验收标准,不是可选项。

## 3. 配色与表面意图 / Color & surface intent

- **实色主强调色:** 鲜明的长春花-靛蓝,用于文字、图标、激活态、边框、聚焦环、轻底色容器。亮色下需在白底上达到 AA 对比;暗色下整体提亮以在深底上清晰可读。
- **渐变主强调色:** 长春花→紫罗兰的斜向渐变,亮暗主题各有一套,只用于上面所说的"主角表面"。
- **背景:** 亮色为柔和薰衣草渐变铺底 + 柔光光斑;暗色为近黑靛蓝 + 靛蓝/紫罗兰径向辉光,辉光缓慢流动。
- **玻璃卡片:** 亮色下玻璃更清透、更接近纯白(更高的不透明度,让卡片更"脆"更清晰);暗色下保持适度通透。

## 4. 布局意图 / Layout intent

- **移动优先、居中手机列:** 内容页是一条居中的"手机宽度"竖列。在平板/桌面上也保持这种手机 App 的居中窄列观感,而不是把内容拉宽铺满。一切都落在拇指可达范围内。
- **悬浮岛底部导航(floating island):** 底部导航是一块**居中悬浮的圆角岛**,离开屏幕底边漂浮、带强投影与饱和玻璃模糊;**中心动作被抬高、用渐变高亮**,刻意打破对称、成为最大的拇指热区;两侧标签保持安静、形成有意的视觉不对称。
- **胶囊式分类/筛选行(pill rows):** 凡是分类、筛选、分段切换,一律用一排可横向滑动的胶囊(pill)。未选中为磨砂浅色,选中为渐变填充并发光。**绝不用下拉框(select)或表格表头**来承担分类切换。
- **卡片/行式内容,拒绝裸表格:** 内容以卡片、行组、透气网格呈现。任何密集表格/密集网格都要改写成卡片或行式分组。
- **充足留白与呼吸感(breathing spacing):** 大面积负空间、统一的较大圆角、区块之间有从容的间距。
- **区块标题:** 用加粗的"真实标题"配一个安静的"查看全部 / See all"链接,而不是细小的全大写小标签。
- **圆形彩色图标块:** 游戏/快捷入口用圆形、带色的图标块。
- **透明媒体呈现:** 透明背景的商品/插图 PNG 放在带淡色底的媒体框里居中呈现(去底色的杂志式陈列)。

## 5. 图标意图 / Iconography

- **绝不用 emoji 当 UI 图标(强制):** emoji 不得作为界面图标或操作符号出现在按钮、统计、导航、成就、列表项目符号、图块、徽章、空状态、状态点等任何界面元素上。emoji 只允许出现在用户真正输入的内容文本里。
- **统一图标风格:** 使用一套一致的线性图标集,尺寸用类名控制、颜色随强调色走(不写死色值)。装饰性图标对辅助技术隐藏;仅图标的按钮要有无障碍标签。

# PART B — 交互意图 / Interaction Intent

下面只描述**目标**的交互与流程,以用户视角的步骤来写。

## 6. 信息架构与导航 / Information architecture & navigation

### 6.1 导航模型

主导航是**底部 5 个标签的居中悬浮岛**,在所有非沉浸式页面上出现,是移动端**唯一**的主导航(没有并行的侧边栏/顶栏菜单来抢占)。子页面在所在标签**内部**打开,返回时回到该标签。

五个标签及其职责:

| # | 标签 | 作用 |
|---|------|------|
| 1 | 首页 Home | 今日计划、推荐、快速开始、进度概览 |
| 2 | 词库 Library | 系统/我的/导入词汇、文档导入、AI 内容 |
| 3 | **练习 Practice(中心动作)** | 阅读 / 听力 / 闪卡 / 测验的入口 |
| 4 | 工具 Tools | 词典、AI 助手、分析统计的中枢 |
| 5 | 我的 Mine | 个人中心、进度、社交、设置 |

中心标签(练习)就是那个被抬高、渐变高亮的悬浮岛中心动作;其余四个保持安静。当前所在页面属于某标签时,该标签高亮。

### 6.2 三层架构 / Three-tier architecture

任何功能从任一标签出发都应在 **≤2 次点击**内到达。

- **学习 Learn(核心):** 首页(今日计划/推荐/快速开始/进度)→ 词库(系统/我的/导入词汇、文档导入、AI 内容)→ 练习(阅读/听力/闪卡/测验)→ 复习(今日待复习、日历、智能复习)。**首页 → 词库 → 练习 → 复习是一个闭环**;首页有一个"继续学习 / Continue learning"的入口,一键跳回上次的位置。
- **工具 Tools(辅助):** 一个中枢,分三块——词典(查词/翻译/发音)、AI 助手(翻译、TTS、文章处理、个人词典)、分析(统计、掌握度、趋势)。工具具备上下文感知,结果回流到学习中。
- **我的 Mine(个人):** 个人资料、进度(每日统计、历史、成就、日历)、社交(好友、排行榜、分享)、设置(偏好、语言/主题、通知、数据同步)。
- **到达目标:** 词典 ≤2 击;AI 工具经中枢 ≤2 击;社交是带分页签的单页。

### 6.3 设计原则 / Design principles

1. **简单优先 / Simplicity first** — 更少的页面,任何东西 ≤2 击,智能默认胜过堆砌选项。
2. **学习优先 / Learning first** — 学习是核心,一切都服务于无缝、沉浸的学习路径。
3. **渐进披露 / Progressive disclosure** — 新手看到简单的表层,高级功能逐步显露。
4. **即时反馈 / Instant feedback** — 操作立即响应,进度始终可见,成就当场奖励。
5. **数据驱动 / Data-driven** — 推荐内容、个性化路径、自适应难度。

## 7. 应用外壳与顶栏行为 / App shell & chrome

- **统一的顶栏契约:** 顶层标签页用"搜索胶囊式顶栏";子页面用"返回+标题"式的头部。没有页面可以自己发明一条临时顶栏。
- **顶栏内容:** 左侧是头像(点击进个人资料、带在线小圆点),或在子页面时变为返回箭头;中间是一条搜索胶囊(点击打开搜索浮层),搜索胶囊尾部带一个渐变的圆形筛选球;右侧是主题切换、语言切换、设置等仅图标的按钮——整体极简、刻意不对称。
- **滚动行为:** 顶栏在页面顶部时透明,向下滚动一小段后转为玻璃磨砂态(安静→实体的过渡)。
- **外壳组成:** 固定顶栏 + 可关闭的公告横幅(展示真实数据,不是占位假数据)+ 主内容区;主区可滚动,为固定顶栏和安全区留出内边距;平板/桌面上画布居中、保持手机窄列。
- **沉浸式 = 只给"学习动作":** 任何专注的学习/运行界面(阅读、听力、闪卡、测验,以及将来的练习运行)都是沉浸式的——头部精简(返回 · 进度 · 更多),内容铺满,**不显示底部悬浮岛**。
- **受保护路由真正拦截:** 未登录访问受保护页面时跳转到登录,登录后回到原意图位置。

## 8. 核心用户流程 / Core user flows

### 8.1 认证 / Auth

- 访客可浏览非受保护的内容;第一次触发受保护操作时,引导到登录,登录后回到原意图。
- 登录界面是玻璃卡片 + 渐变/实色 CTA,只保留极简顶部装饰。
- 表单内联校验,即时给出错误/成功反馈。登录成功后落到首页。

### 8.2 学习闭环 / Learn loop(首页 → 词库 → 练习 → 复习)

一个单一闭环:首页的"继续学习"一键续上上次的会话;词库里的"开始学习"无缝进入练习;练习结束后提供刚才答错项的复习;复习又喂养下一次首页的计划。每一步 ≤2 击,不会被甩回零散的旧页面。

### 8.3 沉浸式练习 / Immersive practice

- 精简头部:返回 · 进度条(如 5/20、25%)· 更多菜单。
- 居中的单词卡区域,带朗读音频。
- 底部动作行:自评(认识 / 模糊 / 不认识)**或**多选(A/B/C/D),答完**立即**给出对/错反馈。
- 闪卡:点击或滑动翻面(正面单词 ↔ 背面释义)。
- 全屏,无底部悬浮岛。

### 8.4 工具中枢 / Tools hub

工具中枢下分:词典(搜索 · 历史 · 收藏);AI 助手(翻译、TTS、文章处理、个人词典);分析(统计与图表)。任一工具从中枢出发 ≤2 击可达。

### 8.5 我的 / 设置 / Mine & Settings

个人中心下含进度(学习统计、历史、成就)与社交(好友 · 排行榜 · 成就 分页签)。设置中枢分为:显示 · 语言 · 学习 · 通知 · 数据同步 · API 服务 · 系统统计 · 关于——各项以行式条目呈现,子导航用胶囊,不用表格。

## 9. 交互状态 / Interaction states

每一个异步界面都要覆盖完整的状态集,用户能看到对应的明确反馈:

| 状态 | 用户看到什么 |
|---|---|
| **加载 Loading** | 统一风格的转圈/加载态;形状已知时用骨架屏占位 |
| **空 Empty** | 图标(线性图标,绝不用 emoji)+ 说明文字 + 一个主操作引导 |
| **错误 Error** | 内联错误信息 + 重试;网络错误优雅降级(用缓存/默认值),绝不空白崩溃 |
| **悬停/聚焦 Hover/Focus** | 强调色轻染 + 清晰可见的聚焦环(无障碍) |
| **激活/按下 Active/Pressed** | 轻微缩放;主角表面呈现渐变 |
| **禁用 Disabled** | 降低不透明度、不可点、对辅助技术标记为禁用 |
| **选中 Selected** | 胶囊呈现渐变激活态;底栏标签呈现激活岛态 |

**即时反馈:** 测验/闪卡作答、保存、开关切换都当场响应;耗时操作显示进度,绝不让界面卡死。

## 10. 浮层与层级 / Overlays & layering(强制)

- **为什么重要:** 玻璃卡片用了模糊与变换、滚动区会裁剪溢出,导致就地手写的"绝对定位下拉"会被困在兄弟卡片或固定外壳之下、浮不上来。
- **行为要求:** 任何锚定的浮动面板(下拉、菜单、替代下拉框、气泡、提示、展开浮层)**必须真正浮在所有内容之上**——挂到页面顶层、相对锚点定位、空间不够时自动翻转方向、点击外部或按 Esc 关闭。就地写一个困在卡片里的绝对定位下拉视为缺陷。
- **层级次序(行为约定):** 滚动内的吸顶头部 < 固定外壳(顶栏+底栏)< 锚定浮层(下拉/气泡)< 全屏弹窗 < 顶层提示(toast)。全屏弹窗永远盖在下拉之上,toast 永远在最上层。这是一条行为要求,不涉及任何具体数值。

## 11. 手势、转场与动效 / Gestures, transitions & motion

- **胶囊菜单**可横向滑动,带吸附(swipe + snap)。
- **底栏中心动作**悬停时微微上抬、按下时缩放;两侧标签随当前页面高亮。
- **按压反馈**无处不在:可点元素按下时有轻微缩放。
- **顶栏**滚动时从透明过渡为玻璃态。
- **极光背景**有缓慢的环境流动动效。
- **页面转场:** 同级标签间切换用横向滑动;下钻进子页用淡入+下滑;返回用淡入+上滑。尊重"减少动态效果"的系统偏好。
- **闪卡翻面:** 点击或滑动翻面,带弹性动效。
- **即时微反馈:** 测验答案(对/错的颜色 + 细微动效)、开关、保存都当场反馈。
- **布局规范:** 内容页是居中的手机窄列,绝不放宽到大尺寸容器;贴合参考设备框,一切落在拇指可达范围。
- **拇指热区:** 主操作位于底部中央(悬浮岛);所有可点目标 ≥ 约 44px。
