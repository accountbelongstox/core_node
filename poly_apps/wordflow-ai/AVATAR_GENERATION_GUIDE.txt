## 🔄 工作流程
═══════════════════════════════════════════════════════════════

1. **用户登录**
   ↓
2. **AppContext.login() 被调用**
   ↓
3. **UserProfileEnsurer.ensureUserProfile() 自动执行**
   ↓
4. **检查 nickname**
   - 如果为空 → 从 name/username/email 生成
   ↓
5. **检查 avatar**
   - 如果为空或默认头像 → 调用 DiceBear API
   - 使用 username 作为 seed（保证一致性）
   - 随机选择8种风格之一
   - 下载 PNG (256x256)
   - 转换为 base64
   ↓
6. **调用后端 API**
   PUT /api/app_qy_v1/user/profile
   Body: {
     nickname: "Generated Nickname",
     avatar_base64: "data:image/png;base64,...",
     avatar_filename: "avatar_1_timestamp.png"
   }
   ↓
7. **后端处理**
   - 解码 base64
   - 保存到 storage/app/public/avatars/appqyv1/
   - 更新数据库 avatar 字段为相对路径
   - 返回完整用户信息（包含 avatar_url）
   ↓
8. **前端更新**
   - 更新 React State
   - 更新 StorageCenter
   - 更新 StateManager
   ↓
9. **用户看到完整资料**

## 🎨 DiceBear API 使用示例
═══════════════════════════════════════════════════════════════

基础 URL:
https://api.dicebear.com/9.x/{style}/png?seed={seed}&size=256

示例:
- https://api.dicebear.com/9.x/lorelei/png?seed=adminroot&size=256
- https://api.dicebear.com/9.x/bottts/png?seed=john.doe@example.com&size=256
- https://api.dicebear.com/9.x/pixel-art/png?seed=user123&size=256&backgroundColor=b6e3f4

特性:
- 确定性生成（相同 seed = 相同头像）
- 无需认证
- 免费使用
- 支持 SVG/PNG/JPG/WebP/AVIF
- 最大尺寸 256x256 (PNG)

## 🎯 关键技术点
═══════════════════════════════════════════════════════════════

1. **头像生成**
   - DiceBear API (免费, 无需认证)
   - 确定性生成 (seed-based)
   - 8种风格随机选择

2. **文件存储**
   - Laravel Storage facade
   - Public disk
   - 路径: storage/app/public/avatars/appqyv1/
   - 通过 /storage/ 路由访问

3. **Base64 传输**
   - 前端: Blob → Base64
   - 后端: Base64 → Binary → File

4. **数据库设计**
   - 只存储相对路径
   - 返回时构建完整 URL
   - 支持外部 URL (filter_var FILTER_VALIDATE_URL)

5. **自动触发**
   - 登录后自动检查
   - 异步执行 (不阻塞导航)
   - 失败时不影响登录
