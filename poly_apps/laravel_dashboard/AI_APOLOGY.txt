4.2 After download, locate the file by scanning the target directory.
- Use “before/after” snapshot:
  - list matching files before download
  - perform download

4.3 Validate by file checks.
- Existence check
- Minimum size threshold (and optionally magic header checks)
- Only then proceed.

4.4 Make logs visible even under `$(...)`.
- Print progress to stderr.
- Print only the final selected path to stdout.

4.5 Keep the script short.
- Put common code in `common_functions.sh`.
- Keep this installer script mostly orchestration.
