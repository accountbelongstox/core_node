Laravel 12 Compatibility Check Guide
====================================

OVERVIEW
========

The compatibility checker provides comprehensive verification of system
requirements for Laravel 12 before deployment. It checks:

1. PHP version and extensions
2. Nginx version and configuration
3. Project structure
4. Database setup
5. System dependencies

QUICK START
===========

Standalone Compatibility Check:
  bash scripts/check-compatibility.sh

Embedded Check (during deployment):
  Automatically runs at start of:
  bash scripts/deploy.sh

WHAT GETS CHECKED
=================

1. PHP Version Detection
   - Installed PHP version
   - Minimum requirement: 8.2
   - Recommended: 8.3
   - Optimal: 8.4
   - Real-time output of version info

2. PHP-FPM Configuration
   - PHP-FPM service status
   - Socket file location
   - Socket availability verification
   - Real-time FPM version display

3. PHP Extensions (Laravel 12 Required)
   Required: bcmath, ctype, curl, dom, fileinfo, filter, hash,
             json, mbstring, openssl, pdo, pcre, session, tokenizer,
             xml, xmlrpc, zlib

   Optional but recommended: redis, memcached, imagick, gd, intl

   Real-time status: PASS/FAIL/WARN for each

4. PHP Configuration
   - Configuration file location
   - Critical settings:
     * memory_limit (recommended: 256M)
     * max_execution_time
     * post_max_size
     * upload_max_filesize
   - Real-time display of current values

5. Nginx Version Detection
   - Installed Nginx version
   - Minimum requirement: 1.20
   - Real-time version info

6. Nginx Configuration
   - Configuration file location
   - Configuration syntax verification
   - Laravel-specific config directory: /www/nginxconfig
   - Nginx service status (running/stopped)
   - Real-time validation results

7. Nginx Modules
   Required modules verification:
   - http_ssl_module
   - http_rewrite_module
   - http_gzip_module
   - http_fastcgi_module
   Real-time status for each

8. Laravel Project Structure
   Required files:
   - artisan
   - composer.json
   - composer.lock

   Required directories:
   - app/
   - config/
   - database/
   - routes/
   - storage/
   - public/
   - bootstrap/app.php

   Real-time PASS/FAIL for each

9. Composer
   - Installation verification
   - Laravel framework presence
   - Version information
   - Vendor directory status
   - Real-time output

10. Database Configuration
    - .env file existence
    - Database connection type
    - Database file location (SQLite)
    - Real-time status

CHECK RESULTS INTERPRETATION
============================

Status Indicators:
  [PASS] - Check passed, requirement met
  [FAIL] - Critical failure, deployment may not work
  [WARN] - Warning, feature may be unavailable
  [INFO] - Informational, just displaying values

Color Coding:
  Green  - Success (PASS)
  Red    - Failure (FAIL)
  Yellow - Warning (WARN)
  Cyan   - Information (INFO)

Examples:
  [PASS] PHP version meets Laravel 12 minimum requirement (8.2)
    -> PHP is installed and version is adequate

  [WARN] Nginx is not installed
    -> Nginx not required for development mode

  [FAIL] File missing: composer.json
    -> Critical issue, Laravel structure incomplete

  [INFO] PHP configuration file: /etc/php/8.4/fpm/php.ini
    -> Just displaying the current configuration location

LARAVEL 12 REQUIREMENTS
=======================

Minimum Versions:
  PHP: 8.2.0
  Nginx: 1.20.0 (for web server mode)

Recommended Versions:
  PHP: 8.3.0 or higher
  Nginx: Latest stable (1.25+)

Optimal Versions:
  PHP: 8.4.0
  Nginx: Latest stable

Required PHP Extensions:
  bcmath, ctype, curl, dom, fileinfo, filter, hash, json,
  mbstring, openssl, pdo, pcre, session, tokenizer, xml, xmlrpc, zlib

Recommended PHP Settings:
  memory_limit: 256M or higher
  max_execution_time: 300 seconds or higher
  post_max_size: 64M or higher
  upload_max_filesize: 64M or higher

TROUBLESHOOTING
===============

Issue: PHP version check fails
  Cause: PHP not installed or version < 8.2
  Solution:
    1. Install PHP 8.2+: apt install php8.4
    2. Verify: php --version
    3. Rerun check: bash scripts/check-compatibility.sh

Issue: Missing PHP extensions
  Cause: Required extension not installed
  Solution:
    1. List missing extensions from check output
    2. Install: apt install php8.4-{extension}
    3. Restart PHP-FPM: systemctl restart php8.4-fpm
    4. Rerun check

Issue: Nginx not found
  Cause: Nginx not installed (OK for development mode)
  Solution:
    For production: apt install nginx
    For development: Skip, use php artisan serve

Issue: Nginx configuration syntax error
  Cause: Invalid configuration in /etc/nginx/nginx.conf
  Solution:
    1. Check syntax: nginx -t
    2. View full config: nginx -T | less
    3. Fix configuration file
    4. Reload: systemctl reload nginx
    5. Rerun check

Issue: Database connection fails
  Cause: .env not configured or database missing
  Solution:
    1. Copy .env: cp .env.example .env
    2. Run migrations: php artisan migrate
    3. Rerun check

  Individual functions:
    check_php_version          - Check PHP version
    check_php_extensions       - Check extensions
    check_nginx_version        - Check Nginx version
    check_nginx_config         - Check Nginx config
    check_laravel_structure    - Check project files
    check_composer            - Check Composer

  source scripts/deploy_tools/compatibility_checker.sh

  if perform_full_compatibility_check; then
    echo "Ready to deploy"
  else
    echo "Fix compatibility issues first"
  fi
