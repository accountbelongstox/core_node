WHAT WAS ADDED IN PHASE 4?
═════════════════════════════════════════════════════════════════════════════

Three new compatibility checks + ServerManagerV1 domain binding integration:

  1️⃣  Laravel Artisan Command Verification
      └─ Checks if php artisan is callable and working
      └─ Verifies ServerManagerV1 commands are available
      └─ Shows Laravel version information

  2️⃣  Vendor Directory & Dependencies Status
      └─ Checks if vendor/ directory exists
      └─ Lists key Laravel packages (framework, console, DBAL, tinker)
      └─ Shows total number of installed packages
      └─ Displays version information for key packages

  3️⃣  Domain Binding Detection
      └─ Checks Nginx configuration for existing domains
      └─ Queries ServerManagerV1 database for bindings
      └─ Shows current domain configuration status

  4️⃣  ServerManagerV1 Domain Binding Registration
      └─ Automatically registers domains during Nginx integration
      └─ Uses php artisan servermanager:website:add command
      └─ Provides real-time feedback of registration process

WHAT EACH CHECK DOES
═════════════════════════════════════════════════════════════════════════════

1. check_laravel_artisan()
   ───────────────────────
   Checks:
   • Does ./artisan file exist? [PASS/FAIL]
   • Can PHP execute artisan? [PASS/FAIL/WARN]
   • What's the Laravel version? [INFO]
   • Are ServerManagerV1 commands available? [PASS/WARN]
   • Are migration commands available? [PASS/WARN]

   Status:
   [PASS] - Artisan is fully operational
   [FAIL] - Artisan file missing (blocking)
   [WARN] - Some commands unavailable (non-blocking)


2. check_vendor_status()
   ──────────────────────
   Checks:
   • Does vendor/ directory exist? [PASS/WARN]
   • Is laravel/framework installed? [PASS/WARN]
   • Is symfony/console installed? [PASS/WARN]
   • Is doctrine/dbal installed? [PASS/WARN]
   • Is laravel/tinker installed? [PASS/WARN]
   • Total number of packages? [INFO]

   Status:
   [PASS] - Package is installed, version shown
   [WARN] - Package not found, likely not installed yet
   [INFO] - Informational (total count, etc.)


3. check_domain_bindings()
   ────────────────────────
   Checks:
   • Does /www/nginxconfig exist? [PASS/WARN]
   • Does laravel_main.conf exist? [PASS/WARN]
   • What domains are configured? [INFO]
   • Is database accessible? [PASS/WARN]
   • Is app registered in ServerManagerV1? [PASS/INFO]

   Status:
   [PASS] - Domain binding exists and is configured
   [WARN] - No binding found yet (expected on first deploy)
   [INFO] - Status and configuration information


4. register_domain_binding_with_servermanager()
   ─────────────────────────────────────────────
   When called (during Nginx integration):
   • Displays command being executed
   • Shows real-time output from artisan
   • Reports success or warning
   • Does NOT block deployment on failure

   Example command:
   php artisan servermanager:website:add \
       --name="laravel_main" \
       --domain="localhost" \
       --path="/www/wwwroot/laravel_main/public" \
       --type="laravel" \
       --php-version="8.4"

TROUBLESHOOTING PHASE 4 FEATURES
═════════════════════════════════════════════════════════════════════════════

Issue: Artisan check shows [FAIL]
───────────────────────────────
Solutions:
  1. Verify artisan exists: ls -la artisan
  2. Verify PHP is installed: php --version
  3. Make artisan executable: chmod +x artisan
  4. Run: php artisan --version (test directly)


Issue: Vendor status shows [WARN] for packages
──────────────────────────────────────────────
Solutions:
  1. Run composer install: composer install
  2. Wait for completion
  3. Verify vendor exists: ls -la vendor/
  4. Check key package: ls -la vendor/laravel/framework/


Issue: Domain binding shows [WARN] "not configured"
──────────────────────────────────────────────────
Solutions (on first deployment):
  1. This is expected on first deploy
  2. Run deployment: bash scripts/deploy.sh
  3. Deployment will register domains
  4. Rerun check to verify


Issue: ServerManagerV1 registration shows warning
─────────────────────────────────────────────────
Solutions:
  1. Check vendor installed: composer install
  2. Check ServerManagerV1 app: ls -la app/Apps/ServerManagerV1/
  3. Check artisan command: php artisan servermanager:website:add --help
  4. Review database: sqlite3 database.sqlite ".tables"
