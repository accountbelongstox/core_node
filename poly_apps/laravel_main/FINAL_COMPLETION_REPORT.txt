   - Migration file checks for existing tables (hasTable)
   - Safe to run multiple times
   - Readonly database error requires manual permission fix

3. AI Provider Warnings (Optional):

   - deepseek: Not configured (can be ignored)
   - gemini: Available and working
   - These do not affect SMS functionality

4. SMS Testing:
   - Development mode (log driver) does not send real SMS
   - Codes are output to console and log files
   - Perfect for testing without incurring SMS costs

5. Tencent Cloud:
   - Requires company registration for signature approval
   - Template approval usually takes 1-2 business days
   - International SMS requires separate configuration

================================================================================
🔍 VERIFICATION STEPS
================================================================================

After Setup:
------------
1. Check file permissions:
   ls -la dd.sh                              # Should be executable
   ls -la /www/wwwroot/laravel_db/           # Should be www-data:www-data

2. Verify configuration:
   cat .env | grep SMS_                      # Check SMS settings
   php artisan config:cache                  # Cache config

3. Test initialization:
   php artisan sys:init                      # Should see all ✅

4. Test API endpoints:
   # Send code
   curl -X POST http://localhost/api/awy-v0/auth/send-code \
     -H "Content-Type: application/json" \
     -d '{"phone":"13800138000"}'

   # Check log for code (development mode)
   tail -f storage/logs/laravel.log

   # Login with code
   curl -X POST http://localhost/api/awy-v0/auth/phone-login \
     -H "Content-Type: application/json" \
     -d '{"phone":"13800138000","code":"CODE_FROM_LOG"}'

5. Verify database:
   sqlite3 /www/wwwroot/laravel_db/awy_v0_database.sqlite
   .tables                                   # Should see all tables
   SELECT * FROM awy_v0_verification_codes;  # Should see code entries
   .quit
