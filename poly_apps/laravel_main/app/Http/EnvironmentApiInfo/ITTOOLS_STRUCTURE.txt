================================================================================
ITTOOLS DEVELOPMENT TOOLS - STRUCTURE DOCUMENTATION
================================================================================

This document describes the structure and organization of the ITTools Development
Tools system integrated into the Laravel debug interface.

================================================================================
FILE STRUCTURE
================================================================================

1. HTML Template (Multi-file Architecture)
   └── app/Http/EnvironmentApiInfo/debug_interface_template.html
       - Main HTML template with external CSS/JS imports
       - Includes Development Tools section with complex layout
       - NAMESPACE markers for easy AI navigation

2. CSS Files (Modular Design)
   └── app/Http/EnvironmentApiInfo/assets/css/
       └── ittools-layout.css
           - NAMESPACE: ITTools Layout Styles
           - Complete styling for ITTools complex layout
           - Top menu, left menu, content, right panel, bottom menu

3. JavaScript Files (Modular Design)
   └── app/Http/EnvironmentApiInfo/assets/js/
       ├── ittools-core.js
       │   - NAMESPACE: ITTools Core JavaScript
       │   - ITTools.State: localStorage management
       │   - ITTools.Menu: Menu navigation and state
       │   - ITTools.API: API communication layer
       │   - ITTools.UI: UI helper functions
       │   - ITTools.Init: Initialization
       │
       └── ittools-tools.js
           - NAMESPACE: ITTools.Tools
           - ITTools.Tools.Registry: Tool registration
           - ITTools.Tools.Loader: Dynamic tool loading
           - Tool implementations:
             * Text Encoder
             * Hash Generator
             * UUID Generator
             * JSON Formatter
             * Timestamp Converter

4. Laravel Backend (ItToolsV1 App)
   └── app/Apps/ItToolsV1/
       ├── IttoolsV1ApiInfo.php       - API endpoint documentation
       └── IttoolsV1Gvar/
           └── Constants.php           - Global constants

5. Routes
   └── routes/
       ├── web.php                     - Asset serving routes added
       └── ItToolsV1Router/api.php    - Existing ITTools API routes

================================================================================
KEY FEATURES
================================================================================

1. localStorage-based Menu State Management
   - Remembers expanded menu groups
   - Tracks active submenu
   - Stores recent tools used
   - Persists right panel visibility

2. Modular Architecture
   - Separate CSS/JS files prevent file bloat
   - Easy to extend with new tools
   - Clean separation of concerns

3. Tool Registration System
   - ITTools.Tools.Registry for registering new tools
   - Dynamic tool loading
   - Consistent tool interface

4. Complex Multi-panel Layout
   - Top menu for main navigation
   - Left menu with collapsible groups
   - Main content area for tools
   - Right panel for additional info
   - Bottom menu for actions

5. API Integration
   - ITTools.API layer for backend communication
   - Connects to existing ItToolsV1 Laravel app
   - Supports all existing ITTools endpoints

================================================================================
ADDING NEW TOOLS
================================================================================

To add a new tool:

1. Register the tool in ittools-tools.js:

   ITTools.Tools.Registry.register('my-tool', {
       name: 'My Tool',
       category: 'category',
       render() {
           return `<div class="ittools-card">...</div>`;
       },
       init() {
           // Optional initialization
       }
   });

2. Create tool implementation:

   ITTools.Tools.MyTool = {
       async execute() {
           const result = await ITTools.API.post('/endpoint', data);
           ITTools.UI.showResult('result-id', result.data, true);
       }
   };

3. Add menu item in HTML:

   <div class="ittools-submenu-item" data-submenu-id="my-tool">
       My Tool
   </div>

4. Add backend controller/route if needed in ItToolsV1 app
