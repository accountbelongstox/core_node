SMS SERVICE FEATURES

✅ Configurable Settings (config/sms.php)

- Code expiration (30 minutes default)
- One-time code usage
- Automatic expired code cleanup
- Phone number validation

✅ Provider Support
-------------------
1. Tencent Cloud SMS (Production)
   - TC3-HMAC-SHA256 authentication
   - E.164 phone format
   - Configurable templates
   - Error handling

2. Log Provider (Development)
   - Console output
   - Log file recording
   - No actual SMS sent
   - Perfect for testing

✅ Verification Code Table
---------------------------
Database: awyv0
Table: awy_v0_verification_codes

Columns:
- id (primary key)
- phone (varchar 20, indexed)
- code (varchar 10)
- expires_at (timestamp, indexed)
- used (boolean, default false)
- created_at, updated_at

API ENDPOINTS
================================================================================

1. Send Verification Code
--------------------------
POST /api/awy-v0/auth/send-code

Request:
{
  "phone": "13800138000"
}

Response Success:
{
  "success": true,
  "message": "Verification code sent successfully",
  "data": {
    "phone": "+86138****8000",
    "expiresIn": 1800
  }

Response Error (Rate Limit):
{
  "success": false,
  "error": "RATE_LIMIT_EXCEEDED",
  "message": "Rate limit exceeded. Please try again later.",
  "retry_after": 45
}

  "data": {
    "user": {
      "id": 1,
      "username": "user123",
      "email": "user@example.com",
      "phone": "+8613800138000",
      "avatar": "https://...",
      "lastLoginAt": "2025-12-03T10:30:00.000Z"

    "token": {
      "accessToken": "eyJ0eXAiOiJKV1Q...",

{

CONFIGURATION GUIDE
================================================================================

1. Environment Variables (.env)
--------------------------------
# SMS Service Configuration
SMS_DRIVER=log                    # 'log' for dev, 'tencent' for production
SMS_CODE_EXPIRY_MINUTES=30        # Code expiration time
SMS_CODE_LENGTH=6                 # Verification code length
SMS_MAX_DAILY_SENDS=10            # Max sends per phone per day
SMS_RATE_LIMIT_SECONDS=60         # Minimum seconds between sends
SMS_ENABLED=true                  # Enable/disable SMS service

# Tencent Cloud SMS (Production Only)
TENCENT_SMS_SECRET_ID=your_secret_id
TENCENT_SMS_SECRET_KEY=your_secret_key
TENCENT_SMS_SDK_APP_ID=your_app_id
TENCENT_SMS_SIGN_NAME=your_signature
TENCENT_SMS_TEMPLATE_ID=your_template_id
TENCENT_SMS_REGION=ap-guangzhou
TENCENT_SMS_ENDPOINT=sms.tencentcloudapi.com

================================================================================
USAGE EXAMPLES
================================================================================

Example 1: Using VerificationCodeService Directly
--------------------------------------------------
use App\Services\VerificationCodeService;

$service = new VerificationCodeService('awyv0', 'awy_v0_verification_codes');

// Send code
$result = $service->sendCode('+8613800138000');
if ($result['success']) {
    echo "Code sent! Expires in: " . $result['expires_in'] . " seconds";
}

// Verify code
$verifyResult = $service->verifyCode('+8613800138000', '123456');
if ($verifyResult['success']) {
    echo "Code is valid!";
}

// Cleanup old codes
$deleted = $service->cleanupExpiredCodes();
echo "Deleted {$deleted} expired codes";

Example 2: Custom Expiry Time
------------------------------
$service = new VerificationCodeService();
$service->setCodeExpiry(15); // 15 minutes
$result = $service->sendCode($phone);

Example 3: Different Connection/Table
--------------------------------------
// Use with different app
$service = new VerificationCodeService('vipclubv1', 'vipclub_verification_codes');
$result = $service->sendCode($phone);

// Or using setters
$service = new VerificationCodeService();
$service->setConnection('custom_db')
        ->setTableName('custom_codes')
        ->setCodeExpiry(10);

⚠️ IMPORTANT: The following permissions must be fixed to complete initialization

1. Fix Core Node Permissions
-----------------------------
Run dd.sh and navigate to:
  Linux Management > Permissions Repair Menu

Select option 2: "Full Core Node Repair - All project directories"

This will fix permissions for:
- Core Node root directory
- Scripts directory
- Python directories (pycore, pyapps)
- Node.js directories (ncore, apps)

2. Fix Laravel Database Permissions (Manual)
---------------------------------------------
Note: dd.sh permissions menu does not currently include Laravel database
directory. You need to manually fix these permissions:

sudo chown -R www-data:www-data /www/wwwroot/laravel_db/
sudo chmod -R 775 /www/wwwroot/laravel_db/
sudo chmod 664 /www/wwwroot/laravel_db/*.sqlite

================================================================================
TROUBLESHOOTING
================================================================================

Problem: "Permission denied" when sending SMS
Solution: Check database file permissions (see above)

Problem: "Rate limit exceeded"
Solution: Wait 60 seconds or adjust SMS_RATE_LIMIT_SECONDS

Problem: "Daily limit exceeded"
Solution: Wait until next day or adjust SMS_MAX_DAILY_SENDS

Problem: "Invalid or expired code"
Solution:
- Check code hasn't expired (default 30 min)
- Verify code wasn't already used
- Request new code

Problem: SMS not sending in production
Solution:
- Verify Tencent Cloud credentials
- Check template ID is correct
- Verify signature is approved
- Check account balance

Problem: Tables missing in AwyV0
Solution:
- Fix permissions first
- Run: php artisan migrate --database=awyv0 --force
- Or: php artisan sys:init
