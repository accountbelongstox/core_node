INITIALIZATION INSTRUCTIONS
================================================================================

To complete the setup, run as system administrator:

1. Fix database directory permissions:

   sudo chmod 775 /www/wwwroot/laravel_db/
   sudo chown ubuntu:ubuntu /www/wwwroot/laravel_db/

2. Run initialization command:

   cd /www/programing/core_node/poly_apps/laravel_main
   php artisan sys:init

3. Verify AwyV0 initialization:

   Look for output:
   ✅ AwyV0
      ✅ database_connection: Check database connection
      ✅ create_database_file: Create database file if not exists
      ✅ run_migrations: Run database migrations
      ✅ verify_tables: Verify all tables created
      ✅ create_indexes: Create database indexes
      ✅ seed_initial_data: Seed initial data if needed

4. Check database:

   sqlite3 /www/wwwroot/laravel_db/awy_v0_database.sqlite
   .tables
   .quit
