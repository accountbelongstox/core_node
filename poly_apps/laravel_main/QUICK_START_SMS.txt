================================================================================
🐛 TROUBLESHOOTING
================================================================================

Problem: "Permission denied"
→ Run: ./fix-permissions.sh

Problem: "Rate limit exceeded"
→ Wait 60 seconds or adjust SMS_RATE_LIMIT_SECONDS in .env

Problem: "Invalid code"
→ Code expires in 30 minutes (default)
→ Each code can only be used once
→ Request a new code

Problem: "SMS not sending" (Production)
→ Check Tencent Cloud credentials in .env
→ Verify template ID and signature are approved
→ Check account balance

================================================================================
📞 TENCENT CLOUD SETUP (Production Only)
================================================================================

1. Register: https://cloud.tencent.com/product/sms
2. Create signature (需要企业名称审核)
3. Create template (需要模板内容审核)
4. Get credentials:
   - SecretID
   - SecretKey
   - SDK App ID
5. Add to .env
6. Change SMS_DRIVER=tencent
7. Test!

Approval time: Usually 1-2 business days
