## Overview

IT Tools is a comprehensive collection of developer utilities and converters, all accessible through a modern, user-friendly web interface. Built with Vue.js and TypeScript, it provides over 80+ tools for everyday development tasks.

### Key Highlights

- 🚀 **80+ Tools** - Extensive collection covering various developer needs
- 🎨 **Beautiful UI** - Modern, responsive design with great UX
- 🌐 **Multi-language** - Support for English, Chinese, French, Spanish, German, Portuguese, Ukrainian, Vietnamese, Norwegian
- 🔒 **Privacy-First** - All processing happens locally in your browser
- 📱 **Responsive** - Works seamlessly on desktop and mobile devices
- ⚡ **Fast** - Instant results with no server-side processing
- 🎯 **No Sign-up** - Start using immediately without registration

## Installation

### Prerequisites

- Node.js (v18 or higher)
- pnpm (v9.11.0 or higher)

### Quick Start

#### Windows

```bash
# Using batch file
quick-start.bat

# Or using PowerShell
.\scripts\quick-start.ps1
```

#### Linux/macOS

```bash
# Using shell script
./quick-start.sh

# Or using run script
./run.sh
```

### Manual Installation

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm preview
```

### 🔧 Technical Implementation

#### 1. **No Backend Server Required**

- **Static Site Generation (SPA)**: All processing happens in browser
- **No Database**: Uses browser's IndexedDB for local storage
- **No API Endpoints**: No server-side API calls needed
- **No Authentication**: No user accounts or sessions

#### 2. **Processing Models**


```bash
# - Netlify (zero config)
# - Vercel (zero config)
# - Cloudflare Pages
# - AWS S3 + CloudFront
```

#### Option 3: Self-hosted Nginx

```nginx
# nginx.conf
server {
    listen 80;
    root /usr/share/nginx/html;
    index index.html;
    
    # SPA routing
    location / {
        try_files $uri $uri/ /index.html;
    }
    
    # Gzip compression
    gzip on;
    gzip_types text/plain text/css application/json application/javascript;
    
    # Cache static assets
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg)$ {
        expires 1y;
        add_header Cache-Control "public, immutable";
    }
}
```

### 💡 Why No Backend?

#### Advantages

1. **🔒 Privacy**: All data processed locally, never sent to server
2. **⚡ Performance**: No network latency, instant results
3. **💰 Cost**: Zero server costs, pure static hosting
4. **📈 Scalability**: CDN handles millions of users easily
5. **🌐 Offline**: Works without internet (PWA)
6. **🔧 Simplicity**: No backend maintenance or scaling issues
7. **🚀 Speed**: Global CDN distribution, sub-50ms load times

#### Trade-offs

1. ❌ **No User Accounts**: Can't save data across devices
2. ❌ **Limited Storage**: Browser storage limits (IndexedDB ~50MB)
3. ❌ **No Server Processing**: Can't use server-side APIs
4. ❌ **Browser Limitations**: Some operations limited by browser capabilities
