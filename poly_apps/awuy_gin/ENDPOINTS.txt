Awuy (AwyV0) API endpoints mirrored from Laravel

/awy-v0/auth
- POST /register           | body: username, email, password, name?
- POST /login              | body: username, password
- POST /logout             | header: Authorization Bearer token
- POST /verify-email       | body: email, verification_code
- POST /forgot-password    | body: email
- POST /reset-password     | body: email, token, password
- POST /send-sms           | body: phone, country_code?
- POST /phone-login        | body: phone, verification_code

/awy-v0/user (auth required)
- GET  /profile            | header: Authorization
- PUT  /profile            | header: Authorization; body: name?, avatar?, phone?
- POST /change-password    | header: Authorization; body: old_password?, new_password
- POST /bind-phone         | header: Authorization; body: phone
- POST /bind-email         | header: Authorization; body: email
- POST /avatar             | header: Authorization; body: avatar

/awy-v0/friend (auth required)
- GET    /list             | header: Authorization
- POST   /add              | header: Authorization; body: friend_id, username, nickname?, notes?
- DELETE /remove           | header: Authorization; body: friend_id
- GET    /info             | header: Authorization; query: friend_id
- GET    /health           | header: Authorization
- GET    /search           | header: Authorization; query: q? (or keyword)

/awy-v0/device (auth required)
- POST   /register         | header: Authorization; body: device_id, name?, platform?, version?
- DELETE /unregister       | header: Authorization; body: device_id
- GET    /list             | header: Authorization
- PUT    /update           | header: Authorization; body: device_id, name?, platform?, version?, active?

/awy-v0/chat (auth required)
- GET    /conversations    | header: Authorization
- GET    /messages/:conversationId | header: Authorization; path: conversationId
- POST   /send             | header: Authorization; body: conversation_id?, to, body
- GET    /history/:friendId | header: Authorization; path: friendId
- DELETE /message/:messageId | header: Authorization; path: messageId
- PUT    /message/:messageId/read | header: Authorization; path: messageId

/awy-v0/search (auth required)
- GET /                     | header: Authorization; query: q? (or keyword)
- GET /users                | header: Authorization; query: q?

/awy-v0/dashboard (auth required)
- GET /stats                | header: Authorization
- GET /activity             | header: Authorization
- GET /insights             | header: Authorization
