## 🔄 **数据一致性原则**

### **1. 单一数据源 (Single Source of Truth)**
- **前端**：每个应用的状态由对应的后端服务管理
- **后端**：每个业务领域由对应的应用服务负责
- **缓存**：缓存数据以后端为准，定期同步

### **2. 最终一致性 (Eventual Consistency)**
- **异步同步**：非关键数据允许异步同步
- **冲突解决**：后端数据优先，前端数据作为补充
- **版本控制**：使用时间戳和版本号解决冲突

### **3. 数据隔离 (Data Isolation)**
- **应用隔离**：不同应用的数据逻辑隔离
- **用户隔离**：不同用户的数据物理隔离
- **环境隔离**：开发/测试/生产环境数据隔离

## 📊 **数据流设计**

### **app_achat ↔ BankV1 数据流**
```
┌─────────────────┐    HTTPS API    ┌─────────────────┐
│   app_achat     │ ←──────────────→ │     BankV1      │
│                 │                 │                 │
│ • 测试数据生成   │ ──── POST ────→ │ • 数据接收处理   │
│ • 用户资料管理   │ ←─── GET ─────  │ • 资料存储查询   │
│ • 心跳监控      │ ──── POST ────→ │ • 会话状态管理   │
│ • 本地缓存      │                 │ • 数据持久化     │
└─────────────────┘                 └─────────────────┘
```

### **数据同步策略**
1. **实时同步**：关键操作（心跳、状态变更）
2. **定时同步**：非关键数据（统计信息、日志）
3. **按需同步**：用户主动触发的数据更新
4. **离线缓存**：网络异常时的本地数据缓存

4. **权限验证**：基于应用类型验证权限

## 🗄️ **数据模型一致性**

### **前端数据模型**
```dart
// 统一响应格式
class NetworkResponse<T> {
  final bool success;
  final T? data;
  final String? message;
  final int statusCode;
  final DateTime timestamp;
}

// 用户资料模型
class UserProfile {
  final String deviceId;
  final Map<String, dynamic> profileData;
  final DateTime lastUpdated;

```

### **后端数据模型**
```php
// 统一响应格式
{
    "success": true,
    "data": {...},
    "message": "操作成功",
    "code": 200,
    "timestamp": 1640995200,
    "request_id": "uuid"

// 用户资料表结构
bank_users {
    id: bigint,
    device_id: varchar(255),

    created_at: timestamp,
    updated_at: timestamp

```

### **数据转换规则**
- **时间格式**：统一使用Unix时间戳
- **JSON格式**：使用UTF-8编码的JSON
- **字段命名**：前端camelCase，后端snake_case
- **空值处理**：null值统一处理规则

## 🔄 **状态同步机制**

### **app_achat 状态管理**
```dart
class AChatState {
  // 应用状态
  bool isOnline;
  DateTime lastHeartbeat;
  
  // 用户状态
  UserProfile? userProfile;
  Map<String, dynamic> testData;
  
  // 网络状态
  bool isConnected;
  List<PendingRequest> pendingRequests;
}
```

### **BankV1 状态管理**
```php
class BankV1State {
    // 设备会话
    public function getDeviceSession($deviceId);
    public function updateHeartbeat($deviceId);
    
    // 用户数据
    public function getUserProfile($deviceId);
    public function updateUserProfile($deviceId, $data);
    
    // 应用统计
    public function recordAppUsage($deviceId, $action);
}
```

### **状态同步流程**
1. **前端状态变更** → 构建同步请求
2. **网络传输** → 发送到对应后端服务
3. **后端处理** → 验证并更新状态
4. **响应返回** → 确认状态同步成功
5. **前端更新** → 更新本地状态缓存
